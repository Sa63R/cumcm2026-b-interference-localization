# 官方演练数据的固定评测规则

用户于 2026-09-12 要求：已采集官方数据仅用于模型完成后的统一评测，统一基线，禁止针对这批数据优化。本规则适用于强化学习、状态搜索及其他候选策略。

## 当前已冻结的内容

- 编号：`official-practice-audit-v1`。
- 第三问 436 局、第四问 436 局，共 872 局；全部纳入，不按模型表现挑选案例。
- 来源是已结束的**官方演练**交互记录，不是正式考试隐藏测试集。
- 从原库用 SQLite 只读 backup 制作独立一致快照；原库未修改，未启动或恢复采集。
- 数据文件、表结构、案例成员分别记录 SHA256。原库的旧 `split=train`、`trainable` 和文件名中的 `training` 不构成训练许可。
- [固定清单](official-practice-audit-v1.json)记录快照位置、身份摘要和基线完整配置。快照仅存本地，不提交数据库、原始案例或凭据到 Git。
- 已知历史上存在完整性、结构和观测支持审查，不能把整批数据重新称为从未看过的盲测集；未能追溯证明所有历史训练与开发过程完全未接触它。

## 数据能力与不能报告的成绩

本快照的能力是 `logged_trajectory_audit_only`。记录含原策略执行的动作、响应、时间，以及带保守误差范围的位置估计。它缺少精确源坐标、每源真实接收半径、第四问逐源类型与朝向，以及未访问位置的固定测向误差或等价的可复位官方环境。

可以审计原轨迹的费用、因果顺序、接口和公开历史处理。不得把原采集策略的用时、全清率或下界比值标为新模型成绩。当前新模型闭环均时与 T/LB 必须为 `null`，而不是 0。

只有当因果前缀和下一步物理动作、坐标、频道、生命周期完全一致，才允许复用对应历史反馈。第一次偏离后应返回 `unsupported_counterfactual`；禁止近邻插值、把估计圆心当真值、随机补方向或把不同轨迹拼成新策略轨迹。单个查询有记录不等于整个新策略可评测。

本次仅交付冻结和核验入口，未实现新模型的严格前缀重放器或闭环评测器。未来若有完整可复位场景或官方回放接口，另注册交互评测版本，并对所有候选与基线使用同一场景、误差实现和环境版本。不得借本集拟合缺失分布后冒称原官方场景。

## 禁止针对评测集优化

1. 整库及其副本、日志、衍生场景、位置标签均禁止用于梯度训练、模仿学习、奖励拟合、先验/场景分布估计、归一化拟合、阈值调参、挑 checkpoint、修改候选点或专门编写规则。
2. 训练、调参、早停与候选选择使用另外的开发数据。先完成候选选择，再登记源码 commit、工作树是否干净、参数、权重 SHA256、动作接口、终止/兜底规则和随机种子，然后评测固定端点。
3. “训练一轮”若指每个 epoch/update，不得每轮查看本集挑最好权重。最终候选的评测须留痕；同一已冻结版本的复核不变成一次新选型机会。
4. 禁止根据本集的差局、分层结果或排名反向修改模型。即使原始数据没进训练，反复看成绩再改也会造成间接适配。若违反，应标记该结果为已受开发反馈影响，不能继续声称独立最终测试。
5. 用户可以查看榜单并选择使用的版本；如果依据该榜单选择冠军，冠军的泛化性能仍需要另一个未参与选择的独立集合确认，不能把同一榜单当成无偏确认。
6. 原始场景和最终标签只供离线评估器审计；策略运行时只能接收截至当前动作的公开观测，不得看到结束后源数、位置估计、案例身份或整局结果。训练包不得包含该库或其派生场景。
7. 只因模型失败而删案例、只统计全清成功子集、临时换测试种子或下界，均不允许。数据追加或有效的数据修复应新建版本，保留旧版和所有结果。

这些是工作流约束；文件只读属性和 SHA256 核验不等于操作系统级训练隔离，也不能追溯消除历史曝光。

## 固定基线与统一报表

冻结对照不随“当前最好”自动变化：

| 题号 | 固定对照 | 源码 commit |
| --- | --- | --- |
| 第三问 | derived-silence combined v1；完整参数在清单中 | `760af8230a8e5bda6050663b19d871a9701c9829` |
| 第四问 | R8 compact_clear_before_probe；center_once，max_expansions=200 | `84773a198720d3e2575798871f800ed04470ceaf` |

这两项是身份登记，**并未获得它们在本快照上的新性能成绩**。以后出现更强状态搜索，作为额外一行加入，保留固定对照，保证历史可比。所有模型的基线用时必须来自同一测试版本，不能复制另一批场景的均值。

能够闭环评测时，每次至少报告：数据版本、候选身份、总案例数、全清/失败/超时数、平均实际计费用时、共同下界均值、`ΣT/ΣLB`、相对固定基线的配对差值与比例、P95、运行环境。CPU 墙钟耗时单列，不能混成物理任务时间。

- 主指标：`ΣT/ΣLB = 平均T / 平均LB`。
- 次指标：`mean(T_i/LB_i)`，明确另列，不能与主指标互换。
- 同一案例必须让所有策略使用同一个事先固定的 LB；下界版本和计算源码摘要随评测版本冻结。
- 原第三问物理下界为 `L/5 + 5N`；L 是真源 20 米清除圆盘之间距离松弛图的最短开放路径长度。
- 原第四问 `q4-common-source-edge-v1` 使用相同路径项，并在 N<16 时加入 `50(20-N)` 空频道证明下界。下界是乐观松弛，不是可达到最优时间的保证。
- 当前日志缺真值，不能据估计中心计算上述同口径下界。观测约束下界可以另行证明和注册，但不得与真值下界混用，也不能让各候选各自生成不同分母。
- 全清失败、超时和不支持的反事实必须保留。出现这些情况，完整成功性能不得默认为可比；不得把未完成轨迹的短时间作为速度优势。
- 配对区间以独立案例/种子簇为单位；多个同源场景不能假装互相独立。统计口径须在查看候选成绩前固定。
