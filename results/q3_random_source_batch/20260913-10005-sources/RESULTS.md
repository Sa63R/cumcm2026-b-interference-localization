# 问题三状态搜索：约一万源独立随机验证

使用 `experiment/q3-runtime-equivalent`，策略代码基于提交 `286b3f764c216cc8183bf39d3234640ca361e47b`。本次仅增加批量运行和核验脚本，未修改策略、模拟引擎、预算或参数。原有 `run_case` 负责执行与基本核验；完整源码 SHA、固定场景清单见 `manifest.json`。

## 主要结果

- 随机场景：763 局；干扰源：10005 个。
- 全清并正常退出：763/763；成功清除 10005 个源；失败清除尝试 0 次。
- 全任务累计计费用时：2352352.594758 秒。
- **每源平均计费用时：235.117701 秒/源**，按全部任务耗时之和除以全部源数计算。
- 以整局为重采样单位的 4000 次 bootstrap 95% 区间：[232.778, 237.365] 秒/源。
- 平均每局：3083.031 秒；每局耗时 P95：3481.175 秒。
- 逐局先算 T/N 再等权平均：239.378336 秒/源，此值与主指标口径不同。

## 数据与执行

使用仓库现有 `random_scenario(3, seed)`，连续新种子 2026091300–2026092062。源数在 10–16 中均匀抽取，位置在半径 1800 m 圆内按面积均匀分布，接收半径均匀分布于 1000–1500 m，沿用引擎默认均匀测角误差。所有场景在运行前固定，累计源数首次达到 10000 时保留最后完整一局，因此总数为 10005。

首 24 局用来测速，随后原样计入最终结果，没有因中间成绩筛选种子。运行在用户指定的 8 核 4060 主机上，使用 4 个 CPU 进程、低优先级，不使用 GPU；未调用官方模拟器。
测速 2.895 秒，剩余 739 局 91.247 秒，共 94.142 秒；此为运行器计算时间，不含准备、传输、审计及统计区间。并行状态下单局程序耗时平均 0.489 秒，不应作为与旧串行计时的速度对照。

## 独立核验及结果范围

逐项审计 98194 条动作记录，重新按移动距离、换频、检测、光学和清除规则计算费用；逐次验证累计时间，按真实源位置验证全部 10005 次成功清除均在 20 m 内，检查场景身份、全清、终止证书与退出状态。所有核验通过，见 `audit.json`。

该结果是本地合成随机分布上的成绩。历史 226.55 秒/源来自另一批 50 局官方演练；虽然主指标口径相同，地图和样本分布不同，不能把两者差值解释为程序优化造成的策略退步。
