# 旧评估器冒烟，不作为最终下界或性能成绩

本目录检查评估器能否对同一案例运行两种实现并比对动作。它早于下界口径修正，原lower_bounds.json错误地包含空频道认证费用，因此原T/LB不应引用为本任务旧物理下界比值。

最终评估使用原先的先知物理下界，不含该费用。相同6000案例的正确旧下界为1482.6491534174388秒，2858.965735秒虚拟用时对应1.92828204057倍。所有最终数据及审计在../linux/6c49ed604f98cc8e/bench和research/runtime_equivalent中。

本目录保留原始记录，不覆盖历史输出；不计入最终54案例的性能结论。
