# 强化学习与状态搜索：同场景配对比较

2026-09-11。结论：当前已评估的强化学习与已确认的状态搜索基本打平，没有证据证明强化学习更好。状态搜索平均略快，强化学习的P95较低，但本批最慢一局更慢。

## 统一实验条件

- 完全相同的48个已公开合成开发场景，种子2100001..2100048。逐例隐藏场景SHA256一致，位置、半径、误差函数一致；真实状态仅供仿真器和退出后的审核器使用。
- 同一台本地Windows电脑、同字节物理引擎/协议/评估器；每种方法独立进程，CPU单线程，共3个进程并行。没有使用GPU、官方模拟器或采集中的SQLite。
- 相同最大动作10000、虚拟预算360000秒、单局真实时间预算300秒。比较的是比赛计费的虚拟时间，不能将并发墙钟计时当作精确硬件性能结论。
- 冻结策略后才运行本批对比，不用本批表现选参数或检查点。配置、源码哈希、源码快照、输入记录和运行器均保存于此目录。
- 主对照为已完成独立确认/最终验证的持证清除尾段版本；原已演练状态搜索也完整运行作参考。尚未完成确认的其他新分支不作为“最佳”对照。

强化学习相对尾段状态搜索平均多用8.2201秒，即慢约0.265%。逐例强化学习26胜、22负；“状态搜索用时－强化学习用时”的平均值为−8.2201秒，20000次配对bootstrap的95%区间约为[−58.87,+41.21]秒，跨越零。因此不能从这48例判断哪一方平均性能具有可靠优势，更不能据此声称状态搜索已经最优或强化学习方向无效。

费用分解显示，强化学习平均少花29.8633秒移动时间、0.6667秒换频时间，但多测量7.75次，增加38.75秒检测时间，抵消了路线收益。两者光学与移除费用相同。此处支持的下一步诊断是扫描取舍；并不能从这一个批次证明少扫描一定更好。

## 纠正先前的比值比较

统一主下界为原状态搜索口径：LB=L/5+5N。L是事后知道全部源中心后，起点到20米清除圆盘、圆盘之间的最短距离边权构成的开放路径子集DP最优值。它是省略发现/定位等代价的先知松弛下界，不是在线可实现最短时间。本批平均LB=1746.245216秒。

先前强化学习“约1.607倍”使用了不同分母：在N<16时额外加入30(20−N)秒，本批该下界平均1936.245215秒。原状态搜索旧报告使用纯物理下界，部分表格还使用逐局比值的平均。因此，直接比较旧状态搜索约1.8倍和新强化学习约1.6倍不成立。此次同时固定场景、分母和聚合方式；完整统计中另外保留此前强化学习分母的结果。

强化学习原远程评估均时3111.796721秒，本次同一检查点在本机重跑为3110.201814秒，差−1.594907秒，但逐例差异绝对值平均25.9809秒、最大146.8014秒，不能用均值抵消后的1.6秒掩盖逐局漂移。不能声称逐动作完全复现远程环境：远端使用额外几何加速改动且运行平台不同；已观察到相同三角函数坐标的末位浮点差异，本地误差函数以精确浮点坐标哈希，末位差异可能影响后续反馈。本文结论使用双方本机统一引擎的结果，不混入远端时间。
