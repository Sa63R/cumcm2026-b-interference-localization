# 给论文作者：第三问提前光学策略

## 1. 本包对应的研究内容

在 v3 的覆盖搜索、集合定位和路径规划基础上，加入**受次数限制的提前光学清除**：当目标位置可行域已经较小、当前点或候选点的 20 米覆盖面积占比较高时，先尝试光学清除；失败后继续原定位流程。

主代码是 `code/vendor/policies/optical_experiment.py` 中的 `ExperimentalOpticalAgent`。它继承 `q3_v3.FastAgent`，再继承 `q3_optimized.OptimizedAgent`。因此论文方法应包括基础搜索和定位，以及额外的提前光学规则，不能只描述新增几十行代码。

## 2. 状态、约束和目标

每个频道属于未发现 `unseen`、正在定位 `tracks`、已清除 `cleared` 或已排除 `absent`。正在定位的目标保存凸多边形可行域 $P_c$、最小包围圆中心 $m_c$ 和半径 $R_c$、已测位置及局部探测次数。算法只接收位置、当前检测频道、测向/近距/无信号结果与清除成败。

若在 $p$ 收到测向角 $\theta$，通过两个半平面将可行域与测向扇区相交。实际入口将角误差界设置为 **1.005°**，含两位小数测向的舍入余量。首次可行域还使用最大接收距离 1500 米及部署圆盘的外包多边形。正负信号的距离关系进一步收缩可行域，详见 `refine_information`；处理负信号时使用保守外包，不直接把不可凸区域当作精确多边形。

基础清除要求找到 $q$ 满足

$$\max_{x\in P_c}\|x-q\|\leq20\text{ m}.$$

对凸多边形，检查全部顶点即可验证这个充分条件。代码的包围圆清除触发阈值为 **19.5 米**，并在路径中的清除点处再检查全顶点距离。这里使用的是最小包围圆及覆盖条件；不能把“可行域直径不超过 40 米”写成同一个充分条件。

每例评价值为

$$S_i=T_i/N_i^{\rm clear},\qquad \bar S=\frac1n\sum_{i=1}^{n}S_i.$$

当前主批均已全清，$N_i^{\rm clear}$ 等于该例源数。目标是在完成搜索与清除的前提下减小这个虚拟时间指标。采用案例等权平均，并非将所有案例总时间除以全部清除数。

本地引擎的计时可写为

$$T=\sum_{\text{移动段 }j}\operatorname{round}_{\mu s}(d_j/5)
+5M+1C+3A+2K.$$

其中 $M$ 是检测次数，$C$ 是检测切频次数，$A$ 是全部光学尝试次数，$K$ 是成功清除数。因此成功光学共 5 秒、失败光学共 3 秒。每段移动分别取整到微秒；清除动作不改变检测频道。完成最后一个清除后用于终止确认的动作也计入正常退出前总时间。

## 3. 提前光学的构造

对 $P_c$ 做扇形三角剖分，各三角形采用 `subdivision=10` 的等面积小三角形质心采样，以面积归一化得到点权 $(x_j,w_j)$。定义

$$h_c(q)=\sum_j w_j\mathbf 1\{\|x_j-q\|\leq20\}.$$

它近似表示可行域面积被 20 米圆覆盖的比例。**这是启发式评分，不是经过校准的真实后验成功概率**；代码没有证明 $h_c(q)\geq0.4$ 意味着真实成功率至少 40%。

固定参数如下，本批未按 2000 例结果重新调参。

| 参数 | 数值 | 代码位置 |
|---|---:|---|
| 面积评分阈值 | 0.4 | `ExperimentalOpticalAgent.__init__` |
| 允许提前尝试的最大可行域包围圆半径 | 80 米 | `max_radius` / `_allowed` |
| 每个目标的提前尝试上限 | 2 次，成功和失败均占次数 | `cap` / `_attempt` |
| 同一目标、同一坐标重复提前尝试 | 禁止，按 `coord_key` 判定 | `attempt_points` |
| 面积采样细分 | 10 | `area_points` |
| 选择面积质心的局部探测计数条件 | `local_steps[c] < 4` | `select_probe` |

新增行为可按下面的伪代码描述。实际继承流程及边界检查以源码为准。

```text
尝试提前清除(c)：
    若 c 不在定位中，或 R_c > 80，或提前尝试已达 2 次：返回未清除
    若当前坐标已对 c 提前尝试，或 h_c(当前位置) < 0.4：返回未清除
    记录这次尝试，调用公开 clear(c)
    若成功：更新 cleared / tracks / unseen，更新终止证书
    若失败：保留原保守可行域，返回未清除

选择下一探测点(c)：
    满足提前尝试资格且 local_steps[c] < 4 时：
        q = 面积加权质心
        若该点尚未尝试，h_c(q) >= 0.4，且全部顶点到 q 距离 < 999.9 米：
            选择 q
    否则使用 v3 的探测点选择

执行 observe(c)：
    先在当前位置尝试提前清除，成功则结束本次 observe
    否则执行原 v3 检测与可行域更新
    再按更新后的状态尝试提前清除
```

提前尝试失败不会将目标标成已清除，不从 `tracks` 中删除目标，也不会据此错误收缩几何可行域。最多两次尝试限制了每源直接失败光学费用为 6 秒；但由探测点改变带来的移动、检测和路径影响仍可能增加，不能据此宣称总额外代价最多 6 秒。

## 4. 继承的搜索与定位流程

`FastAgent.run` 将剩余覆盖点和正在定位的目标中心作为路径节点，在线选择下一任务；途中可执行附带扫描。`v3_origin20` 在原点先扫全部 20 频道；默认 v3 和提前光学会检查后续扫描点本身的覆盖条件后省去这一全扫。

定位中，v3 在局部候选探测点上用代价评分选点；局部探测计数达到 4 后，以及可行域已足够小时，回到包围圆中心探测。基础代码检查中心收缩条件。包围圆足够小时，在满足全顶点 20 米约束的清除区域中选择兼顾前后路径的点。

退出检查为 `unseen` 和 `tracks` 均为空，且 `cleared ∪ absent` 覆盖全部 20 个频道；评测器另外检查真实源全部清除及正常退出。代码有 600 次主循环保护，触发时报错，不能将这一保护本身当作收敛证明。

若论文要写严格保证，应分别论证：可行域始终包含真位置、搜索覆盖足以识别尚未发现频道、中心回退的收缩条件、基础清除的距离充分条件，以及提前失败后状态不变量仍成立。当前有限样本全清结果不能单独替代这些证明，也不能证明路径全局最优。

## 5. 实验设计与结果

场景来自本包固定的本地复原引擎：第三问源全部全向，源数 10–16，频道 1–20 无放回；位置在半径 1770 米圆盘按面积生成，接收半径 1000–1500 米，空间测向误差随位置变化且同点固定。策略使用的部署外界为 1800 米，两者不要混写。更详细的生成和量化逻辑见 `code/vendor/simulator/COMPATIBILITY.md` 及源码。

主批种子为 `q3-top5-holdout-20260912-0` 至 `q3-top5-holdout-20260912-1999`，2000 张图，每张五种方法共享完整场景和空间误差。额外计时种子为 `q3-top5-timing-20260912-0` 至 `q3-top5-timing-20260912-49`，单进程，每方法每例重复两遍，旋转及反转执行顺序。

| 方法 | 全清例数 | 平均秒/源 | 相对 v3 的平均差值 | 差值 95% 区间 | 本机平均执行秒/例 |
|---|---:|---:|---:|---|---:|
| 提前光学 `optical` | 2000/2000 | 239.261 | −1.631 | [−1.715, −1.546] | 0.0567 |
| v3 | 2000/2000 | 240.892 | 0 | [0, 0] | 0.0492 |
| 位置联合设计 `future_cover` | 2000/2000 | 240.924 | +0.032 | [−0.019, +0.084] | 0.0658 |
| 原点扫描 `v3_origin20` | 2000/2000 | 241.384 | +0.493 | [+0.034, +0.946] | 0.0558 |
| v2 | 2000/2000 | 243.850 | +2.958 | [+2.477, +3.433] | 0.1246 |

相对 v3，提前光学在 **1736 例更快、264 例更慢**，平均虚拟秒/源下降约 **0.677%**。主批合计 **1616 次失败光学尝试**，全部保留并计入代价。它在本批行动虚拟时间上更好，但本机计算耗时较 v3 增加；论文应同时报告这两个结果。

置信区间采用 10000 次案例 bootstrap，随机种子 20260912；比较方法时对同图差值重采样。区间未进行多重比较校正。`future_cover` 的配对区间跨过 0，本批未显示明确的平均收益。

主批 10000 轮共 1427131 个接受动作；另有 500 轮串行计时。每轮执行后重放，并独立审计场景配对、记录摘要、清除距离、动作计数与逐段微秒计费。原先 25 轮试跑不纳入上述均值。

现实执行时间包括进入、策略创建、规划、进程内接口处理和退出，不含场景生成、导出、重放及 JIT 预热。此计时不等于通过 UTM 和 HTTP 执行官方程序的耗时。

## 6. 写作与查数建议

正文可依次写“问题和代价模型—可行域定位—覆盖与路径决策—提前光学规则—同图对照实验”。主要消融对照是 v3 与提前光学，其他三种方法可放对照表。可从已有逐例数据制作配对差值分布、成绩分布及按源数分层图，无需重新拟造数据。

文中将主结果明确写为“本地复原模拟器上的 2000 个共同案例”。原 184 例官方演练用于筛选候选，未同图配对，且未包含在本包主实验数据中；正式测试成绩在本包中没有提供。有限场景中的全清、启发式评分和较低均值应分别表述，避免写成普遍成功率保证、真实后验概率或全局最优性。

`code/statistics.json` 保留未取三位小数的统计，`code/results/paired2000/results.jsonl` 保留逐轮指标。读取单轮完整记录：

```python
import gzip, json
from pathlib import Path

folder = Path('code/results/paired2000')
rows = [json.loads(s) for s in (folder / 'results.jsonl').read_text(encoding='utf-8').splitlines()]
row = next(r for r in rows if r['index'] == 0 and r['method'] == 'optical')
record = json.loads(gzip.decompress((folder / row['evidence']).read_bytes()))
print(row['seconds_per_source'], row['failed_clears'])
print(record['state']['scenario'])  # 仅供事后分析，不能输入策略规划
```
