# 第三问清除策略改进与独立验证

2026-09-10。新策略已实现、测试并接入演练入口；本文的独立验证阶段没有调用官方模拟器，论文继续暂停。生产算法冻结于 Git `730d683`，采用 Q3 `efficient`；历史 `adaptive + center` 保留用于逐场对照。

后续官方演练已完成：13/13全清、2979.14秒，详见[新版官方演练验收](第三问新版官方演练验收.md)。下文“待官方演练”保留本文初次研究完成时的状态。

**结论：在100个未参与调参的随机案例上，新策略全部全清、全部比旧策略快，平均总虚拟耗时降低31.16%；相对于同场景共同下界的平均差距缩小50.30%。这证明了有实际改进，不能证明新策略全局最优，也不能保证每个场景都更快。7个困难案例中有1个边界案例慢了15.20%。**

## 1. 改动为什么有效

旧策略在每个巡查点扫频后，先完成这一站发现的全部源，再接着走原覆盖路线。单源定位与全场移动分开决策，容易产生来回绕行。此前官方第三问演练的4589.81秒中，3853.81秒用于移动，占83.96%，因此首先优化总路程。

新策略把“尚未访问的覆盖点”和“已发现但未清除的源”放在同一条待办路线中。源的位置估计只来自合法反馈。用最近邻构造路线，再做开路2-opt改进；执行首项后，以新位置和新观测重新安排剩余任务。定位仍采用有界次数的中心/交叉测向，最终以保证清除点或28米光学网格兜底。

需要区分三个层次：剩余至多6个纯覆盖点的排列用子集动态规划求精确最短开路；混合覆盖点与估计源的路线用启发式；整个未知场景的最短清除时间没有被精确求解。本文不把局部精确计算称为全局最优。

## 2. 保留完整性依据的四项改进

### 2.1 缩短七点覆盖的环半径

原七点为原点加1500米正六边形顶点，新版环半径为1150米。对于1800米源分布圆盘，七点覆盖的最大最近测点距离为

\[
d_{\max}(a)=\max\left\{\frac a{\sqrt3},\sqrt{1800^2+a^2-\sqrt3\,1800a}\right\}.
\]

第一项来自原点与相邻两个环点形成的等边三角形内的最远空隙；第二项来自圆周上相邻环点方向的中间位置。按60度扇区划分、考察各最近点区域的顶点与外圆边界，即得到全场最大值。

令两项都不超过最小接收半径1000米，得到

\[
1122.955832458\le a\le1732.050807569.
\]

采用1150米时，最大最近测点距离约988.51米，留有11.49米余量。原点出发沿相邻环点走一圈但不返回的覆盖骨架长度为\(6a\)：从9000米降到6900米。单独这条骨架节省420秒，但真实清除轨迹还包含定位，因此不能把420秒当作每局必省时间。

### 2.2 用正、负观测共同缩小位置区域

同一未清除全向源位于\(s\)，接收半径\(R\)未知但固定。测点\(p\)收到信号，测点\(n\)无信号，则

\[
\|s-p\|\le R<\|s-n\|
\quad\Longrightarrow\quad
(n-p)\cdot s<\frac{\|n\|^2-\|p\|^2}{2}.
\]

把严格不等式放宽成闭半平面，与测向候选区域求交，不会排除满足观测的真实源。正负观测无论以哪种顺序到达都配对更新。代码没有错误地把无信号点周围1500米全部排除；这项推理只适用于第三问。

### 2.3 选择最近的保证清除位置

候选集包含于圆\(B(c,r)\)，且\(r\le19.9\)米时，任意满足\(\|q-c\|\le19.9-r\)的清除点都有

\[
\|q-s\|\le\|q-c\|+\|c-s\|\le19.9<20.
\]

新版选择这个允许圆盘内离当前位置最近的点，减少没有必要的最后一段移动。没有开启“候选区域尚大就先试一次”的激进清除开关。

### 2.4 成功清除16个不同频道后提前退出

题设公开源数上限为16，因此确认成功清除16个不同源即可停止。若观测已出现17个源则报告模型不一致，不会伪造成功。对于不足16个的场景，仍需完成保证覆盖并清除所有已发现频道才能认证。

这项规则的可核验反例：16个源在原点1米范围内时，旧策略耗时2137秒，新版199秒即退出。这里199秒是该版本的可行耗时，不是该场景的精确最短时间。预算不足、协议错误或未清除源会保留失败状态；安全的完成证书不等于任意预算下都能完成。

## 3. 参数选择与独立验证

开发使用种子2000—2029及7个固定困难案例，先后完成444和333次运行，比较环半径、调度方式、负观测、清除点偏移与激进清除等选项。所有开发运行均全清；激进配置存在清除尝试失败，已保留统计。

在查看独立样本前，固定 [q3_holdout_configs.json](../experiments/q3_holdout_configs.json)：1150米、联合路线、负观测开启、最近保证清除点开启、激进清除关闭。1123米环在开发中略快，但覆盖余量很小；主动试清除平均只额外节省约32—49秒，并增加极端误差案例的失败尝试。选用1150米保守版本。

独立随机样本为3000—3099，与开发种子不交叠。7个困难案例重复使用，仅单列为压力测试，不能称为独立留出样本。每场新旧策略使用同一源场景和同一按位置固定的误差函数。策略只获取观测客户端；真实源位置、总数与清除比例在退出后用于评分。

| 100个独立随机案例 | 旧 adaptive + center | 新 efficient |
|---|---:|---:|
| 全清且认证、正常退出 | 100/100 | 100/100 |
| 平均总虚拟耗时 | 5044.02秒 | 3472.45秒 |
| 各局T/N的平均值 | 387.36秒/源 | 267.60秒/源 |
| 总耗时95%分位数 | 6056.81秒 | 4022.09秒 |
| 平均移动耗时 | 4258.05秒 | 2641.16秒 |
| 平均测量次数 | 125.96 | 130.86 |
| 清除尝试失败总数 | 0 | 0 |

平均节省1571.57秒，即26.19虚拟分钟；总耗时降低31.16%。按案例成对bootstrap的平均节省95%区间为[1475.44,1673.79]秒。100场全部提速，单场节省583.04—2958.82秒。

收益主要来自移动减少1616.89秒；测量和换台增加共45.32秒，最终净省1571.57秒。这也说明测量次数更少并不等于总时间更短。

7个困难案例均全清，新旧平均耗时分别3577.47和4524.75秒，降低20.94%；但边界、1000米最小接收半径的案例，新版4371.75秒，旧版3794.89秒，慢576.86秒。其主动定位测量从48次增至60次，主动定位移动多538.44秒；没有光学清除失败回退。这是“新策略逐场支配旧策略”不成立的明确反例。未据此修改已经冻结的方案或重新挑选留出样本。

## 4. 是否真的更接近下界

为避免把不同场景混在一起，对每个已经结束的模拟场景，用同一组真实源位置离线计算新旧策略共同的下界。真值没有反馈给在线策略，也没有用于回改路线。

若真实源位置为\(s_i\)，成功清除点必在\(B(s_i,20)\)内。原点到首次清除、两次成功清除间的必要路程分别不小于

\[
d_{0i}=\max(0,\|s_i\|-20),\qquad
d_{ij}=\max(0,\|s_i-s_j\|-40).
\]

在这些边长上用子集动态规划枚举全部清除次序，得到最短开路\(L_{\rm lb}\)。于是，对要求保证发现与全清的策略，使用

\[
B=\frac{L_{\rm lb}}5+5N+
\begin{cases}
30(20-N),&N<16,\\
0,&N=16.
\end{cases}
\]

三项分别是必要移动、每个源的成功清除动作、空频道排除额外源的必要动作成本。最后一项的圆周覆盖推导沿用 [三四问理论耗时下界](三四问理论耗时下界.md)，不包含移动，因而没有重复计时。\(N=16\)可利用公开上限终止，不加空频道排除项。实际计算另减微小数值余量。

不同边的最小距离可能需要共享清除圆盘上的不同点，无法同时实现；本下界还省略了其他必要定位、换台等成本。因此 **B是松弛下界，不是可达到的理论最短时间**。

| 同一100个独立随机场景 | 旧策略 | 新策略 |
|---|---:|---:|
| 共同下界的平均值 | 1919.87秒 | 1919.87秒 |
| 平均实际耗时 / 平均下界 | 2.627 | 1.809 |
| 平均实际耗时与下界之差 | 3124.16秒 | 1552.58秒 |

相对于这组下界的平均差距缩小约50.30%。1.809是这一组案例的“均值之比”，不是每场比值上限，更不是适用于任意合法场景的1.809近似比。此前官方演练的2253.15秒下界属于另一具体场景，不能拿它来除本表的3472.45秒平均值。
