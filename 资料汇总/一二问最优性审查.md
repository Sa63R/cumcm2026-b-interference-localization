# 问题一、二当前方法的最优性审查

本轮是诊断与证明工作，没有修改几何、定位或搜索算法，没有调用模拟器，也没有更新论文。复现脚本为 [check_q1_q2_optimality.py](../experiments/check_q1_q2_optimality.py)，结果见 [q1_q2_optimality.json](../results/validation/q1_q2_optimality.json)。结果记录被检查模块的 SHA-256，避免未来改进代码后误用旧结论。

## 1. 必须区分三个问题

1. 给定定位多边形，直径和最小包围圆是否精确？这是几何结果正确性问题。
2. 得到相同几何结果，当前实现是否运行最快？这是算法复杂度和实现效率问题。
3. 第二检测点是否使指定的定位损失最小？这是实验设计与优化问题，必须先定义目标函数。

题目第二问只要求获得较好的定位效果，没有唯一指定“最好”是最坏直径、最坏半径、期望误差，还是包含移动的总时间。未经明确不能把这些目标混为一谈。

## 2. 问题一：核心理论有精确证明，当前整套实现不是最优

对固定凸多边形 P=conv{v_i}，任意两点之差是顶点差的凸组合，因此 D(P)=max_ij|v_i-v_j|。精确谓词下，完整的旋转卡壳扫描求得精确直径。输入已经是顺序凸顶点时扫描为 O(h)，达到必须读取输入的线性量级；当前函数先重新计算凸包并排序，整个调用为 O(h log h)。

当前通用半平面交枚举两两边界交点，再对每个交点检查所有约束，最坏 Θ(m³)。重复 k 次同一首测(0,0)、0°，得到 m=2k 条半平面，当前实现的 contains 调用次数恰为 m³/2+m²+m。m=10、20、40、80 时分别为610、4420、33640、262480。已有分治、对偶凸包等 O(m log m) 算法，因此当前实现的复杂度不是最优。一般完整输出半平面交边界的比较模型下界也是 Ω(m log m)，但不能把这个结论随意推广到只求一个可行点或只输出直径。参见 [UPC 原作者讲义，第13–16页](https://dccg.upc.edu/wp-content/uploads/2020/10/5-Intersecting-halfplanes-LP-MSC.pdf)。

当前浮点实现还存在下列极端输入反例：

```python
p = ((-2, 0), (-1, -1e-14), (1, -1e-14),
     (2, 0), (1, 5e-15), (-1, 5e-15))
polygon_diameter(p)  # 当前返回3.0，独立顶点对枚举为4.0

minimum_enclosing_circle([(0, 0), (1e-9, 0)])
# 当前半径1e-9，数学最优半径5e-10
```

前者是长度4米、厚度约1.5e-14米的极薄输入，固定面积比较容差阻止卡壳指针前进；后者处于纳米尺度，绝对包含容差使微小两点被视为几乎重合。反例说明“所有浮点输入都返回数学精确值”不成立，不意味着已完成官方演练被这些问题影响。最小圆反例的输出仍覆盖输入点，但不具有最小半径。

随机增量最小圆的期望线性复杂度，是对随机处理顺序的期望；固定seed不能提供对任意输入的线性最坏保证。当前还有凸包预处理，不能把增量部分的复杂度当成完整函数复杂度。

## 3. 最小包围圆如何提供真正的全局最优证书

指定目标为 R*=min_c max_{x∈P}|x-c|。找到圆(c,R)包含所有顶点，先给出一个可行上界。再输出最多三个支撑点 p_j 和非负权重 λ_j，使得：

\[
\sum_j\lambda_j=1,\quad c=\sum_j\lambda_jp_j,\quad |p_j-c|=R.
\]

对任意其他圆心 z，有：

\[
\max_j|p_j-z|^2\ge\sum_j\lambda_j|p_j-z|^2
=R^2+|z-c|^2\ge R^2.
\]

任何包围圆都不能更小，而当前圆确实包含整个多边形，上下界相等即证明全局最优。这证明的是给定候选集的一次最坏距离最优，不能推成下一检测点或完整搜索时间最优。

若候选集是外包多边形，证书首先针对这个外包多边形；原始曲边真实可行集的最优半径可能更小。浮点实现应报告可靠下界L、覆盖上界U及差U−L，而不是仅凭测试通过宣称精确最优。

## 4. 问题二：已有明确反例否定当前代理评分的连续全局最优

首测为(0,0)、示向0°，其余均用默认参数。所有比较使用同一个现有score_detection_point函数、同一个候选源域、同一组源假设点和同一个移动惩罚：

| 第二点 | 当前代理评分J，越小越好 | 移动距离 |
|---|---:|---:|
| 程序选点(857.728610,514.102744) | 69.404935413 | 1000.000000米 |
| 反例点(833,551) | 69.196381729 | 998.744211米 |

反例点严格位于当前安全内多边形内部；到源候选多边形所有顶点的最远距离为998.744211米，小于1000米；与首点距离也满足25米最小移动限制。因此两点遵守相同约束，而且 J(833,551)<J(程序选点)。这一个反例足以否定现有选点对连续可行域的全局最优性。评分降低约0.3005%，这里只用其严格更低来反证，没有宣称取得了重大性能改进。

原因是当前程序只生成约25个离散候选点，没有优化整个安全域。当前评分自身又使用有限源假设、一阶交会误差和正弦截断，不等于所有第二次响应下真实后验半径的最坏值。

所以反例的精确结论仅为“代理评分未全局最优”，不能声称真实最坏定位半径或完整任务总耗时一定降低相同比例。

候选域本身也是保守子域。首测已接收到信号意味着真实接收半径R≥max(1000,|s-p1|)，而K0要求到所有候选源均不超过1000米，未利用这个联合信息。例如首测(0,0)、0°时，q=(250,0)虽然被K0排除（到可能源(1500,0)距离1250米），却对所有真实候选源保证接收：源距离首点r≤1000时，两者距离最多约750.06米；r≥1000时，r cos(theta)≥125使|s-q|≤r≤R。故K0不是最大保证接收域。这个事实本身不证明其内部不存在全局最优点，但限制了“全可行域最优”的声明范围。

另需区分：当前完整Q3/Q4演练默认active_policy=center，采用中心优先策略；只有Q3指定minimax才调用上述Q2代理选点函数。Q2局部选点最优性不能直接由两次完整演练成绩证明。

## 5. 若要进一步证明问题二接近真正最优

首先明确目标。例如在保证再次接收的可行域K上，最小化所有可能第二次响应后的最坏包围圆半径：

\[
F(q)=\sup_{z\in\mathcal Z(q)}R_*\bigl(C_1\cap C(q,z)\bigr),
\qquad \min_{q\in K}F(q).
\]

z包括合法示向和near；若考虑移动，可额外加λ|q−p1|/5，并说明λ的单位与选择依据。不能给误差和源位置擅自假设概率分布后再称为同一问题。

证明最优的途径是构造全域下界L和某可行选点的可靠上界U。采用区间分支定界等方法，覆盖全部可行第二点、全部可能第二响应；如果U−L≤δ，便可证明δ精度的近似最优。加密采样只能找到更好的候选或反例，未排除网格间区域时不能单独证明全局最优。

本轮没有给出真实F的全局最优解或δ最优证书。已完成的结论是：第一问核心几何目标可以建立最优性证书，现有实现仍有复杂度与数值边界问题；第二问现有代理选点的连续全局最优性已被反例否定。
