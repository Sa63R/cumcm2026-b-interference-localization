# T01 规则与接口说明

**先统一规则，再联通模拟器。** 本文是第一项任务的规则基线，供几何、搜索和实验模块共同使用。核心客户端位于 [client.py](../src/simulator_client/client.py)；官方软件包及登录环境仍待就绪，本文不代表已通过官方演练。

## 1. 规则基线：数值明确，状态连续

| 项目 | 统一口径 |
|---|---|
| 目标区域 | 以 `(0,0)` 为圆心、半径 1800 m；所有干扰源位于其中 |
| 初始状态 | `/enter` 成功后位于 `(0,0)`，测向机频道为 1，虚拟时间为 0 |
| 坐标与角度 | 东为 x 正向、北为 y 正向；东为 0°、逆时针为正，角度归一化至 `[0°,360°)` |
| 位置限制 | 可以走到目标圆域外；每个坐标分量必须有限且绝对值不超过 2000000 m |
| 频道与数量 | 频道为整数 1–20，每频道最多一个源；源总数为 10–16，具体数目不经接口返回 |
| 接收距离 | 每源有效接收半径为 1000–1500 m，具体值未知；覆盖保证应使用下限 1000 m |
| 源类型 | 第三问全向；第四问包含全向及定向源，定向覆盖 180°（含边界），朝向未知 |
| 测向误差 | 题给误差范围为 ±1°；同地点重复测量误差固定，不能靠重复平均消除 |
| 角度精度 | `svd_deg` 保留两位小数；后续几何模块需明确舍入容差并处理 0°/360° 环绕 |
| 过近阈值 | 距离 ≤5 m 且位于信号覆盖角内返回 `near`，没有示向度 |
| 清除半径 | 距离 ≤20 m 可精确定位并清除，与源的定向朝向无关；已清除源不能再次清除 |
| 移动 | 直线移动，速度 5 m/s；由 `/measure` 或 `/clear` 的位置变化触发 |
| 检测与切换 | 每次检测 5 s；仅 `/measure` 相对当前测向机频道发生变化时增加 1 s |
| 清除耗时 | 未发现目标 3 s；成功清除合计 5 s；`/clear` 不切换测向机频道 |
| 开始与结束 | `/enter`、`/exit` 本身不增加虚拟时间 |

若本步移动距离为 `d`，检测耗时为 `d/5 + 5 + 是否切换频道`；清除耗时为 `d/5 + 3或5`。现实程序无需为一次检测额外等待 5 秒。

## 2. 四个接口：字段固定，逐次执行

默认地址 `http://127.0.0.1:2026`，只监听运行模拟器的本机回环地址；端口可在模拟器空闲时修改。全部接口使用 **POST + UTF-8 JSON 对象**，`Content-Type: application/json`。路径不能追加斜线或查询参数，不允许额外 JSON 字段。

公共请求字段：`arena_id="default"`、`robot_id=当前登录参赛队号`、`request_id=本局唯一动作标识`。标识符不可含控制或不可见格式字符；`robot_id` 为 1–64 UTF-8 字节，`request_id` 为 1–128 字节。

| 接口 | 公共字段之外的请求字段 | `accepted=true` 的专有响应 |
|---|---|---|
| `/enter` | 无 | `max_virtual_duration_s`、`max_real_duration_s`、`remaining_real_duration_s` |
| `/measure` | `position: {x, y}`、`channel` | `measure_result`；仅 `direction` 时有 `svd_deg` |
| `/clear` | `position: {x, y}`、`channel` | `clear_result` |
| `/exit` | 无 | `exit_reason="user_exit"` |

所有业务响应共有 `accepted`、`real_timestamp_ms`、`virtual_time_s`。虚拟时间是可带小数的数值；`accepted=false` 中的 `virtual_time_s=0` **不能覆盖本地已知时刻**，应保留最近一次已接受响应的状态。

## 3. 响应解释：无信号不能直接判空

| 响应 | 含义与下一步约束 |
|---|---|
| `measure_result="direction"` | 接收到信号并获得带误差方向，才可读取 `svd_deg` |
| `measure_result="near"` | 有信号且距离 ≤5 m；可在原地尝试清除，无需虚构方向 |
| `measure_result="no_signal"` | 可能无未清除源、超距或处于定向背面，不能单次宣布频道为空 |
| `clear_result="success"` | 该频道源已清除，记录清除动作位置；该位置不等于源的精确坐标 |
| `clear_result="no_target_in_range"` | 指定频道无未清除目标位于本次清除点 20 m 内 |
| HTTP 200 且 `accepted=false` | 动作未执行；核对状态、队号、区域标识和未知字段 |
| HTTP 400 / 404 / 405 | 字段或取值、路径、方法错误，应修正请求 |
| HTTP 409 | 同 ID 内容冲突或不同动作并发，不能盲目更换 ID 再发 |
| HTTP 413 / 415 / 429 / 500 | 分别为请求过大、格式不支持、流量/幂等记录保护、内部错误 |

必须同时检查 HTTP 状态与 `accepted`，也要处理无 HTTP 响应的超时、断连及接口关闭。请求体上限 65536 字节，不得有重复键或 BOM，JSON 嵌套不超过 16 层。

## 4. 幂等与日志：同一动作，原样重试

- 每个新动作使用新的 `request_id`；收到完整响应后才发送下一个新动作，不并发调用。
- 网络超时不表示动作未执行；重试必须复用原路径、原请求内容及原 ID，防止重复移动、检测或计费。
- 同 ID 同内容重试返回首次完整响应；同 ID 改变路径、位置或频道等会冲突。无法判定结果时保留待确认动作，先解决该动作再继续。
- HTTP 400 及未知字段、身份不匹配等指定拒绝不占用 ID，修正后可复用；不要将此规则推广到所有错误。
- 自行记录请求、响应、时间及异常。正式模拟器的加密日志另行导出提交；本地明文日志不能替代官方日志。

## 5. 时间与演练：先就绪，再开始

**现实时间有两条截止线。** 数据准备完成后倒计时 5 秒，结束时开放接口并启动 25 分钟窗口；`/enter` 成功后另有最多 20 分钟，两者取较早截止。以返回的 `remaining_real_duration_s` 为本局预算，不能固定假定有 1200 秒。虚拟时间上限为 360000 秒（100 小时）。测试结束后接口关闭，不能再用 `/exit` 查询结束原因。

官方演练就绪流程：

1. 从附件 1 的[官方下载地址](https://pan.baidu.com/s/1P1yfVjY0RufU93XOdzhOLw?pwd=2026)获取完整模拟器目录（提取码 `2026`），确认操作系统可运行；移动软件时整体保留数据文件。
2. 用户在模拟器内自行注册/在线登录；程序仅使用参赛队号作 `robot_id`，不需要账号密码。
3. 保持联网，确认服务器时间校验通过；选择 **“问题 3 演练测试”**，等待数据准备及倒计时完成、界面明确显示接口就绪。
4. 在同一设备运行客户端，先执行最小动作流程并核对虚拟时间、频道状态和日志。非测试期间连接失败属于正常情况。
5. 正常调用 `/exit` 结束，记录案例编码和演练反馈。演练次数不限；第三、四问正式测试各仅 3 次，启动成功即占次数，联调不使用正式入口。
