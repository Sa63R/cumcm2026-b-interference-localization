## 2. 本地验证结果

运行命令：`.venv/bin/python -m pytest -q`。

**30 项测试通过。** [测试输出](../results/t01/pytest.txt)与[测试代码](../tests/test_simulator_client.py)已保存，覆盖：

- 附件 2 的计时示例：105 → 111 → 194 → 199 秒，且 `/clear` 不切频道。
- `direction`、`near`、`no_signal` 及两种清除结果；无信号不等于不存在。
- HTTP 200 业务拒绝及 400/409/429/500 拒绝，拒绝响应中的零时间不覆盖本地状态。
- 动作执行后响应丢失：重试不重复清除、不重复计费，本地只更新一次。
- 未知结果阻止后续新动作；即使重试遭拒，也保留原请求继续恢复。
- 进入响应丢失后恢复，不将剩余现实时间重新延长；超时前阻止新动作。
- 无效坐标与频道、会话生命周期、多线程调用串行化、绕过本地 HTTP 代理及可读日志。
- 非法已接受响应不会污染状态；命令行走通四接口，端口检查不发送动作。

另已运行[本地协议演示](../experiments/t01_protocol_demo.py)，[汇总](../results/t01/local-protocol-initial/summary.json)与[明文记录](../results/t01/local-protocol-initial/requests.jsonl)如下：
