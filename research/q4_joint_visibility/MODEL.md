# Q4 联合可见性：固定格网的保守候选区域

本阶段只有纯几何 helper，没有策略集成、617/618 场景、官方模拟器或数据库调用。基线 `da0c912`、已有完整 Q4 策略及其证据均未修改。数学推导和边界讨论见 [THEORY.md](THEORY.md)。

## 接口与信息范围

```python
from planning.joint_visibility_region import joint_visibility_outer
outer_vertices, evidence = joint_visibility_outer(
    canonical_vertices, positive_positions, negative_positions)
```

输入是 canonical 正观测凸外包 C 的顶点、真实正接收位置、真实 no_signal 位置；输出是安全外包顶点和可 JSON 序列化的证据字典。模块不读取源位置、类型、真实 R、朝向、场景种子或总数，不更改输入 C，也不发出动作。

未来调用方必须保证这些点属于同一个尚未清除的固定源：positive 可来自 direction/near；negative 只能来自真实无线电 measure no_signal。跳过的扫描、推断静默、clear miss 和源被清除后的静默不能混入。位置坐标足够形成这里的接收几何约束；原测向误差已经由调用方的 canonical C 保守处理。

## 为什么可以安全使用部分负反馈

对某个候选位置 s，全部真实正接收要求同一个接收半径满足

\[
R\geq R_*(s)=\max\{1000,\max_i\|P_i-s\|\}.
\]

若某个真实负点严格位于这个最小半径内，全向类型无法解释，定向类型必须同时满足所有正点的正半平面条件和该负点的背面条件。只有共同朝向已被证明不存在，才能排除 s。没有强制负点时，必须保留全向解释，即使正点绕着 s 分布、定向朝向交集为空。

本实现对整个格 B 作放宽，不在格中心判断：先给 R 下界和各负点距离上界，识别**对整格**都强制的负点；每个观测的允许朝向先对 B 内全部位置取并，再跨观测求交。不同约束可能以不同位置见证，因此这是安全但可能较弱的外包。负点严格背面放宽成闭条件，端点相交也保留；不是精确隐状态可行性的充要判据。

旧 Q4 的 range/shadow 是用正 C 推出某测量必静默并删去指令，本轮则从真实正负接收历史联合缩小位置候选；旧 positive-hull/pair 是接收探点构造，也没有实现这个联合负信息外包。

## 固定几何流程

1. 对 C 包围盒四边外扩 `1e-4` 米并向外取相邻浮点，生成共享边界的 `16×16=256` 个闭格。网格分辨率固定，不做参数搜索或自适应树。点/线等退化 C 原样返回。
2. 距离保护量为 `1e-7 + 128*ulp(全部坐标尺度)` 米。每格令 `R_min_lower=max(1000,max positive_min_distance)-guard`；负点上界为四角最大距离加 guard。只有 `negative_upper < R_min_lower-1e-4` 才对整格强制。
3. 观测点在闭格内、位于边角，或到格的距离下界不超过 `1e-7` 米时，朝向外包取全圆。其它情况下，点相对格的向量方向落在四角方向最短覆盖弧内；将它两侧各扩半圆得到允许朝向的并。负点先平移 π 再扩。
4. 所有弧向外扩 `1e-10` 弧度。正点再加入本地接收浮点容差所需的 `asin(min(1,1e-12*max(1,1/dmin_lower)))`。跨零区间完整保留；交集可以有多个分量，闭单点不删；不超过 `1e-12` 弧度的小间隙按保守方向合并。
5. 仅在有强制负点且所有允许朝向外包交集为空时删除整格。否则保留。与 C 没有交集的格，用精确有理裁剪单独证明“位于 C 外”，不把它冒充观测排除。
6. 对保留格与 C 的交集使用 `Fraction` 对输入 binary64 所代表的有理数进行精确轴向裁剪。每个有理交点向外舍入为一个微小矩形，保留四角，再用精确有理判向求凸包。输出可能比旧 C 超出相邻浮点尺度，不再通过普通浮点裁剪强行截回。

完整格网保证没有遗失未处理空间；裁剪和凸包不依赖有限样点冒充连续覆盖。实数方向放宽有保守性证明，有理裁剪/判向对给定浮点输入精确；距离和反三角函数仍是带余量的普通浮点计算，不声称整条程序经过形式化区间算术证明。

## 计算与回退边界

输入顶点最多 256 个，固定工作限制为 `256*(正点数+负点数) <= 65536`。超过限制、无正证据、C 退化、格网数值退化、几何异常、全部相交格被删除或输出退化时，返回原 C。异常发生前即使已经删除部分格，也不会返回部分裁剪结果。

复杂度由 `256` 个格的正负距离/朝向计算、精确多边形裁剪和最终凸包组成，约为 `O(256*(P+N+V)+K log K)` 次几何操作；有理数位数也影响运行时间，不能把这个式子当成真实 CPU 秒数或忽略 Fraction 成本。当前没有在线时间承诺。

证据中的 `passed=true` 表示返回值采用了安全外包流程，包括原 C 回退，**不表示缩小成功或性能达标**。`status=fallback` 时只能使用原 `output_vertices`，不能将 `cells` 中可能存在的部分删除记录用于决策。

## 日志与效果指标

证据包含 canonical 顶点、全部输入正负点、参数、完整 bbox 和共享 x/y 边界。每格按 `id=16*iy+ix` 保存 bbox、精确相交类别、半径下界、各负点距离上界、强制负点索引、各方向区间、最终朝向交集、删除/保留理由，以及保留交点的向外舍入小矩形。

非回退格网必须恰有 256 个格；保留格与原 C 的交集及输出凸包可独立重建。回退日志可能没有格或只有部分格，但输出必须逐坐标等于原 C。`old_disk/new_disk` 保存外包圆中心、向上修正后的顶点最大距离半径和 `<=19.9` 指示，`old_vertices_excluded` 列出确实在新外包外的原顶点，`became_ready` 标识是否跨过清除半径阈值。`runtime_s` 包括本函数的几何和新旧圆统计。

**删格数量不等于有效改进。** 构造 P=(0,±100)、N=(1005,0)、C=[990,1015]×[-1,1] 时，可以删中部格，但右侧上下极点仍允许某种朝向，取凸包后几乎恢复原 C，MEC 没有改善。把 y 半宽缩到 0.1 时，才确实削去右边界并保留真实可行位置 (1000,0)。两个情况均作为测试保留，未来应以极端边界/MEC/ready 变化评价潜在收益。

## 验证与未来集成约束

33 项纯单源几何构造测试通过，覆盖合法全向和多朝向定向源、真实正测向误差外包、接收边界容差、圆周跨零及多个分量、闭单点、观测点在格内/边角、零向量、半径等号、精确非二进制交点、完整 256 格、预算/异常/全删回退，以及严格削边与凸包填孔。测试没有导入模拟器或创建完整场景，因此没有任务 T/LB 或性能结论。

未来若集成策略，应保留原 canonical C 和真实观察账本。不能仅覆盖 `_ready/_target`：原 range 扫描会把 ready 记成旧 MEC 证书，原 resolver 也仍直接读取 canonical C。新 `joint_visibility_clear`、扫描删测理由、缓存前缀及调度目标需要各自明确的新证书和独立审计。只有实际 clear success 才清除源；更强位置外包不直接证明某个未来无线电探点必接收，也不删除未知频道的真实覆盖义务。
