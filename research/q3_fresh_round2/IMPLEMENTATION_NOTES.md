# 第二轮实现与复核说明

这是实验交接说明，不是论文。结果与默认策略决策以 GPT_PRO_HANDOFF.md 及完整 analysis.json 为准。

## 范围与版本

本轮遵循“冻结 V1b → 最小 C → 单层完整 rollout → 独立尝试清除 → 冻结测试”的顺序。未运行正式测试，也未调用官方演练接口，全部成绩来自离线研究模拟器或观测兼容的验证重建。未使用 GPU、强化学习主机或重置卡。计算在指定状态搜索主机以最多两个单线程 CPU 进程运行，文件通过对象存储交换。

B 是 01fbea52 的 V1b；src/strategies/q3_fresh.py 未改动。StepperQ3 将递归过程改为可保存、克隆、暂停的显式任务栈，在每个 measure/clear 边界可被规划器打断。只有基线候选时逐动作、逐费用复现原策略，不能把重构差异计入规划收益。

配置：B=冻结基线；C=B+可移动覆盖；R=B+单层 rollout；CR=C+rollout；CRA=CR+尝试清除。尝试增量只在开发四配置完成后开始。第一轮32个留出案例已参与方向选择，本轮未再称其为未接触测试。

## 加强下界

物理下界沿用源访问距离的开放 Hamiltonian 路径 DP 松弛：起点至源减20米、源间距离减40米并截零，再加每源5秒成功清除费。它不包含完整信息获取代价，也不等于已知可达到的最优值。

当 N<16，保证不漏源的策略必须排除空频道上的所有可能源位置。1000米无信号盘和20米失败清除盘都位于完整轨迹的1000米邻域内，因此该邻域必须覆盖1800米圆域。N=16时不能强加此必要条件。

面积法给 L≥1120π≈3518.583772米。更强证书固定六点：(1800,0)、(900,1558)、(-900,1558)、(-1800,0)、(-900,-1558)、(900,-1558)。对轨迹进入六个1000米圆盘的720种顺序，分别构造满足 ||u_i||≤1、u_7=0 的对偶向量。对任意相应访问点 q_i：

    Σ ||q_i-q_(i-1)|| ≥ Σ (u_i-u_(i+1))·c_i − 1000 Σ ||u_i-u_(i+1)||.

生成器的数值求解只负责找证书。验证器使用 Fraction、整数平方根和向上取整的范数惩罚独立检验全部不等式。最弱证书为 1106407876784159/250000000000=4425.631507136636米，安全采用4425.6米。原附件的sandbox压缩包不在本机，因此这里重新生成并验证，而非假称读取原包。证书文件SHA256为9fdcf78bcd5d4d731b448cfcd7c25f423e4bd05cbe7a6377accd3d8f0aa609de。

空频道动作费仍至少30秒。1000米测量盘在外圆周覆盖的角度小于6/5弧度，20米失败清除盘小于1/40弧度；枚举5m+3f<30的非负整数组合，覆盖总角度均小于2π。忽略切换只会使下界更宽松。

    LB_physical = L_DP/5 + 5N
    LB_guarantee = max(L_DP,4425.6)/5 + 5N + 30(20-N),  N<16
    LB_guarantee = LB_physical,                            N=16

两项移动下界取最大值，不能相加。4425.6米约束整个任务，不能当作真实最后清除后的拖尾下界。验证重建另外以位置不确定半径松弛距离，报告 observation_robust_* 下界；重建坐标本身不是确切官方真值。

## C 的最小几何改动

复用七个 COVER 点的外包 Voronoi 责任多边形。责任区 P 对应可行检测位置 Q=交集 B(v,1000)，v遍历P顶点。只在“已发现源均清除、仍有未知频道”的可观测状态启用；固定当时的责任任务、访问顺序和频道集合，只改位置。新源出现后返回普通发现定位流程。

优化目标是从当前点出发的开放路长，无返回原点末段。实现采用24轮块坐标迭代、每块最多24次投影 Weiszfeld/majorization 更新；投影按圆盘交集候选求解，并保留1毫米内缩裕量。逐责任区证书和整条固定顺序路长都检查；无法改进就保留原路线。没有宣称迭代已达到全局最优，没有加入责任区合并或阈值调整。

开发数据69次触发中61次发生于评估器所知的实际全清之前，因此C不能用“只消除真实后清拖尾”的平均上限约束。几何路长下降也不保证后续发现和总任务时间下降。详细退步链见tail_analysis.md。

## 条件场景与单层 rollout

复用现有q3_belief和q3_branch的条件场景与公共状态恢复基础设施。本轮调度本身仍以从零分支的V1b为基线，没有继承其他分支的成功路线或验证集拟合参数。

名义先验明确为N在10至16均匀、N个频道的子集等概率、源位置按圆域面积均匀、接收半径在[1000,1500]独立均匀。已知源位置用兼容半径区间长度加权有限池采样；负观测严格要求半径小于距离，正观测、near、清除成功与失败排除均兼容。未知源数量通过后缀DP联合选择，保留1/组合数(20,N)和各频道负历史证据，累计已知数包括清除过的源。

这是有限池近似，且测向采用1.005度保守兼容带，不是已识别的官方误差似然，也不是对官方地图生成器的精确后验。历史误差缓存；未来误差按场景种子、频道、规范化坐标固定。同一批世界在候选间复用。抽样失败不会证明频道不存在，只回退B。

R固定最多5个非尝试候选，CRA最多再加第6个尝试候选，以保持独立增量：基线动作、附近其他已知源的清除/补测、当前点最多3频道共享测量束、下一覆盖点的未知频道束，以及在候选限额内的75米横向补测。候选束每次真实只执行一个API动作，可被后续规划打断；共享的是移动，不免费共享测量或切换。

首次对所有候选使用4个共同世界；基线与最佳替代候选再加8个世界，最终比较12个完整配对差值。这与建议的“最好的两个候选”略有区别：始终保留基线进入追加阶段，避免最佳两项都不是基线时失去12世界配对对照。该区别已在测试前登记。

每条假想分支从当前合法公共状态和完整策略栈克隆，执行候选后用冻结B延续至自身证书成立并显式exit。即使真实评估器认为全清，也不能提前停止。CR/CRA的当前C动作可参与比较，但假想未来延续仍为B。未来线上再次规划与这种延续存在差异，不能直接套用精确期望下的策略改进定理。

平均配对差+1个标准误<-3秒才替换基线。这只是预登记工程防抖，不是统计显著性保证。每局最多12次昂贵规划；前20个动作不规划，相邻规划至少间隔8动作；单次6秒、累计60秒，并预留30秒真实执行时间。合作式截止检查可能有一个短操作的尾差，实际最大值另报。未完成的任意必要分支不计为便宜样本，而是整个决策回退。

## 尝试清除

只针对已确认存在且包围圆半径20至80米的源，提议包围圆心清除；每次新观测后最多两次，排除已失败的相同位置。成功5秒、失败3秒，清除不切换测向频道。失败圆单独保留，条件场景后续排除 B(q,20)，原保守外包区域不作不安全的非凸裁剪。后续仍恢复B定位。保留与否以完整时间增量判断，不以少测几次或成功率判断。

## 统计、复现与审计边界

开发三类、冻结名义类、冻结压力类、重建验证分开汇总。报告均值、最近秩P95、最慢案例、动作分解、全清/退出、每源数分层、逐例T/N以及物理/加强下界比值。主表比值是组平均时间除以组平均下界；analysis.json另外保留逐例比值均值，两者不可混用。

配对bootstrap以原始case group为重采样单位；重建每组两个半径版本先平均，再重采样12个组。压力集是刻意构造的测试族，置信区间不能代表官方分布。失败不作为更短完成时间；重复冲突保留原始记录并从主选择统计中明确排除。

独立分析器重算每个API动作的移动、测量、切换、成功/失败清除费，检查累积时间、反馈兼容、固定点误差、已清集合、正确退出、规划预算和12配对决策日志。没有保存每个假想世界的全部行动日志，所以不能声称独立逐世界审计了common worlds；该点依靠实现和单元测试。连续覆盖几何由几何测试及C计划复核支持，通用分析器不重新证明每条覆盖证书；已有指数复杂度路径下界也未在通用分析器重复计算。

choices-audit.json是事后开发诊断：严格复现实际日志，在已选动作处用真实研究场景比较candidate→B和pending→B，完整退出才有效。它不接入在线规划、不使用验证库，也不作为新的总体性能样本。10个指定动作9次实际改善，1次预测节省约5秒但实际增加约163秒；这种误判必须与成功例一起保留。

另单独审计近共线案例R/CR的6个改动作，2次实际改善、4次方向误判。两条完整轨迹均准确回放；R的主要改善动作预测-216.61秒、实际-228.03秒，CR的主要改善动作预测-34.70秒、实际-180.57秒。其余4次误判实际增加约6.38至17.26秒。两批合计16个指定动作中11次实际改善、5次误判，不能据这组刻意选择的诊断样本估计总体误判率。

新验证导出严格排除第一轮12个证据哈希，再按SHA256('fresh-q3-v2:'+case_code)排序选前12个原组，各用历史兼容半径区间的0.25/0.75两个版本。重建失败不替换后续更好样本。只在候选冻结之后读取和导出真实验证数据，不用于拟合先验或阈值。数据快照和输入哈希在最终报告记录。
