# 第三问独立研究：第一版结论

本轮只研究第三问，保留原 main、原基线和第四问。三个独立方向均已完成实现及独立最终评估；状态搜索和强化学习达到预先设定的首版性能目标，几何方案有明确平均改善，但未达到随机集平均省时 5% 的门槛。**建议下一次官方演练优先验证状态搜索，强化学习保留为独立备选及对照。**

这是可复现的第一版研究结果，不是官方模拟器成绩，也不是连续在线问题的全局最优证明。用户不在电脑旁，官方演练按约定留待之后验证；本轮没有启动正式测试。

四种方法的最终 284 局均全部清除、正常结束、零失败清除。共 1,136 条完整案例档案通过身份与物理审计，14,600 次成功清除均能从行动前的观测重建清除证据；状态搜索的 527 条逻辑无信号推断也通过复核。这是对这些测试记录的结论，不是任意未来场景零失败的保证。

## 三个方向到底完成了什么

### 状态搜索

每完成一次源处理或完整覆盖扫描后，把“剩余覆盖站”和“已发现但未清除的源”构造成至多 22 个当前任务，用 `(已完成任务集合的位掩码, 最后任务)` 表示路线状态。处理过程中的观测更新区域与局部行动，不触发每步全局重调度。相同状态只保留较低前缀代价；以最小生成树等构造剩余代价下界，用最近邻和 2-opt 给可行上界，再进行有预算的 A* 搜索和剪枝。

这里能证明的是**当前冻结任务代理模型**中的状态合并与剪枝正确性；搜索闭合时，可在实现的 10⁻⁹ 秒比较容差下确认该有限模型的数值最优。它没有枚举未来所有方位反馈，不能证明完整第三问全局最优。开发诊断中约 98.94% 的相关子问题已闭合，说明单纯加大这些子问题的搜索预算未必是主要突破口。

主动定位依据保守候选区域构造几何探点，比较旅行与后续定位代价；探点可以在源候选区域之外。若已有区域与某个测点的最小距离严格超过 1500 米，可以合法推断那里不可能收到该源信号，省去这次物理测量；推断不冒充实际回包，也不抵扣未知频道的覆盖义务。

本轮增加的关键改进是**移动尚未执行的覆盖点，同时保留全场最终覆盖**。设 Ω 是已完成覆盖站和其他保留覆盖站尚未覆盖的区域，新站点 q 必须满足 `Ω ⊆ B(q,1000)`。可行站点集合为 `∩_{x∈Ω} B(x,1000)`，是凸集；沿有限方向找可行新位置，再交给路线规划器比较。实现检查圆盘边界和内部空洞的几何见证点，并保留数值余量。这是一种有几何依据的连续位置调整，而非简单加密整张地图。

最终覆盖保证不意味着提前发现的顺序不变。移站可能推迟某个未知源的发现，随后改变清除路线，因此仍会有坏局；这是后续值得研究的信息价值问题。

### 强化学习

完成了真实 PPO 网络训练。选定模型有 62,882 个参数，用 96 维隐藏层编码每个候选动作，并汇聚集合上下文；actor 选择行动，critic 学习后续代价。模型自己的继承训练链累计 **57,344 局，实际行为克隆为 0**。全部探索审计保留 18 个完整训练试验、53 个开发验证端点，共 359,168 条策略采样及 11,968 条额外配对基线轨迹；这些不能全部当作最终模型的独立训练场景。

网络选择测点、频道、覆盖扫描是否中断、先定位哪个源、采用哪个主动探点，以及何时清除已有证据的源。这些属于核心决策，部署时不由状态搜索器替网络打分。时间奖励为每步实际虚拟秒增量的负值除以 1000，并另有失败罚项；测量、换频、移动和兜底均计费。

同时保留固定的合法候选生成、保守几何区域、清除证书和有界兜底。网络没有自由输出任意连续坐标，也没有学习光学搜索内部每一步；因此可以称为覆盖核心调度与探测决策的强化学习，不能称为完全无规则、覆盖所有连续策略的端到端最优控制。

最终选择的 λ=0.95 同时改变优势估计和 critic 的 λ-return 训练目标，并未改变评估的实际总耗时或 γ=1。它体现偏差与方差的权衡，没有单调变好的理论保证。更大注意力网络、更多候选和继续训练均尝试过；更复杂或训练更久并没有稳定带来更好结果。

模型已在 Windows CPU 环境加载并通过既用训练案例的离线检查及零网络请求的演练入口 dry-run。跨平台浮点尾数可能改变测点，再改变位置哈希噪声，因此 Windows 兼容性结果不与 Linux 最终成绩混做配对比较。

### 几何方案

保留最近邻与 2-opt 全局调度，优化单个源第一次主动探测的选择，并加入同样的可移动覆盖点。主动探点评分包含旅行、测量和后续定位尾程，使用有限几何假设与噪声样本作近似；这些样本不是已经证明正确的官方后验分布。

该方向不调用状态 DP/A*，也不需要网络训练，因而保持独立。随机集有正向平均改善证据，但 4.36% 没达到预定门槛；不能把压力集的 10.29% 混入随机均值来宣布达标。

## 下界和“还能优化多少”

本轮重新区分了四件事：已知真值时的路线松弛下界、考虑合法终止证据的条件下界、冻结离散任务模型最优值，以及实际可执行策略的上界。它们不能互相替代。

自包含证明的下界针对实际源数 N<16、且对所有与观测相容的合法场景都提供完整清除认证的策略，结合源清除访问下界、未知频道覆盖证据所需路长、必要服务费与最低测量换频费用，采用

`L = max(L_source, L_certificate)/5 + 5N + 31(20−N) − 1{初始频道为空} − 舍入余量`，

其中证据路长项取 `L_certificate = 1120π` 米。两项路长取最大值，不能相加以重复计费。成功清除 16 个不同源时，允许依照题目源数上限提前结束，需要使用单独的 N=16 公式。完整假设和推导在状态分支 `research/theory_v1` 中。

另提供引用“六个单位圆盘不能覆盖本题半径比的圆域”结果的更紧版本；其加强量对 N<16 为 `3(20−N)` 秒。已明确保留引用条件：已读论文报告该六圆结果，但原始完整证明的来源并未全部取得，不能把它写成我们独立证明的定理。

随机测试中，自包含下界均值约 **1935.516 秒**；引用条件下的加强版约 **1955.602 秒**。以下统一是**平均时间除以下界平均值**，并非逐例比值再平均：

| 方法 | 对自包含下界的比值 | 对引用条件加强界的比值 |
|---|---:|---:|
| 原基线 | 1.7368 | 1.7190 |
| 状态搜索 | **1.5920** | **1.5757** |
| 强化学习 | 1.6274 | 1.6106 |
| 几何方案 | 1.6610 | 1.6440 |

所以“比此前更接近一个经过审查的下界”有证据；“已经接近无法再优化的极限”仍没有证据。下界省略了部分信息获取难度和动作耦合，未证明可达到，不能把 1.5920 解读为还确定能省 59.20%，也不能直接说该策略离在线最优还差 59.20%。理想连续先验下的期望信息成本另列，未硬加到每局下界中。

## 第一版完成后，下一版优先研究什么

1. **先做官方演练校准。** 验证实际反馈、时间账、坐标精度与研究模拟器一致，优先跑状态搜索，然后在更多官方演练中检查 RL 泛化。单个随机官方案例不能直接给不同方法作公平排名。
2. **状态搜索关注未来信息价值。** 当前有限路线子问题常已接近求完，主要欠缺是新源发现与后续绕路的预测。可研究覆盖移站对发现时机的代价、异步任务更新，而非只增加同一代理模型的搜索节点。
3. **RL 关注有效训练分布和尾部代价。** 独立验证课程/困难场景比例、稳定性和风险敏感目标，再考虑更大网络。保留纯 RL 独立分支；注意力、额外特征和加长训练的负结果说明“更大”本身不是收益保证。

未承诺下一版一定改善，也不重新使用本轮最终测试挑选修改。具体反例、逐局费用和训练失败路线都保留，方便提出可检验的新假设。
