# 首版串行运行成本

所有 GPU 训练、最终评估与物理深审结束后，在登记的 Linux 主机上逐个执行四种方法，OMP/MKL/OpenBLAS/NumExpr 均为 1 线程。每方法预热一局，再将已用开发种子 6000–6015 重复两轮，共 32 个计时案例。全部成功、零失败清除，各种子两轮动作历史字节摘要相同。

| 方法 | 平均实际秒/局 | 中位数及最大值 | P95实际秒/局 |
|---|---:|---|---:|
| 原 rollout 基线 | 5.844822 | 见原JSON | 6.657640 |
| 状态搜索 | 0.591682 | 见原JSON | 0.769840 |
| 强化学习，CPU | 0.170162 | 见原JSON | 0.196367 |
| 几何方案 | 2.098069 | 见原JSON | 2.679628 |

口径为整局策略及模拟器接口的墙钟时间，排除 Python 启动和一局预热；不是纯网络延迟、训练时间或机器人虚拟时间。它采用已经打开的开发场景，不构成新的独立效果测试。不同方法按固定顺序独立执行，仍可能受机器温度等非算法因素影响。

首次监督器在读取一个同用户、非训练系统进程的 `/proc/.../cwd` 时遇权限错误，故未启动任何计时案例；拒绝记录保存在 `initial_preflight_refusal.json`。修正仅允许已经由命令行确认不是训练的进程缺少 cwd；实际训练命令的 cwd 不可读仍拒绝继续。三项针对性回归检查通过，新批次使用独立输出目录，未覆盖原拒绝记录，也未改算法或模型。
