# 由真实旧负观测推断静默：理论与执行边界审查

本报告只读检查 `q3-r2-derived-silence` 当前基类的 `_scan`、真实客户端账本及 `OmniCandidateRegion`。没有修改实现、运行新案例或读取SQLite。新的helper/策略尚未作为已完成实现验收；以下是其设计条件及阻断标准。

结论：提出的几何判据正确，且比“整个区域距q超过1500米”能覆盖更多合法情况。主要工程风险不在代数，而在**真实负观测的来源、浮点正裕量、扫描中途达到16的处理，以及把逻辑处理完成误记为机器人真实到站**。

## 1. 证书的证明与适用前提

设频道c的源始终存在、静止、全向，接收半径R固定；当前c已经由真实正反馈确认且尚未清除。旧位置n的真实反馈为no_signal，所以对实际源s有

\[
\|s-n\|>R.
\]

设当前保守外包凸多边形C确实包含s，顶点集合为V。定义

\[
F(x)=\|x-q\|^2-\|x-n\|^2
=2(n-q)\cdot x+\|q\|^2-\|n\|^2.
\]

F关于x仿射。若所有顶点均有 `F(v)>0`，则任意凸组合x∈C也有F(x)>0，因此实际源满足 `distance(s,q)>distance(s,n)>R`，q必定no_signal。无需知道实际R，也无需使用R≤1500来完成这段证明。

边界上数学条件F≥0本来已经足够，因为旧no_signal给的是严格 `distance(s,n)>R`。首版保留严格正裕量更稳健；证书拒绝等距点是保守漏用机会，不是错误。q=n可以由重复真实负观测另作直接推断，但该严格仿射判据应直接拒绝，不能除以零。

一个人工说明：C为 `[-10,10]²`，n=(1100,0)，q=(1200,0)。所有点均有F≥228000平方米，因此旧n处no_signal足以证明q处静默。q距C约1190米，原1500米证书不会通过；新增证书确实有不同适用范围。

必须保留以下前提：

- 只用于问题3全向源；问题4后向静默不意味着距离超过R。
- c当前已知存在且未清除。清除后的静默只表示源已移除，不能作为原R的距离上界。
- n来自同频道、成功接受的真实measure/no_signal记录，允许发生在该源首次被发现之前；静止且固定R保证它仍有效。
- C非空、有限、保持真实源外包性质。点或线段退化情况仍可逐顶点核验；空集合不能因`all([])`而被当作证书。
- 必须先在当前C上通过证明，再记录推断；不能先把q的负约束加入C后反过来证明q，形成循环。

## 2. 浮点实现应怎样表述

直接计算两次很接近的平方距离再相减会有消去误差，单位也容易与米制裕量混淆。更稳的等价计算是：

\[
d=q-n,\quad u=d/\|d\|,\quad m=n+d/2,\quad
\frac{F(v)}{2\|d\|}=u\cdot(m-v).
\]

用 `min_v u·(m-v)>margin_m` 检查n侧的正间隔，单位为米。坐标差、归一化和点积必须有限；q与n相同或近到无法稳定确定方向时拒绝。使用归一化判据之后，不能把该数值又报告成“平方距离差”。

当前基础几何使用binary64、`EPS=1e-8`以及外包多边形。正裕量提供工程保护，但并不自动构成任意坐标规模下的区间算术证明。若实现要声称给定输入浮点顶点的严格代数符号证书，可在快速筛选后用向外舍入区间或精确有理数复核仿射式；仍需明确外包C本身沿用现有几何假设。不能用凸包中心、MEC中心或少量粒子替代全部顶点。

建议证书至少记录：q、真实n、n的原始action_history索引、使用时的实际动作数、顶点数量/区域摘要、最小归一间隔、裕量和推断类型。事后审计必须从原始前缀重建该时刻C及真实n，而不是用后来更小的区域倒证当时结论。

## 3. 不能直接把region的负点当作真实前提

`inferred_state_search.py:_scan`已经会把原1500米推断的q传入 `region.observe_no_signal(q)`。因此 `OmniCandidateRegion.no_signal_positions` 和 `_no_signal_set`混合了真实负观测及推导事实。

首版限定“只准真实旧负点作前提”，必须从 `report.action_history` 中筛选 `action=measure、result=no_signal、channel=c`，或维护只由成功 `_perform` 更新的等价索引。不能直接遍历region.no_signal_positions后把每个元素都称为真实n。`observed_positions`只有六位舍入的坐标集合，也不保存响应类型，不能用它恢复真实负观测。

当前C可以已经包含先前正确的推导约束；只要每次推导依赖的旧真实事实及先前C合法，这是按时间归纳的可靠外包更新。它不意味着可以把推导点伪装成真实测量前提。

`observe_no_signal(q)`只更新策略几何及内部负点集合是允许的，但不得更新：

- `report.action_history`、measurement_count、accepted_actions或actions；
- `client.state.position/current_channel/virtual_time_s/time_breakdown/sources`；
- `observed_positions`或“真实曾测过这个位置”的记录。

同一个q处后来真的进行了测量，仍应产生一条真实记录；几何更新可以幂等，但不能为了保留推断日志而拦掉实际反馈。审计器也必须按新的证书类型分派，不能继续把所有 `inferred_no_signal_constraints` 都交给旧1500米条件检验。

## 4. 达到16时跳过未知频道的边界

`known=detected|cleared`，不是两个集合长度相加。仅在已依法确认 `len(known)==16` 时，公开上界才保证其余频道无源。

检查必须在每个频道迭代时动态进行：本站的一条真实direction或near可能恰好发现第16个源。此后只`continue`仍未知的频道，不能`break`整个循环；尚未处理的已知未清频道仍走原“已有清除证书则跳过、可靠静默则推导、否则真实测量”流程。不能提前根据预测值或存在概率认为将达到16。

不应给被跳过频道造no_signal记录，也不修改客户端SourceState为“已测静默”。这是源数量上界推理，与距离静默证书是不同类型，应使用独立计数及原因。大于16表示数据/模型不一致，应沿原错误路径处理，不能用`>=16`掩盖矛盾。关闭新增选项时，必须保留父版本的动作及记账行为作为对照。

## 5. 整站逻辑完成不等于真实到站

现有 `InferredSilenceSearch._scan` 在循环之后无条件执行：

```python
self.report.coverage_points_visited += 1
self.discovery_stations.append(point)
self.blocked.clear()
```

原实现仍会真实测量未知频道；新加入16上限跳过之后，整站可能没有任何真实调用，不能直接复制这段收尾。

应区分三个事实：

1. **逻辑扫描任务处理完成。** 所有该查的频道已处理，剩余项被合法跳过；上层可以消费该待办任务。
2. **机器人确实在q做过真实动作。** 只能由成功客户端调用证明；如果没有调用，就不能改变位置、时间、频道，或把该任务计成一次新的真实访问。
3. **q成为完整未知频道巡检证据。** `discovery_stations`会进入覆盖重定位oracle，它的原语义是“每个仍未知频道都在这里真实测过”。即使在q有部分真实测量，其他未知频道因16上限未测时，也不能无区别写入这个证据集合。

一种保守且可审计的条件是：仅当本站结束时仍未知的每个频道，都有q处真实no_signal记录时，才把q加入原 `discovery_stations`。达到16使继续覆盖不再必要，但不能据此伪造原覆盖证书的前提。也可以为“因16上界无需继续巡检”建立单独证明类型；不能混用同一个列表而不说明语义改变。

若整站零真实调用且已知数仍小于16，应视为异常：本首版只推断已知频道，而此时必有未知频道仍须实测。若零调用且已达16，则可以逻辑跳过站点，真实当前位置保持原样，后续到其他源的移动费用必须从原真实位置起算。禁止为了方便后续代码手动将当前位置设为q，或仅添加一个没有付费的“移动”。

`EfficientSearch._execute_plan`会在_scan返回后移除剩余站点；这是任务列表状态，不是物理移动。`coverage_points_visited`和`coverage_complete`的旧审计口径须与这个区别一致。真实全清可以使用16源上界证明，不能把未执行的站点拼成全区域物理扫描证书。

`blocked.clear()`只是原策略的重试调度，不是新增物理信息。零调用或只有冗余推断时，若保留它，需要继续依赖有限待办站点与动作预算限制重试；不能声称每次解除blocked都得到了新的实测反馈。

## 6. 通道、移动和成本同步

客户端的同步状态只在 `_perform` 成功接受真实请求后改变。被推断的频道不能变成当前频道；后续第一条真实测量必须按客户端的实际频道和实际位置收费，而不是按原计划里最后跳过的频道/位置收费。

若本站还有其他真实测量，机器人会在第一条真实请求中移动到q；跳过之前的一条静默查询通常只减少测量和部分换频，不能再重复记一次“移动节省”。若整站均跳过，则此次不移动，但后续访问顺序及起点改变；整局收益仍须按真实完整轨迹计算。

删除一条measure至少涉及其5秒检测费用，换频变化由前后真实频道共同决定，不能统一按“每次省6秒”宣传。当前频道改变还可能改变下次扫描顺序；新反馈、几何浮点计算和滚动调度会影响后续轨迹，所以局部静默必然性不等于整局用时严格不退步。

## 7. 实现验收前的必要人工检查

| 检查 | 必须核对 |
| --- | --- |
| 严格内部、等距边界、反向点 | 正证书成立；零/负间隔拒绝；归一化符号正确 |
| q=n、极近q/n、NaN/Inf、空区域 | 不除零、不凭空集合放行，不接受非有限输入 |
| 点/线段/普通凸多边形 | 全顶点判据与独立仿射最小值一致 |
| 真实n与旧1500推断n混合 | 只有真实history中的n可作为首版前提 |
| 先于首次发现的真实no_signal | 后来已知同一固定源时仍能合法使用 |
| 已清源、Q4、未知频道 | 不进入该距离证书 |
| 扫描中15→16 | 剩余未知跳过，剩余已知继续原流程 |
| 整站零调用且已达16 | client状态/时钟/计数完全不变，不假称新增物理访问 |
| 部分真实调用后达16 | 真实访问与完整unknown覆盖证据分别记账 |
| 推断后再真实调用 | history、observed_positions及费用只记真实调用一次；推断不改变当前频道 |
| 中途真实请求失败/预算中断 | 不把未完成站加入完整发现集合，仍保留合法退出 |
| enabled=false | 与父基准逐动作、响应、费用相同 |

本次证书是一个有充分理论依据的静默查询删除机制。只有通过上述因果及执行核对之后，才适合冻结做配对实验；其平均收益大小与后续路线风险仍需实测，不能由几何不等式直接推出。
