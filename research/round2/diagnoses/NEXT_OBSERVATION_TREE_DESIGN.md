# 下一项独立试验：跨源与巡检的条件观测树

状态：只读设计，2026-09-11。没有建立分支、修改策略或开启任何案例，也没有读取 SQLite。当前确定性尾段验证继续，本设计不能作为新方法已有效的证据。

## 1. 要检验的差异

问题不是“搜索层数多就一定好”，而是：在同一生成模型、同一候选动作和同一完整收尾策略下，是否值得提前优化“看到不同反馈之后，下一次选择哪个源或巡检点”。

现有 `strategies/rollout.py` 是根节点宏任务 Monte Carlo：选一个 source/cover，随后由 `EfficientSearch` 完整收尾；它已有反馈驱动的尾策略，并非以后完全不看反馈，但没有在模拟到达的观测分支中再优化跨任务选择。它的 `_Continuation` 不是目前基准 `RelocatingStateSearch`，因此不能直接拿旧 rollout 与新树比较并归因于树深。

现有 `planning/binned_probe_tree.py` 及 `strategies/binned_state_search.py` 已经按连续误差落入角度箱的概率构造观测分支，分支里继续选探点，但作用域是一个已知源的局部测量。它不是没有观测树；缺少的是涵盖多个已知源、未知频道存在性和未访 cover 的共同决策状态。

建议首版保持宏动作边界：一个 `cover` 执行原 `_scan`，一个 `source` 执行原 `_resolve`，两者完成后再选下一任务。不加入单次测量中断，不另改几何清除点，也不混入刚完成的尾段优化。这样不重新引入此前反馈插队的承诺与进展问题。若这种窄树失败，不能据此否定今后更细动作边界的树，但应先停止该首版。

## 2. 三组对照及真正的公平条件

|组|真实执行基类|额外模拟选择|模拟叶子的完整尾策略|
|---|---|---|---|
|A：v1|冻结 `8c624d0` 的 `RelocatingStateSearch`|无|不适用|
|B：新模型 root MC|相同冻结 v1|根节点选一次宏动作|完整冻结 v1|
|C：两层条件树|相同冻结 v1|根动作后，按完整观测历史分支，再选择一次宏动作|完整冻结 v1|

B 与 C 共用候选生成、先验、似然、真实历史过滤、分支客户端、v1 克隆、接纳门槛、失败规则与随机数调度。B 与 C 的唯一区别是模拟中的第二次任务选择由完整 v1 或条件树优化。A 用来检验整项改动是否优于现有方法；C 对 B 才主要回答增加条件层是否值得。不能把更好的尾策略、更多采样或新候选的效果记在树结构名下。

每个真实调度边界，先在实时 v1 上调用一次原 `_next_task(remaining)`，取得基准动作并保留该次实际发生的 cover 重定位、展开预算和日志变化；随后制作不可变快照。B/C 的所有候选共享这个快照。不得在 live 对象上为每个候选再次调用父 `_next_task`，否则未执行 cover 会被反复移动。候选上限先取 3：基准动作、一个最近的其他已知未清且未 blocked 源、一个原 remaining 中的 cover；缺某类时以确定性距离/频道次序补齐另一类。不得产生新 cover，也不因某个假想真值增加动作。内层使用同一规则，在其条件观测快照中生成最多 3 个候选。

实际只执行被选的第一个宏任务，完成后按新的真实反馈重新建树。两层指 `a0 -> 完整观测串 z0 -> a1(z0) -> 完整观测串 z1 -> v1尾`；不是同一世界下枚举一条事先不随反馈改变的两步序列。B 的完整 v1 尾也会自然利用后续观测，不应将 B 描述成盲目开环。

## 4. 隐变量、似然与固定误差

一个假想世界包含频道存在集合、每源位置 `s_c`、固定接收半径 `R_c`，以及对新测量键惰性生成的固定误差。先验先延用公开写明的研究假设：N 在 10..16 均匀、同大小频道子集均匀、位置在区域内面积均匀、R 在 [1000,1500] 均匀。它们不是官方发布的生成分布；不得从验证库拟合。

对活跃频道在位置 p 测量，d=||s_c-p||。不存在或 d>R 时 `no_signal`；存在且 d<=5 时 `near`；其余接收范围内为 `direction`。同一源在所有观测中共享一个 R，不能每次测量重抽半径。清除结果由 20 米规则决定，成功后该源后续静默不再作为原位置的负约束。

本地 `simulation.engine._quantize_bearing` 的研究约定是：误差 e 位于 [-1,1]，方位加误差后取百分之一度，并在边界按该函数修正，保证最终误差界。对一个新键 `(channel, x, y)`，若 theta 为世界中的真实几何角度、b 为报告方位，应计算

`L(b | s,p) = length({e in [-1,1]: Q(theta,e)=b}) / 2`。

初版可在相关两度范围内枚举量化断点并积分分段常值 Q，包含 0/360 回绕和边缘修正；不以“附近最近粒子”或任意高斯核代替该概率。区分研究模型的精确量化概率与真实模拟器未核实的舍入细节。若将来改成观测箱 B，必须用 `sum_{b in B} L(b|s,p)`，同时用覆盖整个箱的安全假想几何；不能把箱中心当精确读数而切掉支持。

历史后验权重乘以每个不同有效测量键的似然；已重复的同点读数只检查一致性，不再独立相乘。键需按协议/当前客户端实际浮点坐标规范化（包括 signed zero），不要复用 `observed_positions` 六位小数的防重复近似作为物理键。已知键的未来反馈是缓存中的点质量；不能靠复测把同一固定误差平均掉。同点不同频道是不同键，已清频道静默优先。

当前本地环境从 seed 与精确坐标哈希得到固定误差，而已有 branch 用新 seed 再 anchors 过去。即使理想哈希近似独立，也不能说这是严格条件化原 seed。新研究模型应明确用“不同新键独立均匀、同一键固定”的惰性随机场；这是可计算的近似认识模型。采样器的内部伪随机 seed 仅用来复现自己的计算，与真实案例 seed、编号隔离。决策器不能取出世界中的真位置直接定动作；世界只交给生成器、似然计算与事后模拟费用评估。

## 5. 宏动作观测、粒子退化与树节点

source/cover 宏动作可能产生很多条反馈，而且测量点会随着前面的反馈改变。其输出 z 必须包含宏动作内按顺序发生的全部新测量/清除结果，以及可以由该观测历史重现的实际动作路径。宏动作似然按这条固定观测历史中各首次测量键的条件概率相乘，清除/接收种类不相容的粒子权重为零。不能只使用最后一条 bearing，也不能把原策略依赖前面反馈作出的动作当额外独立证据。

移动位置、宏动作何时结束和累计费用是已有动作及反馈的确定函数，只作一致性核对，不再独立乘一个“时间似然”或“路径似然”。32个乃至64个整局联合世界均可能在多频道观测后退化，增加到64不是解决方案或统计充分性保证。

一个观测子节点保存：该代表观测历史对应的公开快照、完整 z、加权世界集合、访问数与候选价值；不是“恰好产生 z 的一个世界”。其他假想世界也按上述整段似然加入此节点的后验，重新在代表公开历史上继续。第二层动作必须对这个共同后验选择，禁止对每个世界先知道源位置再各选最优动作后求平均；后者是先知式估值，会夸大观察价值。

初版采用有限动作与观测渐进扩展，不必先实现连续动作 DPW。每个动作的代表观测子节点数上限为 `min(4, max(1, ceil(sqrt(visits))))`。允许扩展时，从当前后验生成一份完整新观测串；达到上限时复用已有节点，按节点访问形成的经验概率抽取，并对新世界计算该代表串似然、加入加权粒子。该经验分支近似必须记录，不能称4个分支已枚举所有未来。若实现者不采用标准 POMCPOW 的具体选择/权重步骤，就应命名为“有限加权粒子观测树”，不能直接贴上完整 POMCPOW 的正确性结论。

最危险的情况是多频道 cover 输出包含多条窄量化方位，似然乘积使节点只剩一个有效世界。每次更新用 log weights，记录 ESS=`(sum w)^2/sum(w^2)`、最大归一权重、不同位置/频道集合支持数。建议初版门槛：树子节点至少4个不同世界且 ESS>=4；只重复拷贝同一个世界不能满足不同支持数。

不足时只允许一次有界的、从该节点完整历史重新条件采样的补粒子尝试：复用每频道几何提议与共同R区间，再使用同一量化似然校正；频道数量/存在组合仍按共同条件模型采样。系统重采样本身不能创造新支持。补采样耗尽、全零权重或不相容时，该节点使用原 v1 尾，记录 `child_belief_degenerate`；不能扩大误差界、删去负反馈、注入真实源或把单粒子当已定位。若整次规划未实际形成至少两个有效观测子节点，且未在至少一个子节点完成第二层候选比较，就记录“树未生效/回退”，不算已检验条件树机制。

按频道条件增补是可行的结构：给定存在集合后，声明的独立源先验与每频道观测似然可分解。已知源在其完整方向/正负反馈条件区域内提出新位置，按共同R的可行区间和量化似然校正；仅负反馈的未知频道保留其存在证据，先用联合N/子集条件模型抽存在集合，再抽各源，不能改成20个独立Bernoulli。已有 `q3_belief._pool/_radius_interval` 可作为提议器骨架，但新的似然必须与提议权重一致，避免将同一历史似然重复相乘。宏动作跨频道的控制路径不会破坏这一似然分解，因为给定完整反馈历史后各测量位置已经固定。固定噪声跨键独立的假设仍是模型前提。

进入性能实验前的阻塞条件：需要在不调用真实源的人工观测树中证明条件增补与似然归一正确、同点不会重复计权、宏动作后仍有足够的不同有效支持，且预算内至少有一次有效第二层。如果暂时只能把 `_Continuation` 加一层递归而没有这些能力，应停止在模型实现验证阶段，不能为“先跑出首版”跳过。支持不足后的v1回退是安全行为，不是完成了观测树试验。

## 6. 有限计算预算与小样本选择偏差

下面是建议冻结前的初始资源上限，不是已测试配置：根支持64个世界；每节点最多3个动作；每个动作最多4个代表观测子节点；深度2个任务；每个真实决策最多96次完整v1尾评估、40,000条生成器动作和12秒规划；整局最多8次规划、512次完整尾评估、160,000条生成器动作及90秒。任一上限先到即停止，低于10秒真实剩余时限则不规划。截止检查要深入采样、宏任务和每条假想动作，不能仅在整尾外检查。

B/C 使用完全相同的上述上限；B 可把不建子树省下的预算用于更多根估计，这是同计算预算下的合理比较。不能暗中要求两组粒子数、完整尾次数和墙钟同时精确相等——每次模拟尾长不同，往往做不到。主比较固定相同资源上限并逐局报告实际消耗；另列同完整尾评估次数下的结果。固定 v1 A 不强制耗掉这些资源。若最小有效第二层在预算内总是无法形成，应报告 Python 完整尾代价造成的资源不可行，而非悄悄提高 C 的时间预算。

根候选在同一假想世界和同一新键误差随机场上配对，降低比较噪声。不同真实策略跑到不同历史后无法继续强行共享同一后验样本，此时仍使用相同的采样算法和预算即可。不要用搜索序号变化导致的不相关噪声解释收益。

需避免“在同一小批世界挑最好第二层，再用它们报告根价值”的乐观偏差。建议在每个代表观测历史z的条件后验内，把预算预先分成约一半世界选a1(z)、一半新条件世界评估已经选定的a1(z)，后者不回流改该节点动作；根价值按预定代表观测权重汇总。B同样保留采样分组，避免因独占更少验证成本造成比较口径不明。这是条件分层MC评估，不是用独立整世界碰巧再次产生完全相同的连续观测串；精确重现同一高维串的概率极小，不能依赖这种拒绝法完成复核。若条件采样做不到，此复核同样属于阻塞项。

只执行根动作后就重新规划，因此不需要把有限代表节点硬套到将来的真实连续观测；真实反馈必须重新过滤建树。有限代表节点仍只是观测积分近似，分支概率、低支持回退权重及不同树重复估计的方差均应报告，不能只展示有利分支。条件样本分组并未消除根动作择优偏差，也不是外部独立确认。若首版只能做自适应树值估计而无法留出上述条件复核预算，则应显式降格为偏倚估计并更依赖外部配对评估，不作贝叶斯最优主张。

候选接受规则 B/C 相同，例如沿用旧 rollout 的“配对均值改善超过10秒并减去0.5×标准误差”的固定工程门槛；这不是置信下界，尤其在 ESS 小、相关粒子和多动作择优时。门槛应在开新开发案例前冻结，不能根据胜负连续调低。硬清除与终止仍完全依赖原几何/覆盖证书；模型概率仅影响任务次序。

价值目标为从当前真实状态到完整清除并退出的无折扣总虚拟成本，`gamma=1`；包含实际移动、换频、测量、成功或失败清除的全部已计费动作。禁止使用gamma<1让拖延的清除成本折价。模拟未完成或预算耗尽用不可接受/正无穷标记并保留基准，不能只收已走短前缀。若后续需要有限失败惩罚来支撑某个求解器，必须在有证明的完整成功成本上界之外设置并冻结，同时把清除失败率单列；本首版无需此额外设计。

## 7. 必要实现测试与最小评估闭环

在跑性能案例前，至少验证：

1. 同一公开快照的克隆 v1 尾逐动作等价；覆盖重定位、剩余预算、inferred silence、共享测量、near/持证clear、blocked、16源停止和显式退出一致。开关关闭完整轨迹等同v1。
2. 在人工固定小世界上枚举量化误差区间，似然归一且符合生成频率，测试角度回绕、±1边缘、no_signal共同R、near、已清频道与同点缓存。重复100次同键不增独立似然，不缩小误差。
3. 两个可产生同一观测历史的世界必须在子节点共存；由不同观测形成的节点能选不同的下一源/cover；同一观测不能按世界真值选择不同动作。以小的可手算2层树验证备份费用等于树策略期望，而不是逐世界最小值。
4. 一个 cover 返回多频道正负反馈时，全部反馈参与子后验；一粒子/全零权重/补采样超时正确回退，不伪造证书；历史、剩余 cover 和真实 client state 在规划前后没有预测副作用。
5. 预算按生成器实际动作及完整尾评估计数，强制超时保留exit；不完整尾不能低价获胜。测试相同随机场配对与分支缓存隔离。

通过后才由根任务另分配从未打开的新开发案例，预先固定三组配对协议。先报告机制覆盖：根改变率、有效第二层比例、不同观测导致不同宏任务的次数、ESS分布、补采样/超时回退、树深与完整尾评估量。若 C 很少实际拥有第二层，先诊断资源/退化，不把它当树方法已输。

整局报告完整清除率、failed clear、平均/P90/最坏虚拟时间、逐局T/LB、CPU与墙钟、配对差值区间；T/LB继续使用本项目既有先知理论下界并明确非在线近似比。模型改动导致 B 与 A 的差异、条件树带来的 C 与 B 的差异须分别列出。只有开发证据足够才冻结候选并开启新的独立确认；不能用同批调模型后再称独立确认。官方只允许演练，实际案例真值只用于根任务许可的事后指标计算，不进入决策或训练。本设计不使用验证 SQLite 的分布或内容。

## 8. 文献支持及不能承诺的内容

POMCP 把搜索放在动作—观测历史上，并以模拟完成在线选择；它不是训练一个AlphaGo式神经网络。[Silver & Veness, 2010, 原论文](https://papers.nips.cc/paper_files/paper/2010/file/edfbe1afcf9246bb0d40eb4d8027d90f-Paper.pdf)

POMCPOW 的关键启示是连续观测下仅做渐进扩展会使树内信念退化，必须处理观测似然与加权粒子；增加层数不能自行解决这个问题。[Sunberg & Kochenderfer, 原论文](https://arxiv.org/abs/1709.06196)

这里仍是有限世界、有限宏任务、有限分支、有限深度与有限完整尾预算的近似在线规划。固定但未知误差场的建模、官方生成分布和宏动作高维观测都可能引入系统偏差；更多模拟只能降低给定模型中的数值误差，不能消除模型偏差。现有v1已经在真实反馈后滚动重规划，因此新树可能只得到小收益，也可能增加CPU、发生错误调度并使整局更慢。值得检验的是上述特定可复现差异，不能承诺两层优于根MC，更不能据文献直接保证本题接近理论下界。
