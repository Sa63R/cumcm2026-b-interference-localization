# 冻结观测树的统计局限、计算成本与后续可检验假设

只读审查冻结实现 `a876e595d14fdf067852ddf54078aa99292de9ca`。本报告没有修改候选、运行新性能案例、读取 SQLite 或新 pilot 结果。数值仅来自已经打开的旧开发案例 200114 的机制烟测；它们不是独立性能证据。参考 [文献适配判断](../LITERATURE_ASSESSMENT.md)、[审核合同](OBSERVATION_TREE_REVIEW.md)及既有状态搜索诊断。

当前实现确实执行了未来观测后的第二次任务选择，但仍是**有限代表观测的两层条件 Monte Carlo**，不是完整 POMCPOW。最明显的限制是两个外层预测代表、每个子节点两个训练和两个独立计价世界，以及只在前三个合格宏动作边界尝试规划。未发现连续位置提议、共同接收半径和联合源数量计算中另一个漏乘或重复乘先验因子的结构性错误；有限池误差和声明模型与实际环境的失配仍然存在。

## 1. 现在究竟比较了什么

主要入口是 `q3-r2-observation-tree/src/strategies/observation_tree_state_search.py`；参数以该分支两个冻结 experiment spec 为准。

| 项目 | B：root_MC | C：两层观测树 |
| --- | --- | --- |
| 根候选 | 基准宏动作加至多两个其他宏动作 | 相同 |
| 预测信念 | 完整历史条件下抽 16 个世界 | 相同 |
| 外层观测积分 | 从这 16 个世界有放回抽 K=2 个代表，等权积分 | 相同 |
| 每个完整观测 z 后的条件采样 | 两个独立随机流各抽 8 个世界 | 相同 |
| 子节点动作 | 原 v1 选择 | 用第一流前 2 个世界比较至多 3 个动作 |
| 子节点独立计价 | 每流前 4 个，共 8 个世界运行 v1 尾 | 用第二流前 2 个评价已经选定的动作，再接 v1 尾 |
| 每节点完整尾次数上限 | 8 | 3×2+2=8 |
| 每次完整比较上限 | 3 根动作×2 代表×8 尾=48 尾 | 相同 |
| 本次冻结预算 | 每次 90 秒、40000 条内部 measure/clear，整局最多 3 次、270 秒 | 相同 |

因此 B/C 是**相同任务集合、概率模型及资源上限下的两种计算分配**，不是“增加第二层以后仍保持同等估值精度”的纯因果对照。B 的 8 次计价和 C 的 2 次训练/2 次计价不能统称为“每节点 8 个有效评估样本”。C 的 6 个训练尾包含同 2 个世界上的多个动作，不是 6 个独立世界。

正常完成六个子节点时，共调用一次根采样和十二次条件采样，输出 16+12×8=112 个世界。实际尾评估仍最多 48 次，外层观测仍只有两个；112 不能作为根决策的独立样本量。C 每个子节点另外 12 个未运行尾策略的世界提供的是支持检查，不提供尾成本信息。

`max_searches=3` 限制的是前三个发生记录的规划尝试，回退同样耗用一次机会。没有按新信息、预测不确定性或预期决策价值来分配时机。200114 烟测为 `max_searches=1`，只覆盖中心首轮 20 次测量后的机会；不能凭它推断第三次规划也能在相同时间内结束。

## 2. 两个外层代表限制了什么

每个根动作的估值是

\[
\widehat Q(a)=\frac12\sum_{k=1}^{2}
\left[c_0(a,z_k)+\widehat V(z_k)\right].
\]

16 个根世界并没有全部生成并计价观测；实际只有两个代表。若某类重要反馈在模型下概率为 10%，理想独立两次抽样就有 81% 概率两次都看不到。实际还经过有限根池，因此这只是解释抽样稀疏性的例子，不是本批场景的事件概率估计。16 个等权且不同的根世界中，有放回抽两次抽到同一世界的概率为 1/16；重复必须保留积分重数，但不能算成两个不同反馈分支。

相同代表被用于不同根动作，这是有效的共同随机数配对。不过各动作产生不同 z，随后条件池使用不同随机流，配对并未消除后缀估值噪声。根估值同时受到“哪些反馈被抽中”和“给定该反馈后尾代价估得怎样”两层误差影响，C 还多一层“两训练世界选错动作”的误差。

固定门槛为 `mean_gain - 10 - 0.5*SE > 0`。K=2 时，两个配对收益 g1、g2 给出的 SE 恰为 `abs(g1-g2)/2`，所以门槛为 `mean_gain - 10 - abs(g1-g2)/4`。它只是启发式防抖，不是置信下界，不提供多候选比较之后的错误接纳概率保证。两次代表偶然一致也不证明缺失的反馈分支不重要。

条件计价与子动作训练已经分流，排除了“同一 world 选动作又在该 world 宣称验证”的明显错误；但这份计价值随后仍参与根动作的选择。因此“独立计价”只针对该子动作的训练，不能称为对最终根赢家或整局策略的独立验收。

## 4. 计算成本：知道什么，不知道什么

| 同一旧开发烟测 | 规划墙钟 / 秒 | 已启动尾评估 | 内部 measure/clear | 完成子节点比较 | 结果 |
| --- | ---: | ---: | ---: | ---: | --- |
| C v0，optional 尚会提前停止，60 秒上限 | 50.683463 | 48 | 4531 | 6 | 完成，1 次子动作改变 |
| C 固定 optional 4096，60 秒上限 | 60.048584 | 44 | 4294 | 5 | 尾执行中到预算，整体回退 |
| B 固定 optional 4096，60 秒上限 | 56.011987 | 48 | 4686 | 0 | 完成 |
| C 固定 optional 4096，90 秒上限 | 53.273339 | 48 | 4721 | 6 | 完成，2 次子动作改变 |
| B 固定 optional 4096，90 秒上限 | 52.490143 | 48 | 4686 | 0 | 完成 |

记录入口为 `results/round2/observation_tree/model_smoke/`。60 秒中断记录保留为预算可执行性证据；90 秒组是冻结前调整资源后重跑的同一个旧案例，不能算新样本。墙钟受并发和运行条件影响，v0→固定4096还改变了随机流消耗、假想世界和尾轨迹，因此不能把两行墙钟之差全部归因于采样。

根据代码能确定以下成本来源，但目前没有分阶段 profiler 可给出各自百分比：

1. **完整 v1 尾的重复执行。** 一次完成比较最多跑 48 条完整后缀。每条还包含原定位几何、路线搜索、覆盖重定位及证书计算，并非一次廉价价值函数调用。约 53 秒除以 48≈1.11 秒只是包含全部规划开销的摊销量，不能称为已测得的单尾耗时。
2. **每个 z 两次从完整历史重建条件池。** 有负历史的 optional 池固定 4096 次先验提议；mandatory 池通常首批 256，不足才补 3584，每个位置需检验共同 R 和所有首次方向似然。两组都承担这些成本。相同频道历史在一次采样调用中共享缓存，不能把日志每个频道的 proposals 直接相加当实际采样次数。当前 trace 没有实际缓存命中和分阶段用时。
3. **快照、历史重建和复制。** `observation_continuation.py` 在 capture、实例重建、history 属性及宏动作结果中 deepcopy；完整尾会不断产生宏边界快照。后续真实规划还带着之前的报告和诊断。现有数据不足以断言复制是主瓶颈，但它是明确的额外工作，首次机会烟测不能标定三次机会总成本。
4. **部分比较无法兑现。** 若最后一条尾超时，已完成的前面比较不会被拿来临时挑赢家，而是整体退回 v1；这保证了保守性，但会出现几十秒计算后没有实际动作改动。应独立报告这类计算浪费，不能将回退后的全清成功率算作树机制有效率。

4096 是为去掉 optional 证据的自适应停止偏差而固定的估计规则，不是从本批性能结果调出的最优粒子数。后续若要减少该成本，需要另行给出可校验的证据估计方法；不能悄悄恢复“抽到几个支持点就停止”。

## 5. 连续位置提议和先验校正的复核

对频道 c，令 x 为源位置，I_c(x) 为所有正负接收反馈共同约束的 R 区间；同时检验近场、清除成功/失败等确定几何条件。独立有效方向键集合为 D_c。位置边缘的未归一权重是

\[
h_c(x)=\mathbf1_{\text{确定几何相容}}
\frac{|I_c(x)|}{500}
\prod_{j\in D_c}P(Q(\theta_j(x),E_j)=b_j),\quad E_j\sim U[-1,1].
\]

重复同点键不再进入乘积；已清除后的静默不限制原源位置。完成完整反馈历史后，自适应测点由之前反馈及控制规则确定，不另乘一个“选择这个位置的概率”。

- `q3_belief.py:_proposal_polygon/_polygon_sampler` 在保守凸多边形 P 内按面积均匀提议。多边形的外包圆、方向带和正负点距离半平面只用于保留合法支持，接受时仍检验真实 1800 米圆域、共同 R 和精确本地量化似然。距离比较半平面使用的是 `distance(x,positive)<distance(x,negative)` 的正确方向。
- mandatory 提议密度为 `1/area(P)`，原先验密度为 `1/(π·1800²)`，重要性权重需乘 `area(P)/(π·1800²)`。该常数在一个频道位置池内自归一时消掉；当前 `_conditional_pool` 计算绝对 evidence 时也记录了该面积比，没有漏掉径向面积因素。
- 给定 x 后，R 从同一个相容区间均匀抽取；先前位置权重已包含区间长度/500，因此不是“把每个截断区间都按同样概率看待”的错误。no_signal 的上端严格排除。
- optional 只有负观测，使用原圆域面积均匀提议。其存在证据 q_c 用固定 4096 次的完整平均，拒绝计零；无源情况下这些负观测的似然为 1。源数量 N 的权重为 `e_(N-|M|)(q_optional)/choose(20,N)`，其中 M 为必存在频道集、e 为基本对称和。所有 mandatory 的证据常数共同相乘，确实在 N/子集比较中消掉。没有将 20 个存在状态错误拆为独立 Bernoulli。

相关实现位于 `q3_observation_likelihood.py:187、257、309`，解析/人工校验位于 `tests/test_q3_observation_likelihood.py`。本次只读复核未发现需要打断冻结试验的新增校正 bug。

仍须保留四类限制：有限自归一重要性采样不是精确后验；支持阈值不能证明没有遗漏狭窄/分离模式；声明的面积均匀、R均匀及独立固定键噪声不是官方已知分布；支持不足回退后的“成功返回样本”不能被当作无条件无偏抽样集合。mandatory 的支持触发扩样及有限 optional 证据进入非线性 N/子集归一也仍有有限样本误差。

此外，已清源仍被重新采样并要求位置池支持，尽管它们未来不再发射，且其必存在证据不再影响其余源的相对 N 权重。这是可能多余的计算和保守拒绝，不是当前权重错误。若以后消去该状态，应先证明对未来公开轨迹的边缘化等价，并保留历史相容证据；不能简单塞入不相容的假位置。

## 6. 三条后续假设；不做粒子数/阈值扫表

以下都只是冻结 pilot 之后可选择的单机制研究，不要求三条都实现；不得用新 pilot 结果反复调成通过。

**H1：当前部分“树评分变化”主要是未配对的尾均值噪声，评价相对 v1 的配对优势会改善辨识力。** 已有烟测六个节点已经提供直接诊断：不改动作的配对差严格为零，而不同样本数的绝对均值能相差数百秒。先在已经打开的 B/C 同历史节点统一提取 `cost(chosen,w)-cost(v1,w)`，统计训练与独立计价的方向一致性；这不需要新性能运行。若有下一版，只测试一个明确的配对增量估值/接纳机制，同时为已选动作与 v1 支付必要完整尾费用，记录真实额外计算，并给 B 相同资源上限；不能把多跑的尾隐藏成免费降方差。如果配对后仍没有可靠正优势，就不应优先加深树或降低门槛。

**H2：前三次连续宏边界不如三个公开新信息事件有价值。** 保持三次调用和相同单次预算，另一个固定方案只在“刚完成的覆盖扫描发现新源，且同时仍有已知未清源和未访覆盖站”后的宏边界启用；其余时刻继续 v1。比较实际机会覆盖、回退率和整局费用，不按场景编号或事后误差选时机。如果这类事件本来就很少，或新信息时规划仍不能稳定改变有利动作，则该调度假设应停止。依据是旧 [结构瓶颈诊断](../../state_search_v1/STRUCTURAL_BOTTLENECKS.md)中大部分顺序损失发生在发现未结束阶段，而非已知固定点的排列未算精确。

**H3：三候选的家族分配遗漏了有价值的已知源替代。** 当前 `macro_candidates` 在基准为 source 且仍有至少两个 cover 时，另外两个候选都来自 cover；它不会同时比较另一个已知源。基准为 cover 时则优先放入两个 source。可固定改成“基准＋最近的另一类任务＋最近的同类不同任务”，不足时才补齐，仍为三候选、同模型和相同尾预算。检验改变是否改善不确定源目的地与发现时机的取舍，而不是增加候选数。若同类替代仍没有稳定独立优势，就不扩展为更多邻近点扫描。旧冻结 TSP 大多已经界闭合，不支持以加大同一有限搜索预算代替这个信息假设。

更细的“测一次后重新选任务”与真实 POMCPOW 渐进扩展不在这三项小研究内。当前 source 宏动作仍完整执行 `_resolve`，中间得到信息也不暂停；因此它看不到一些中途信息获取/抢占机会。但旧反馈插入方案已经经历 64 对开发后停止，详见 [反馈扩展诊断](feedback_coverage_dev_diagnosis.md)。未来若重新研究细粒度控制，必须另建动作语义和进展/恢复约束，并用新的完整条件成本模型评价；不能把旧插入规则换个名称再次测试。

## 7. 什么时候可以停止，结论应怎样写

| 观察到的证据 | 可以说 | 不能说 |
| --- | --- | --- |
| 大量零支持、采样/尾超时，第二层未完成 | 这份条件采样与完整尾实现不适合当前计算预算 | POMCPOW 已被完整检验且无效 |
| 第二层确实生效，但小批均值区间跨零或严重依赖少数局 | 当前实现尚无可靠改善证据，可因研究价值不足归档 | 已证明观测条件规划不能改善本题 |
| 冻结独立复核显示完整清除不退步，但均时/尾部持续恶化 | 当前模型、候选、K=2及预算配置的组合不宜替换 v1 | 当前 v1 理论最优，或全部强化学习/搜索方法无用 |
| 新树优于 v1，但没有优于同资源 B | 新模型/完整尾或候选可能有帮助，第二层额外价值未得到支持 | 改善已被归因为观测树深度 |
| 新树优于 B 且独立复核、可靠性及计算成本均通过 | 这份有限宏动作条件规划有经验改善证据 | 已完整复现 POMCPOW，或逼近未知信息下的理论最优值 |

POMCPOW 的带权观测信念、访问驱动扩展与多层树搜索没有在这里完整实现，相关文献保证的前提也没有在本题全部建立。另一方面，承认方法族未被否定不等于必须无限研究；在固定预算、完整且有效的机制覆盖之后，证据不足或计算成本过高，已经足以停止这一个候选。应将“实现不可执行”“可执行但无可靠改善”“预算用尽”和“理论不可改善”分开记录。
