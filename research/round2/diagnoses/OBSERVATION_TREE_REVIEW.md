# 条件观测树：独立执行与信息约束审核合同

审阅对象：`NEXT_OBSERVATION_TREE_DESIGN.md`，独立试验树 `q3-r2-observation-tree`，基准 `8c624d0`。当前仅审核设计，没有运行性能案例、SQLite、官方接口或候选策略。实现冻结后按本合同独立测试。下列条件未满足时，应停在模型验证阶段，不能用大量回退到v1的成功局宣称已验证观测树。

## 最关键的五个风险

1. **有限代表观测的概率尚未被唯一规定。**‘从预测分布抽代表’、‘按访问次数复用代表’和‘对代表乘似然’是三件不同的事。自适应访问频率不天然等于真实观测质量；已按预测分布抽来的代表若再按该代表的发生概率加权，会重复偏向高概率观测。若保留渐进扩展，必须明确代表的抽样分布、重复观测的重数、每次备份权重和访问计数的含义。
2. **第二层逐世界择优会变成先知。**同一完整观测串对应一个共同公开状态，必须只产生一个动作 `a1(z)`。允许不同z选不同动作；不允许相同z因为计价世界的真位置不同而选不同动作。只有生成器和似然函数接触隐藏世界，候选生成、路由与动作选择不能接触。
3. **条件独立复核必须是真的条件采样。**不能挑完动作后，用训练world再算一次费用当复核；也不能把不满足z的新world强行装上z的反馈anchors。高维精确宏观测串的整world拒绝采样几乎不可执行。若每频道条件增补无法在预算内产生足够独立支持，则这份设计在该预算下没有实现，而非树方法效果不好。
4. **提议分布和似然容易重复或漏计。**从方向带/共同R区间内提议时，其提议密度、截断归一常数与观测似然必须一并处理。已经从历史后验抽样的world加入新z时只乘增量似然；从先验提议的world应乘完整唯一键历史似然。两者不可混用。
5. **宏动作的完整路径、费用和快照必须一致。**source宏动作可能因观测不同产生不同后续点、测量数或clear结果；cover包含多个频道。z必须是整个实际宏动作轨迹，不能仅用最后一条方位。条件计价从z结束后的公开状态起步，根宏费用加一次；不能重跑a0并取得另一条反馈后还称在原z节点计价。

## 推荐先冻结的可执行估值口径

首版可采用固定有限代表，而暂不使用访问频率驱动的观测扩展。对每个根动作a：

1. 用根后验及生成器独立产生K次完整宏观测 `z_k`，得到实际宏费用 `c0(z_k)` 和其共同公开快照。抽到相同z的次数保留为重数；这些是预测分布的Monte Carlo样本。
2. 对每个z，用一批**新**的条件world `T_k ~ p(w|H,a,z)` 选出唯一 `a1(z)`，候选集合仅由该z公开快照产生。代表生成world不要自动加入选动作和计价两批。
3. 在选择完成后，用另一批新条件world `E_k` 计价固定的a1，并运行完整v1收尾。E不能回流修改该节点动作、阈值或候选集合。同一z的各候选可在T内配对，E只用于已冻结动作的后缀费用。
4. 根估值为 `K^(-1) Σ_k [c0(z_k) + V_eval(z_k,a1(z_k))]`。这里无需再乘代表的发生概率；分布已由代表抽样体现。若预先枚举了有明确概率质量的互斥穷尽离散观测，则才用 `Σ_z P(z|H,a)V(z)`。
5. B组使用同一条件快照和条件评估机制，第二层动作固定由v1产生；C才用T优化a1。两组均按完整结束费用计价，不能让B承担了C没有承担的采样验证开销，或把不同叶策略收益归因于树。

这是一种有限条件分层MC，不是POMCPOW的复现证明。每代表最多4个、宏观测又高维时，估值方差可能很大；固定K解决权重定义问题，不保证采样充分。如果root选择别的方式，需要给出同样清楚且可运行的小树备份公式再通过下列测试。

### 条件计价的具体接口边界

`choose_child(public_snapshot, weighted_training_worlds)` 产生一次动作ID；`evaluate_fixed_child(public_snapshot, chosen_action, evaluation_world)` 接收已经固定的动作。计价接口不应含‘为当前evaluation_world再选一次动作’的入口。生成器可接收evaluation_world，但用于模拟反馈；它不把源位置、真实N、R、world ID或未来缓存误差交给策略。

条件world在代表z之前的每个首次键都须具有正似然，并缓存该代表真实反馈；已知键重测直接使用条件缓存。对真实源相容但量化噪声不相容的world也必须拒绝。新的后缀键使用该world自己的固定随机场。同一模型world内给不同候选共享键值，执行次序不能改变某个新键的误差。

宏费用对同一z是确定的，不能既含在clone的累计virtual_time差值中，又在根备份额外相加。推荐明确 `root_start_us`、`macro_end_us`、`leaf_exit_us`，核验总增量等于这两个不重叠区间之和。gamma=1，所有失败clear也按实际费用累计；未完成/未exit的模拟值不可用作便宜候选。

ESS、不同支持数须分别记录根、子节点支持池、实际子训练集、实际子计价集。一个含8不同world的集合在分成训练/计价后，不代表两组各自ESS均≥4；最终实际用于估值的条件样本和权重也必须检查。‘节点池ESS≥4’可以作为生成信念的门槛，但不能据此描述实际2个world估值也有ESS≥4。测试2-world代数核对时可直接测试纯备份函数；生产触发测试至少构造4个不同物理支持以覆盖所声明的节点池门槛。

## 可直接运行的2-world/2-action代数核对

下面纯Python代码只使用人工数表。实现完成后，适配器应把同一张表交给真实树备份/选动作代码，并保留这些精确期望作为独立oracle；仅运行这段oracle本身不能证明策略通过。

```python
from fractions import Fraction as F

# W_L/W_R 等概率。动作L在W_L花0、W_R花10，动作R相反。
prior = (F(1, 2), F(1, 2))
costs = {"L": (F(0), F(10)), "R": (F(10), F(0))}

def posterior(likelihood):
    weights = [p * likelihood[i] for i, p in enumerate(prior)]
    mass = sum(weights)
    return mass, tuple(w / mass for w in weights)

def choose(weights):
    values = {a: sum(weights[i] * c[i] for i in range(2))
              for a, c in costs.items()}
    action = min(values, key=lambda a: (values[a], a))
    return action, values[action]

# 未提供信息：同一个z必须选同一动作，不能逐world偷偷各取最优。
_, uninformative = posterior((F(1), F(1)))
assert choose(uninformative) == ("L", F(5))
clairvoyant_wrong = sum(prior[i] * min(c[i] for c in costs.values())
                        for i in range(2))
assert clairvoyant_wrong == 0  # 必须与合法值5区分。

# 测量花1秒：z_L在两world的概率0.8/0.2，z_R为0.2/0.8。
root_value = F(1)
child_actions = []
for likelihood in ((F(4, 5), F(1, 5)), (F(1, 5), F(4, 5))):
    mass, belief = posterior(likelihood)
    action, value = choose(belief)
    child_actions.append(action)
    root_value += mass * value
assert child_actions == ["L", "R"]
assert root_value == 3  # 合法条件树3；无信息直接选动作5；先知伪值1。

# 只用一个训练world挑动作可得到训练值0，独立计价必须仍是5。
selected, train_value = choose((F(1), F(0)))
assert selected == "L" and train_value == 0
heldout_value = sum(prior[i] * costs[selected][i] for i in range(2))
assert heldout_value == 5

# 两条新键反馈的似然相反，完整宏后验0.5/0.5；末条独用会错。
first, second = (F(9, 10), F(1, 10)), (F(1, 10), F(9, 10))
_, macro = posterior(tuple(first[i] * second[i] for i in range(2)))
assert macro == prior
_, once = posterior(first)
_, repeated_wrong = posterior(tuple(p ** 100 for p in first))
assert once == (F(9, 10), F(1, 10)) and repeated_wrong != once

# 已按预测概率抽取代表，再乘一遍概率会把正确值1变为5/41。
p, values = (F(9, 10), F(1, 10)), (F(0), F(10))
correct = sum(p[i] * values[i] for i in range(2))
double_weighted = sum(p[i] ** 2 * values[i] for i in range(2)) / sum(x*x for x in p)
assert correct == 1 and double_weighted == F(5, 41)

# 同一固定R的联合证据不是每次各抽R。
assert F(1200 - 1100, 1500 - 1000) == F(1, 5)
assert F(1500 - 1100, 500) * F(1200 - 1000, 500) == F(8, 25)
print("人工代数oracle通过；真实实现还须接入同样数表并通过上述约束测试")
```

## 进入性能实验的审核结论门槛

必须同时具备：有可复现的完整条件后验校正；纯数表树值通过；生产ESS门槛下实际形成两个有效观测分支并至少一次第二层候选选择；clone无污染且v1逐动作等价；独立条件计价与完整费用通过；预算中断不会当成胜出。若只有fallback安全和清除成功，只能结论为‘基准回退路径工作’，不能结论为‘两层树已被检验且无效’。

以后整局实验仍需同冻结模型下A/B/C成组配对，给清除率、failed clear、平均/尾部时间、原口径每局T/LB、真实CPU/墙钟、机制覆盖及配对差值。条件评估消除的是第二层训练复用的部分乐观偏差；根动作择优、小K观测积分、自适应采样相关性和声明先验与官方环境不一致，仍需外部新案例检验，不能靠‘0.5个标准误’包装成统计保证。

## 根任务随后提出的有限预算修订

根任务已采纳固定K=2预测代表、等权积分，不使用自适应节点访问概率，也不称完整POMCPOW。当前实现阶段拟议：每根最多3候选，每z生成8个条件world；C用2个选动作world比较至多3个内层动作，再用独立2个world评价选定动作，即每z至多 `3×2+2=8` 完整尾；B用8个条件world评价v1尾。每组每次总完整尾上限因此同为 `3×2×8=48`。另拟每次60秒、整局3次/180秒。尚未冻结，不是已完成性能结果。

独立意见：这是成立的**同完整尾计算预算**对照，没有因C训练消耗也计入预算而产生结构性不公平，但不是相同估值精度。B每z计价8个，C计价2个，C方差较大；增加第二层的收益是否抵得上损失的估值精度，正是该同预算对比的一部分。不能把B/C尾次数相同写成各自有效样本量相同。

实施前必须落实以下约束：

- C的条件支持池8、实际训练2、实际计价2各自记录权重、ESS、支持数；未使用的4个不计为已完成尾或估值样本，但其采样开销仍计预算。2样本的ESS最多2；若另宣称每个实际估值集ESS≥4，则与这套预算矛盾。
- training和evaluation使用分离条件抽样流，不经过eval再选择代表或动作。若8个world是带权提议样本，应正确加权或按其权重抽样；不能机械取头2个等权。若两组由共享有限粒子池重采样，应明确‘给定该近似池独立’而非宣称精确后验的独立样本；同源重复支持仍须记录。
- 每次60秒上限还须取 `min(规划上限, 实际剩余时间-退出/通信裕量)`。仅在起点检查剩余大于10秒，无法保护一次长达60秒的规划。
- K=2时若用配对标准误作工程门槛，先按外层代表ID汇总每根动作的完整条件估值，再比较外层配对差值。不得把同一z下多个尾样本当作多个独立未来观测。仅2个外层样本的标准误很不稳，不能成为置信声明。
- 本修订没有降低信息隔离、完整宏似然、同键误差、完整收尾、真实clone无污染或实际机制覆盖要求。因预算无法产生有效子节点时，应记录为树未生效。
