# 冗余负反馈测量：冻结实验协议

本试验以受保护的状态搜索 v1（8c624d0）为基准，候选为独立分支 research/q3-r2-derived-silence 的 760af823。只改扫描时可证明没有新增信息的查询；不改基础路径搜索和定位算法。旧案例只用于实现检查，不作为独立效果证据。

## 两个独立机制

1. 相对距离证书：对已知未清除频道，当前源的保守外包多边形为 C。此前在同频道实际测得无信号的位置为 n，计划查询位置为 q。若对 C 的全部顶点 v，G(v)=(n−q)·(v−(n+q)/2) 严格大于安全裕量，则 |v−q|²−|v−n|²=2G(v)>0。仿射函数的顶点条件覆盖整个凸多边形，故未知源距 q 比距 n 更远；同一源的接收半径不变，因此 q 也必然无信号。生产实现逐操作使用向外舍入区间，独立审核使用精确有理数。不能用事后真值检查替代此前观测的证明。
2. 扫描中的数量上限：题面至多16个源。在一次扫描中实际发现第16个不同源后，后续尚未出现过的频道不再需要测量。已知未清除频道仍按原证据处理，不把整次扫描冒称完成了未知区域的实际几何覆盖。

推断反馈不写成实际测量，不增加真实观测位置或覆盖站计数。相对证书只使用此前实际同频道无信号，不使用推断链。若全部查询均省去，不虚构移动、时间或巡检站。清除与可靠终止须继续满足原证书审核；独立审核还删除新增相对推断，再运行旧清除及终止审核。
