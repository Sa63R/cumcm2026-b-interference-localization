## 2. “状态搜索”实际在做什么

它不是把整张地图离散成小格，再穷举所有真实世界。方法分为三个层面：连续几何保留哪些位置仍可能是真源；有限任务模型决定大致处理次序；收到真实反馈后更新几何并重新规划。完整代码核对见[基准算法说明](diagnoses/STATE_SEARCH_BASELINE_METHOD.md)。

### 2.1 真实观测状态：哪些信息不能丢

按频道维护源是否已发现、是否清除、保守候选区域、真实测量位置与反馈、near信息和负反馈历史；全局维护机器狗位置、当前接收频道、真实覆盖站、未来覆盖站及执行预算。一个频道最多一个源，使按频道分解自然成立。

测向误差是有界的±1°，同地点重复测量并非新的独立噪声。实际实现使用1.005°的保守角度包络，场地圆与1500米接收上界圆使用外切128边形；维护的是包含真实源的保守外包，不是精确后验或精确可行集。不会把重复观测平均后虚构更高精度。最小包围圆的圆心和半径是规划摘要，不是隐藏真值。

真实位置可能相同、已完成任务集合也可能相同，但观测历史不同的两局不能直接合并为一个信念状态。压缩的是下面的冻结代理任务子问题，完整在线几何信息仍要保留。

### 2.2 有限任务状态：把重复的排列前缀合并

将尚未执行的覆盖站与已发现未清源转换成有限任务。源任务以当前候选域的代表点近似位置；任务集合、位置和服务费用在一次求解中冻结。状态为

\[
S=(M,j),
\]

其中M是已处理任务的位掩码，j是最后一个任务。对这个冻结模型，同一(M,j)的未来可选任务与转移费用相同，较贵的前缀可以删除。相比排列枚举的阶乘增长，最坏状态规模为\(O(n2^n)\)，转移量级\(O(n^2 2^n)\)。实现按需展开，不会真的创建所有状态。

求解器用增量代理代价贪心与2-opt生成可执行的模型路线作上界；用“到未处理集合的最短入口＋该集合最小生成树＋固定服务费”构造剩余代价下界，进行有预算的A*搜索及支配剪枝。当前冻结配置每次有限路线求解最多100次展开，移站还会求解至多4个路线变体，整局60000次累计预算包括这些调用；不是无限算到完整真实问题的最优值。

这里有一个应当在论文里讲清的区别：**(M,j)在冻结任务模型内部是无损的历史合并；真实未知世界被表示为若干代表点任务时，则已经引入有损近似。** 不能将前者的正确性扩大成后者没有误差。

每完成一次完整覆盖任务或一个源的处理后重新建立任务模型。定位期间持续吸收真实观测，但不等于每个无线动作后都重新求全局路线。冻结spec中的`scan_source_s=0`，所以不能声称任务路线目标已经精确计算了“先清除一个源会少扫多少次频道”。这些真实效应由动作控制和整局实验检验。

### 2.3 几何测点：搜索为定位和清除服务

基准先考虑中心及8个横移点：在当前位置至MEC中心连线的中点与终点处，沿首测向的垂线向两侧偏移50米或150米。原9点有合法赢家时，常规加入14个主轴/分位候选，形成至多23点的集合；不是只有检测到定位困难才加点。只保留满足接收和去重条件的点，以有限区域假设评估移动、观测后定位困难和尾程等代价。清除后还会在已到达位置按条件共享其他频道的交叉观测。

这些评分帮助挑动作，但不是官方噪声分布下已被证明正确的期望用时，也没有对所有连续测点求精确最优。较低的评分只说明模型更喜欢该点；真实整局可能因下一次反馈、更多测量或任务重排而变慢。

### 2.4 移动覆盖站：路线变化必须保持发现能力

基准允许调整尚未执行的覆盖站。新站必须与已实际扫描站、其他保留未来站合起来仍覆盖整个题设圆域；检查圆周和内部空洞对应的有限几何见证点，不以稀疏格点抽样代替覆盖证据。

未来站仍不是实际测量。只有真的对所需频道完成扫描，才获得真实覆盖信用。站点变化可以缩短路，但也可能推迟某个未知源首次被发现的时间，因此必须观察整局结果。

### 2.5 清除与退出：和规划评分分开认证

常规清除使用近场信息或保守区域到实际清除点的距离证书。基准常用最小包围圆半径≤19.9米的充分条件，保留相对20米阈值的余量；不能仅凭区域直径≤40米就认定存在安全清除点。一次源处理最多主动探测6次，仍不足以定位时转28米步长的有限光学格子保底。格子联合覆盖才保证包含可成功的清除点，不是每个格点均持有覆盖整个候选域的单点证书；失败尝试须照实计费。预算用尽或接口失败导致的退出，不算完整清除或终止证明。

结束依据是实际已清除16个不同频道，或者真实发现覆盖已经完成且已发现源全部清除。推断“此处无信号”不会伪造成实际HTTP回包，不改变接收器、时间或位置，也不能抵扣未知频道的真实覆盖义务。

## 3. 哪些理论结论成立

| 可以说明 | 不能由此推出 |
| --- | --- |
| 冻结任务模型中，同状态保留低代价前缀不会丢掉该模型更优解 | 所有真实观测历史都可以压成同一个任务掩码 |
| MST等给出冻结路线子问题的可采纳下界 | 给出了原Q3在线最优用时的紧下界 |
| 搜索闭合时，在实现的数值比较容差下找到有限模型的最优路线 | 真实连续问题已全局最优，或者再增加训练不会超过它 |
| 真实前缀能支撑清除/覆盖/逻辑删测证据 | 所有浮点几何都已通过形式化验证，或未来任意场景都已经实测安全 |
| 独立测试集上有显著平均省时 | 每一局都必然更快，或官方分布上必然同样提升 |

早期开发诊断约98.94%的相关有限任务子问题已经搜索闭合。这是“不优先继续加A*节点”的依据，不是原题98.94%已求最优。深入同一个错误或不完整的代价模型，可能更准确地选到实际较差的动作。

\[

下界只由策略退出后的评估器使用真实中心计算。它免费给出目标位置，放松检测与未知频道排除费用，并允许同一圆盘的前后边各取不一致接触点，所以是物理先知松弛，不能解释为在线一定可达的时间。图上子集DP精确，不代表连续圆盘访问问题精确。

## 5. 第二轮有效的探索

### 5.1 相对负反馈与数量上限：较明确、可解释的小幅提升

源位置s位于当前公开观测得到的保守区域C中；旧测点n实际无信号，所以\(\|s-n\|>R\)。如果对所有\(s\in C\)，新点q到源比n更远，那么新点也必然无信号。平方距离差是仿射函数：

\[
\|s-q\|^2-\|s-n\|^2
=2(n-q)\cdot\left(s-\frac{n+q}{2}\right).
\]

因此只需在C的所有顶点核验严格正下界，就可省去这一次查询；不需要知道源位置或R。生产代码逐操作向外舍入，独立审核再用精确有理数验证。旧负反馈必须真实发生在当时前缀中，不允许凭后续反馈倒推自己当时已经知道，也不使用推断链冒充真实覆盖。

第二个独立开关是扫描循环里发现第16个源后立即停测未知频道，而不是等完整扫描结束才检查上限。已知未清频道仍按原规则处理。两项分开消融后才组合。

开发16、独立确认64、最终随机256和压力28个不同案例，四组共1456局，全部清除且零失败。主要最终结果如下，四组共用均LB=1750.182585秒：

### 5.2 持证清除尾段：可以证明局部取舍，但收益太小

当发现已合法结束，剩余2～4个源均已有清除证书时，后续不再需要猜未知观测。方法重现原基准完整可执行尾段，枚举最多24个次序并优化安全清除点，按实际逐段计费比较；至少省10毫秒才接受，而且必须执行被比较的整条尾段。

380对开发、确认、最终与压力案例全部清除、零失败；最终256对平均3083.748585→3083.703140秒，旧LB均1732.957082秒，均T/LB=1.799075→1.799049。平均省0.045445秒，区间[0.027055,0.066123]，26胜230平；P95、max不变。

收获不是“排列枚举解决了大问题”：最终改变的记录均没有改变源顺序，收益来自清除点微调。它说明将不确定性已经消失的小子问题单独求解更容易给出可信接受条件，也说明这个尾段已经不是主要瓶颈。详见[持证尾段验证](CERTIFIED_TAIL_VALIDATION.md)。没有将它和删测方案相加冒充组合实测。

| 有限观测树：两层MC，16对 | -26.273777 | [-83.038432,19.058522] | 1.729053→1.742813 | 无可靠收益 |
| 同预测世界计费：根层MC，16对 | 2.103798 | [-37.355250,40.353814] | 1.763072→1.761902 | 区间跨零、尾部退步 |
| 同预测世界计费：两层MC，16对 | -32.151757 | [-82.627980,16.789842] | 1.763072→1.783273 | 更慢且计算昂贵 |
| 主频道原地探测，16对 | 0.605840 | [-0.404459,1.670184] | 1.815994→1.815615 | 未通过扩样，暂停时保留 |

这些方向带来的具体认识：

1. **安全可行域更大，不等于整局更快。** 清除圆盘交集比MEC安全小圆更完整，几何上合理；但实际收益很小，细小落点变化还可能改变后续定位反馈和调度。不能用“更接近最近安全点”替代配对整局证据。
2. **“顺路做事”需要算完成代价。** 覆盖插入虽承诺恢复原定位任务，仍可改变扫描位置并跨过接收边界，导致未知源更晚发现。最差例不是未履行恢复承诺，而是信息时机与后续路径耦合。
3. **更精细的状态必须被决策用上。** 负反馈收紧主要发生在未发现频道的条件区域，旧调度并不据此安排未知任务；已知源轨迹未变。增加几何计算没有自然转化为动作改善。
4. **局部优化精度可能已不是限制。** 末站几何子问题逼近毫米至厘米gap后，继续提高精度的量级远小于整局路线误差；不能把求解器精度提升包装为机器人时间的大幅提升。
5. **多想几步需要可信的内部反馈模型。** 两类有限MC均实际完成了规定规划，零fallback；更慢不能归结为程序根本没跑起来。同世界计费修订消除了一个估值不一致来源，仍未取得可靠收益，说明有限粒子、任务候选及剩余代价近似仍可能误排动作。
6. **当前位置零移动，不等于少走这一段路。** 原地探测在旧示例省56.775599秒，T/LB=1.749033→1.719491；新16对却只省0.605840秒，8胜3负5平，LB均1719.228333秒。仍要赶到源并清除，可能多测一次，不能把省掉的第一段移动全算成收益。详见[最后一批诊断](diagnoses/CURRENT_PROBE_PILOT_DIAGNOSIS.md)。

首轮更早还试过扫描罚项、不同环布局、局部测点细化、未知源路线插入成本、只扫未知频道、提前共享和有限观测分箱等。其开发记录见[首轮候选清单](../../../q3-state-search/research/state_search_v1/CANDIDATES.md)，本交接不把它们的训练/开发数字混入第二轮独立统计。尤其“只扫未知频道”丢掉了覆盖站上对已知源仍有用的交叉定位信息；“原始状态求解得更精确”也曾因代价模型忽略信息价值而退步。

有限MC试验借鉴了附件中的反馈规划思想，**不是完整复现POMCPOW、VOMCPOW、ADVT，更不是新训练的RL**。负结果只针对已冻结实现与测试条件，不是否定这些方法族的证据。[文献核对及适配边界](LITERATURE_ASSESSMENT.md)保留了原论文和我们的改造之间的区别。

## 7. 日志告诉我们慢在哪里

对32个已打开且去重的旧开发基准，平均T=3164.974209秒，旧LB均1788.654831秒，均T/LB=1.782543。逐步重新计费如下：

| 费用 | 每局均值/秒 | 占整局 |
| --- | ---: | ---: |
| 移动 | 2407.161709 | 76.056% |
| 测量服务 | 583.593750 | 18.439% |
| 换频 | 107.031250 | 3.382% |
| 清除服务 | 67.187500 | 2.123% |

主动定位测点的到达移动约1264.013秒，占整局39.938%；该阶段测量本身仅85.781秒。覆盖扫描的移动约727.774秒、测量与换频583.344秒。这里把移动归到“抵达后执行的用途”，是费用归类，不证明这些路都能删掉。

从全部无线费用免费这一不现实参照看，最多也只去掉690.625秒；另外约685.694秒是实际移动相对先知图移动下界的差。这个差既包含可优化绕路，也包含不知道源位置时不可避免的获取信息路线，以及图下界自身松弛，不能全算浪费。

主要矛盾是**去哪测、何时发现、何时切换任务，怎样让用于获取信息的路和最终清除的路重合**。单纯删查询、抠最后几厘米、加更多A*节点都难以消除这部分差距。

结构压力例218026更直观：12源窄带聚集，四组均T=2969.604045秒，LB仅256.0000038秒，T/LB=11.600016。前5站100次无信号已经花1515秒，首次发现发生在1750秒；源都很近使先知盘间边界很松，同时真实搜索又确实花了很久。本轮删测机制在此没有触发。见[压力诊断](diagnoses/DERIVED_STRESS_REVIEW.md)。

## 8. 对后续强化学习的可复用收获

状态搜索不必成为最终赢家，仍然可以提供很有价值的对照和基础设施：

| 已得到的东西 | 对RL或其他方法的用途 |
| --- | --- |
| 按频道的公开可行域、测量新鲜度、覆盖状态 | 可作观测编码的依据，保持历史信息边界 |
| 清除与终止证书 | 可作共同安全检查；若RL不用相同检查，应明确其风险与额外自由度 |
| 几何候选、未来站点可行域 | 可作离散RL的动作集合，或连续RL动作的合法性验证；不能据此称完全自由连续控制 |
| 逐动作五项费用账 | 使奖励对齐真实时间，避免只缩小区域却绕更长路 |
| 原状态搜索与删测增强两个冻结版本 | 提供有竞争力、可复现的非学习基线及消融 |
| 失败场景及机制说明 | 可在标为开发用途后提出新假设；已经看过的最终集不能再次作新模型的独立验收 |
| 同场景配对、固定版本、独立审计 | 区分实际能力进步、随机波动、实现错误和计算开销 |

用户指定SQLite仍是验证数据：不拿它拟合分布、训练模型或作为课程采样池。日志回放只能沿相同请求前缀使用；一旦候选请求不同，缺少反事实反馈，不能把旧日志后续反馈拼给新策略。此前45条历史对基准和五个早期候选都只能支持共同前21步，见[严格前缀验证](STRICT_VALIDATION_RESULTS.md)。

后续如果比较RL与状态搜索，建议预先固定：两个明确提交及checkpoint、同一物理引擎和平台、独立且相同的案例、相同失败罚项与动作/现实时间预算，并分别报告全清率、失败清除、平均/P95/max虚拟时间、逐局T/LB、程序开销。训练费用另列，不能将训练时间与一次部署推理混为同一量。若RL候选集、覆盖自由度或安全控制不同，分开说明“整系统比较”和“共同动作空间下的调度消融”。

只有在这些共同条件下，新RL稳定优于冻结状态搜索，才支持它更强的结论。状态搜索自身的次优不削弱其作为基线的价值；反而有证据的非学习对照能更清楚展示学习到底补足了什么。

## 9. 写论文时值得展示与应避免的表述

可以作为算法依据的核心链条是：连续未知位置的保守几何表示→任务集合与位掩码压缩→可采纳下界剪枝→每个真实任务后的重规划→公开前缀的安全与终止认证。后续相对负反馈证书能用一个垂直平分线图解释，既直观又有可检验的代数条件。图已保留在[几何证书示意](figures/derived_silence_certificate.png)，只使用公开前缀，不画隐藏真值。

建议保留原状态搜索、只相对证书、只数量上限、两者组合的消融表，以及均值和尾部同列的RL对照；失败路线可在篇幅允许时选2～3个最能解释机制的例子，其余放支撑材料。它们反映了研究判断，而不是无目的堆算法名。

应避免：“穷举得到了第三问最优解”“细化网格必然改善完整在线策略”“证明POMCPOW不适合本题”“所有案例都接近理论极限”“以一次官方局取代配对实验”“把不同阶段改进百分比相加”“把置信区间全正等同任意未来场景保证”。本轮0.475%不能直接加到第一版8.34%上宣布总提升，因为对照、平台和案例集不同。
