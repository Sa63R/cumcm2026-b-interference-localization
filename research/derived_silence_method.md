# 问题3：从实际负观测推导静默，并在扫描中应用16源上限

本候选基于 `8c624d0` 的 `RelocatingStateSearch`。它只修改扫描时是否需要物理查询，保留原有覆盖点、逐次覆盖点迁移、主动定位、清除、任务排序、退出和预算机制。只适用于问题3；不适用于定向源的问题4。

## 动机和证据范围

只读旧开发案例 200101–200116、203101–203116 的32条基准轨迹。原均时3164.974209秒，旧物理先知下界平均1788.654831秒，逐局 T/LB 平均1.782543319。移动占76.056%，测量与换频占21.821%。

其中90次已知频道扫描可由此前实际负观测推出必无信号；另外11次是在同次扫描已发现16源之后，仍查询未知频道。保持其他物理动作与坐标不变、仅重算删除这些查询的费用，合计606秒，平均18.9375秒，占整局0.598%。这是固定轨迹的费用潜力，不是本候选已经达到的改善，更不代表整局支配。583次已知频道扫描中有68次形成新的清除证书，因而不能把“已经发现”当成“无需再测”。

完整原始输入哈希、逐局 T/LB、前缀检查和机会事件位于主研究树 `q3-round2/research/round2/diagnoses/BASELINE_OBSERVATION_COST.{json,md}`。没有读取SQLite或利用案例真值选择动作。

## 机制1：相对此前实际负点的静默证书

当前同频道未清源为 s，接收半径 R 固定且未知。保守凸多边形 C 包含 s。此前实际测量点 n 返回 no_signal，故距离(s,n)>R。若拟查询点 q 对 C 内所有可能源都比 n 更远，则 q 必然无信号。

平方差可以改写为仿射函数：

```text
d = n − q
m = (n + q) / 2
G(s) = d · (s − m)
distance(s,q)^2 − distance(s,n)^2 = 2 G(s)
```

G 在凸多边形上的最小值由顶点取得，所以只需检查全部顶点。新证书能覆盖原先 `distance(q,C)>1500` 证书不能覆盖的一些情形。

数值实现没有直接相减两个大平方。每次加、减、乘都用 `math.nextafter` 向两侧扩张为区间，计算每顶点 G 的保守下端点及 `|d|` 的上界。只有

```text
min_vertex_G_lower > 1e-5 metres × upper_bound(|d|)
```

才接受；边界、不确定、空集合、没有正观测、同点和非有限中间值不接受。`1e-5` 是平分线有符号距离的额外裕量。区间包络针对输入的二进制浮点顶点；源是否被这些顶点包围仍依赖继承的原几何外包络假设，不能把它夸称为全系统区间证明。

证据仅从 `report.action_history` 中同频道、此前实际 `measure/no_signal` 动作提取，并要求已有实际方向或 near 发现且未成功清除。`region.no_signal_positions` 混有推断点，绝不直接用它当真实旧负点来源。初版不允许推断点作为后续证书的旧负观测见证。证书计算不读源位置、接收半径、随机种子、案例编号或策略外部状态。

推断只执行 `region.observe_no_signal(q)` 并向原 `inferred_no_signal_constraints` 添加明确的推断日志。没有调用客户端、伪造返回值、改变接收频道、位置、虚拟时间、物理动作计数、客户端频道状态或 `observed_positions`；不能给予未知频道任何物理覆盖信用。

新推断的 `method` 为 `relative_actual_negative`，含此前真实动作的 `witness_action_ordinal`（报告动作列表1起始）、见证位置与时刻、仿射下界、所需裕量以及范数上界。`after_actual_action_count` 延续原语义，是推断发生时已经完成的报告实际动作数量。独立审计必须对方法分派，不能再只用旧1500米证书审计这类新推断。

## 机制2：扫描循环内识别公开数量上限

在每个拟测频道之前检查 `len(detected | cleared)==16`。仅当频道仍未知时跳过；已知未清且未持证的频道仍按原有流程进行有价值的扫描。先前推断、理论场景总数、隐藏总数或最终报告总数均不参与这个判定。

这修补的是第16个源在一轮扫描中途才被发现的情况。不会直接退出，所有已发现源仍由原策略清除，原16次实际成功清除的终止规则不变。

## 扫描证据与预算

`derived_scan_audit` 记录扫描开始/结束的实际动作数量、真实测量频道、各类跳过频道及16源证书成立的动作前缀。没有把没有执行的测量计入实际历史。

只有扫描完整结束、发生至少一次真实测量、且扫描结束时每个仍未知频道都在本次扫描真实测过，才增加 `coverage_points_visited` 和 `discovery_stations`。扫描中达到16源后若跳过了未知频道，则单列 `certified_by_count=true`，不能给该扫描几何覆盖信用。全部读数跳过时，不新增访问站点，机器人位置/频道/时钟/动作数原样保留。中途达到动作或时间预算时只记录未完成扫描，不给予站点信用，退出仍由父实现处理。

未记录为几何站点的数量证书扫描不影响仍未知源的覆盖：达到公开16源上限时，未知频道已被数量规则排除；未达到上限时，本机制不会跳过未知频道，因此原几何覆盖不缺失。

## 独立开关与三个规范

入口：`strategies.derived_silence_state_search:run_derived_silence_state_search`。

三个布尔参数为 `enabled`、`relative_silence`、`stop_scan_at_16`，默认都为 true。`enabled=false` 或两个机制都 false 时，`_scan` 直接分派到原父方法；原覆盖点迁移仍启用，不把禁用新机制误解释为禁用v1优化。
