# 固定完整网格的首次命中顺序实验

本轮从 `compact_combo` 出发，不合并观测树探点。仅在原主动定位循环进入
`clearance_grid` 后改变遍历顺序；22 点覆盖、range 跳测、源调度、每次
`_resolve` 的主动测量预算、near/19.9m 安全清除及实际 60 秒服务门控不变。
复制的 resolver 前缀有 AST 等价测试；继承方法身份测试另核探测/扫描/调度。

入口 `strategies.q4_optical_order:run_q4_optical_order`，两个预设参数：

* `{"prior":"uniform_C"}`：当前保守 C 的 192 个确定性面积求积点等权；
  退化线段用分位中点。它只是均匀区域先验的有限近似，没有用真实源布局。
* `{"prior":"observation_weighted"}`：相同位置求积点，边缘化三个半径
  1000/1250/1500m、全向/定向各 1/2、定向八个 45° 间隔朝向的先验。
  历史接收类别不符或方向误差超出 1.005° 时乘 `.001` 软似然。
  这不是经过采集数据校准的后验，也不限制每局必须有全向源。

其他入口默认值为 `problem=4,max_actions=20000,max_active_probes=6,
max_expansions=200`，内部调度固定 onroute。

## 同一个实际顺序下的期望费用

对原网格每点 q，计算其 20m 光学圆覆盖哪些有限位置假设。贪心过程每次
选择 `尚未首次命中的概率质量 / (从当前点移动/5 + 光学3秒)` 最大的下一点；
即使概率为零也保留该点，只按距离打破零质量的并列。所有假设共用这个
完整顺序，没有按各假设分别优化路线后再平均。

然后分别计算**原顺序**和**贪心顺序**的共同首次命中期望：此前均未命中
的质量乘本步移动与 3 秒光学费，仅本步首次吸收的质量再乘成功移除 2 秒。
重叠光学圆不重复吸收；不在 clear 时额外收换频费。只有贪心期望严格低于
原顺序超过 1e−9 秒时才采用，否则保留原顺序。
完整推导及贪心无一般最优保证的反例见 [THEORY.md](THEORY.md)。

覆盖检查使用未覆盖节点的**位掩码**：任何节点在原完整网格仍无覆盖，
包括极小正权重和零权重节点，均直接拒绝模型、回退原网格顺序。
没有把 `≤1e−10` 残余质量当作零费用丢掉，也没有用 `1−累计浮点质量`
判断覆盖而受舍入误差影响。负权、NaN、Inf 会被拒绝。

## 真实失败、模型耗尽与服务中断

同频道同精确测点的方向/静默历史只计一次，不能把固定误差当独立样本
平均。两种先验都应用真实失败 clear 的半径 20m 排除，但只排除有限
概率模型中的位置，绝不修改保守 C、网格覆盖证明或真实 cleared 集合。

一次光学阶段规划一条共同失败分支顺序；只在 `_clear` 已接受并返回后，
才记入 `executed_indices` 并消费该点。若真实失败排除了所有正权模型点，
剩余点切回本阶段原顺序，**所有未实际检查的网格点仍在**。
源位置不在有限节点上时，真实执行仍会完成原光学覆盖；模型耗尽不能
触发成功、退出或漏点。成功只由真实 clear 返回决定。

60 秒服务片或总预算在调用前中断时，未执行的点留在 `remaining_indices`。
`finally` 记录实际起止前缀。稍后重入从真实历史和当时 C 重建完整原网格；
不会把上一阶段的计划点误记为已经检查，也不会凭零概率省去点。
如果 C 未变，重入仍保留完整覆盖点集合，即使其中某些点已有失败历史。

额外排序最多处理 512 个网格点，有 0.5 秒定期检查墙钟上限；过大、超时或
模型为空时使用原完整顺序。单个原语不可中断，因此不是实时系统硬截止。
硬件与并发负载会影响回退，不能保证跨平台逐动作位级相同。
原网格生成本来就存在，它不属于新增排序预算。

日志 `optical_order_log` 保留本阶段全部网格点、原/候选/所选索引排列、
有限支持与权重、两种期望费、实际已执行/剩余索引、模型耗尽前缀和墙钟。
这些位置是由观测构造的假设，不是真值；原始日志可大于只记清除结果的日志。

从已接受 wire/phase 前缀重建 C 与原网格，核完整排列、实际执行/剩余账本、
真实失败排除、模型耗尽和中断证据。期望费用用独立的“每个节点沿同一顺序
走到首次成功”方式复算；不调用被审计的排序或期望函数、不读真值。
它证明的是记录一致性与费用算式，不是先验真实性或实际性能保证。

此版本的潜在收益来自未知源首次命中顺序，与此前改变光学条带几何的
实验不同。192 点求积可能漏掉小区域、先验可能偏置；贪心的移动代价与
光学圆重叠也使简单概率/成本排序没有一般最优保证。下一阶段应由统一
614xxx 新案例比较实际总费、全清、失败数与旧口径 `T/LB`；本文件没有
将预测期望下降或构造测试计作实际性能改善。
