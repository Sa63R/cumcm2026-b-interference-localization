# 完整网格光学重排：开发集负结果与实际前缀诊断

## 范围与结论

仅分析冻结提交 `ec9ab75fbe68fb3fdaae8f1b758fc19b0025ca80` 已完成的随机 `614001–614024` 和开发压力 `614031–614044`。输入为各局 `row`、`summary.action_history`、`summary.strategy_parameters.optical_order_log`，以及既有审计的通过状态；没有以隐藏源坐标解释或重放反事实，没有打开预留确认/压力集，没有修改配置或重新运行策略。比较对象是 `compact_combo`，不是较弱的 `compact_baseline`。

两个先验均未产生可晋级的整体收益。随机组只在一局发生用时变化；压力组的加权模型明显减少光学检查，却增加了更多移动。共同顺序期望的算式与执行审计通过，并不意味着假定先验已校准。真实失败能耗尽全部有限模型节点，而源仍未清除，是本轮直接观察到的模型支持不足证据。保留完整原网格的机制保障了最终完成。

合计 uniform_C 的计划重排为15/22，实际执行前缀改变13/22；weighted为21/22与19/22。二者各有一次 `614037/channel5` 在光学首条动作前被原有60秒服务门控挡住，实际执行0条，后续重新进入；不能将此记为已生效重排。另外，选择的新完整排列可能只改变成功之后从未执行的后缀。

前置回退为0不等于没有模型问题：后续真实失败使正权支持耗尽的事件分别为7次、6次，执行器随后恢复所有未检查原索引的顺序。所有epoch均通过独立费用/完整排列/真实前缀审计，未见漏节点、虚报成功或中断吃掉未执行动作。此次没有墙钟超时回退，不能用CPU超时解释虚拟用时退化。

## 4. 为什么数学期望下降而实际总体变差

1. **优化目标所用分布尚是假设。** uniform_C是几何求积，不是由观测与场景生成规律推导的真实后验；weighted只在相同192点上，用离散半径/朝向和人为0.001不匹配因子重新加权。同一位置重复观测去重，避免了重复独立证据，但没有解决先验失配。614038给出实测支持缺口，614002还表明即使成功圈初始有节点，前面的真实失败仍可能排尽这些节点。
2. **在有限节点上尾部概率为零，不代表真实尾部不可能。** 所有模型节点都被原网格覆盖，故没有违反“未覆盖正权节点不得零成本消失”的实现要求。然而共同顺序一旦覆盖完所有模型节点，模型认为余下存活质量为零，后续路线再差也不增加该期望。真实执行中的7/6次模型耗尽恰好落在这种建模盲区；执行器保留完整网格，付出了真实的非零尾部成本。不能把这一点误写为成本算式漏项或完备性失败。
3. **检查次数和移动距离是不同目标。** 压力weighted相对combo减少光学检查费，但表2显示移动费增加更多；614002和614043的同前缀账目直接定位到光学失败路径。局部质量/增量成本贪心不是全局最优排序，更不保证真实最坏路径。本轮没有比较连续后验、精确排序或风险约束，不能将“增加节点”“换先验”或“限制回跳”写成已证有效修正。

结论限于当前两配置与已打开开发分布：没有晋级依据，按预注册规则停止，不通过挑掉614002或只保留614031来挽救均值。完整网格、真实失败记账和独立审计应保留为可靠性经验；先验校准与失配尾部控制只能作为将来重新预注册的问题，本轮不调参。

根路径为 `results/q4_optical_order/`。两组使用 `development/`、`development-stress/` 下的 `summary.json` 及 `records/<strategy>-<seed>.json.gz`，原始大日志不重复入Git。

既有 `independent_audit.json` 分别96/96、56/56通过；`optical_order_audit.json` 分别48/48、28/28通过。此处只引用其通过状态，不把独立物理审计等同于概率模型校准。

可复核的计算定义：

- 完整排列改变：`selected_indices != original_indices`。
- 已执行前缀改变：`executed_indices != original_indices[:len(executed_indices)]`；零执行不算改变。
- 每epoch实际首次成功段费：历史 `h[end-1].virtual_time_s - h[n-1].virtual_time_s`；空epoch为0，其中 `n=after_actual_action_count`。移动费再扣 `3*实际检查数 + 2*实际成功数`。
- combo无epoch日志：把实际历史中连续、同频道的 `guaranteed_clearance` 动作分段，使用相同时间差定义。
- 模型耗尽：真实记录的 `exhaustion_after_actual_action_count is not None`；成功圆盘初始质量为 `sum(w for p,w in zip(support,weights) if distance(p,actual_success_position)<=20)`。
- 总表直接重算已列定种子的 `row.virtual_time_s` 和 `row.common_lower_bound_s`，保留每一局、每一失败尝试，不使用预测期望替代实际总时。
