# RL半程横向探点：实现门控与负向烟测

本分支只扩展问题3/v3的有限动作集合。`range_probes`以当前位置到当前保守候选域包围圆中心的半程点为锚点，按首次方位的垂直方向产生−150、−50、50、150米四个候选。只有对整个凸候选域能保证在1000−1e−7米内接收、未实测、未重复的点才加入。

全部base动作保留；不删可能有信息的无信号探测，不改MLP、PPO损失、真实时间奖励、清除证书、覆盖完成规则和回退限制。网络自己选择新增点，不调用状态搜索评分器或规划器。独立action_schema完整记载规则；新family为option7（特征18=7/6），原特征宽度60不变。加载、warm initialization和resume都会核验schema；初始化允许显式迁移，但不会声称动作概率保持不变。

这个设计与旧axis_quantiles不同：旧模式的14点相对长轴分位构造，忽略当前位置；新点相对实际接近路线构造，且最多4个。它也不重复此前attention或v4覆盖负债试验。其动机来自已公开48局中RL主动定位测量比状态多23.1458次/局，同时coverage少15.3958次；净增加7.75次。新增候选只能检验其中一个机制，不能解释所有差距。

## 4局实现烟测：没有性能提升结论

既有trial-1父检查点SHA256：`3d21ba7931143f281d2e7554261b001867c65fec9c2bd7465a79f91e95b7cef4`。合成训练只用了1990001..1990004，2次更新、4局、5个优化器小批；CPU单线程，无BC。评估只用已公开的2100001..2100004，不开启独立最终集、不选offset、不按结果换checkpoint。

**本烟测明显退步，不能推广新模式为更优策略。** 最大变化来自2100001：2923.681386→3311.806495秒（初始化），其余3局变化较小；这4局不支持均值或尾部泛化结论。扩大动作集合会改变flat softmax概率和候选池汇聚，旧权重没有受训过option7；初始化改变和PPO学习增量必须分开记录。root可按预登记新训练计划再检验，不能为了烟测“变好”反复改阈值。

LB沿用已有完整物理先知下界L/5+5N，各方法对同一局复用相同分母。它不是在线可达最短时间。第一次烟测的case SHA门发现仅用seed重新生成场景无法逐字节复现历史浮点位置，于是停止计分；完成的4局训练保留。之后仅将既有冻结世界装入仿真引擎，策略仍接收普通公开观测，最终SHA匹配并通过逐动作物理审计。没有根据真值选择动作。

完整逐局结果、检查点和训练记录位于本地`results/rl/range-smoke/`（未入Git）；精简可复查记录为`smoke.json`。`research/run_range_probe_smoke.py`保存复现方式、父模型哈希、世界哈希校验、只在退出后审计与同一LB的比较。重复运行不会再训练这4局，但会重新执行这次明确标记的开发烟测；正式实验应创建新输出并冻结。

## 调用

训练：在原v3/MLP96/CPU/PPO参数上加`--probe-candidates range_probes`，从base迁移必须用`--initialize-from`开启新试验。接续相同模式用`--resume`；不能把base检查点直接当range的resume。

部署：检查点已保存schema，`research_rl.run_rl_search(checkpoint=...,device="cpu")`自动选择匹配控制器；指定不同模式会拒绝加载。本分支没有官方演练或正式测试。
