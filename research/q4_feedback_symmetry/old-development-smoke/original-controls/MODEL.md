# R16：首轮真实反馈选择同点集覆盖次序

本候选继承 R12 `Q4JointContinuation`，仅在原点完整测完 20 个频道后，一次性选择余下覆盖链。它不增加测量，不改变定位、清除、服务片或光学兜底；不是学习到的先验，也不保证整局更快。尚未使用 625 场景评价。

## 不变的几何与执行边界

`compact_22` 原点、7 个内环点、14 个外环点组成同一个固定点集。内环半径 970 m；外环半径 `1800/cos(pi/14)+5` m。编号为内环角索引 i、外环角索引 j 时，候选由 k=0..6 的旋转与是否反射组成：

- 内环映射 `i -> (+i 或 -i + k) mod 7`，严格括号为 `(sign*i+k)%7`；
- 外环映射 `(sign*j+2*k)%14`；
- 候选 ID 为 `7*reflected+k`，0 是原路线。

输出使用原路线的坐标对象和索引置换，不生成近似新测点。全部 14 条链均以原点开头，原 22 个坐标各出现一次，纯覆盖开路线长度与原链差不超过 `1e-7 m`。镜像、旋转只改变次序，因此已有连续全域、任意定向覆盖的点集证书仍适用。证书不表示未访问位置已有反馈；实际扫描仍逐条收费。实际服务绕行、提前达到 16 源上限，以及定位信息变化会改变整局路径及费用。

父调度在 `_execute_plan` 入口复制待访问链。因此新入口先执行完整原点 `_scan`，根据真实反馈锁定路线，再把 21 个未访问点交给父方法；report 始终保留完整 22 点，已访问数此时为 1。父方法返回或抛出异常后恢复完整 `self.points`。不旋转 C、正负观测或源位置估计。仅接受原点无先前动作的新搜索；原点测量未完成时沿用父异常，选择日志为空，report 保持原链且不虚记完整访问。

## 两个固定选择规则

`bearing_mean`：每个频道仅用首轮真实 `direction` 反馈的一次方位，等权圆均值 `atan2(sum sin θ, sum cos θ)`，集中度 `rho=|sum exp(iθ)|/n`。需要至少两条方位且 `rho>=0.5`；否则保留原链。评分为候选首个非原点站与均值方向的最小圆周夹角，单位度。最小分数优先，精确浮点分数相等时按 ID 优先，故原链优先于与它相等的候选。

`early_centers`：对首轮实际方向反馈所构成的每个非空 canonical C，取其最小包围圆中心，计算该中心到候选前 3 个非原点站的最近欧氏距离，再对频道求和。评分单位米。最小值必须严格比原链小 `1e-9 m` 以上才换链，其余保留原链；非原链平分按固定 ID。中心仅是公开观测形成的几何代理，不当作真实源位置或概率均值。`near` 计入已知源，但不捏造方位和方向 C，故不参与这两个评分。

两规则均在已知频道达到公开 16 源上限时优先保留原链，由父流程停止发现而继续真实清除。优先状态为 `source_count_cap`，其次 `insufficient_directions`、`low_concentration` 或 `no_positive_regions`，最后 `identity_best`/`selected`。除严格中心改善阈值外，没有因开发结果调整的容差或训练参数。

## 可审计记录和局限

唯一选择事件记录完整原点动作半开区间 `[0,20)`、真实方向频道/角度、C 中心、已知频道、原/选完整点集、14 个候选的索引与分数、当前位置/频道及原动作与虚拟费用预算。选择本身不产生动作，`after_actual_action_count=end_actual_action_count=20`。原有正规观测更新、后续覆盖/调度、R8 投机清除、R9/R12 辅助域收紧与光学搜索均完全继承。计算墙钟另记，不混入仿真虚拟费用。

该代理可能把路线指向已知且易接收源，反而推迟未知源发现；趋近首方位还可能降低交会角，或者走到定向源背侧。纯链等长和完整覆盖只能保证公开几何任务不被漏掉，不能推出相同的信息质量、全清用时不增或全局最优。实际实验必须与 R12 在同批独立场景配对，并保留失败和旧口径下界比值。

构造验证仅使用固定公开覆盖点和人工脚本回包，不访问模拟器、数据库、隐藏真值或新场景。独立前缀审计另由不导入本评分函数的 checker 复核。
