# Q4 联合微动作：最小实现与验证计划

本文是下一阶段设计，尚未实现、训练或证明性能提升。依据当前 `q4_rl.controller.Q4RLSearch`、`strategies.search._Search`、`q4_clear_before_probe`、`localization.CandidateRegion` 以及现有网格/方向探针对接口的只读审阅。应在新实验分支实施，保留当前宏动作 MLP、attention 和 R8 冻结对照；不改变已冻结评估集与下界口径。

## 1. 拆分的目标与最小接口

现在 actor 可选择 `measure(point, channel)` 或整个 `service(channel)`。后者调用 `_resolve`，内部决定中心及偏移测量、何时结束定位、清除和光学网格；R8 还会在特定中心测量前插入一次真实光学尝试。故“选择服务哪个频道”尚不等于学会该源的定位/清除过程。

最小版本沿用 `run_q4_rl(client, policy, ...)`、实际动作历史和完整计费回报，将服务候选替换成下表。每个候选只执行一次真实 `client.measure` 或 `client.clear`，返回观测后重新生成所有频道的候选。移动已含在这些 API 中，暂不另加没有观测的纯移动动作。策略可以选择别的频道/覆盖点，从而暂停定位；不必添加零成本 `continue/stop` 动作或强制局部服务循环。

| 候选 | 公开产生方式 | 实际含义与检查 |
|---|---|---|
| `measure(p,c)` | 原覆盖站、当前真实位置、源可行域中心及4个沿/垂直首个真实方位的偏移点 | 一次真实测量；中心/偏移规则直接复用 `_next_probe` 的点族，但让网络选择。沿用 `min(180,max(25,r/2))`，不引入新距离先验 |
| `certified_clear(p,c)` | `near_points[c]`，或 `CandidateRegion.enclosing_disk()` 给出的中心/朝当前点最近的安全位置 | near 点在公开5m近场内；一般点须覆盖整个保守可行域，见下节。只有真实 `success` 才记清除 |
| `grid_clear(p,c)` | `clearance_grid(C, bearing_deg=first_bearing, spacing=28, start=current)` 的未尝试点 | 单次真实光学搜索；允许未命中，必须记录失败清除与3秒光学代价；完整网格覆盖才保证最终有一次能命中 |

实现上必须显式拆掉 R8 `_perform` 的“请求 measure 却先 clear”拦截，否则候选类型和实际轨迹仍不一致。微动作控制器调用一个共用、只执行一次实际 API 的原语，保留 `_Search._perform` 的预算、响应校验、几何更新和历史记录；R8 拦截仅存在于独立冻结宏动作对照/其明确标记的全局兜底。每条学习记录增加实际 action 序号区间，验证一个微动作对应一个接受的实际请求。

第一版不把 R8 的半径19.9至40m中心试清伪装为 `certified_clear`；该试清属于允许未命中的动作扩展。如以后加入 `speculative_clear`，应单独命名、单独消融，与网格未命中一起完整报告。

## 2. 规则负责的安全边界与完成条件

- 可行域 `C` 是1800m场地外包多边形与真实正方位楔形、1500m外包接收盘的交。安全清除可用充分条件 `max_v ||p-v|| <= 19.9m`（凸多边形顶点全验）；中心半径为 `r<=19.9` 时，圆盘 `B(center,19.9-r)` 内点也充分安全。near 可直接复用近场点，或只在相同保守裕量下扩展。浮点裕量沿用现有工程约定，不宣称区间算术证明。证书清除却未命中时，保留原始矛盾并退出成功路径，不能静默当作普通学习噪声。
- 合法性 mask：有限坐标且在协议允许范围、有效频道、源未实际清除、已知源清除/网格有真实正观测与非空 `C`、实际剩余时间/请求预算足够并保留 `/exit`。复用真实账单和向上取整的移动时间；不要用神经网络成功概率代替安全条件。
- 已知源 `dist(p,C)>1500+margin` 的测量必定无信号，可规则剔除，但不授予负观测或发现完成信用。空 `C` 是观测/模型矛盾，不是“源不存在”。``_ready`` 时禁测、限制重复点、top-k筛选等属于搜索空间限制，需与物理合法性分别记录；它们并非已经证明的全局最优性规则。尤其带独立角误差的重复正测可能继续收缩区域，首版可以保持禁重复，但应明确这一尚未探索的限制。
- Q4 `no_signal` 可能源于距离或未知发射半平面，不能按Q3的1000m无源盘删位置；光学未命中也不能直接把非凸的“C减圆盘”写回当前凸 `CandidateRegion`。可保存历史/已尝试点用于决策和去重。`guaranteed_detection_region` 的1000m几何距离条件本身不是Q4方向接收证书。
- 单次网格搜索的合法与光学确认安全，不等于这次必然命中。网格一经创建保存完整覆盖队列和已执行点；后续正测只缩小 `C`，原队列仍覆盖它。暂停/恢复不能丢格、重复重建后遗忘进度；第一版不按未经证明的概率删格。尽管网络只见少量候选，未见的网格点必须仍在兜底队列。预算用尽仍未清除就算未完成，不得因“理论网格能覆盖”宣布成功。
- 沿用 `_terminal_gate`：16个真实清除；或逐未知频道有发现覆盖证书、所有已发现源均真实清除且公开源数一致。任意当前/探测位置不因存在而获得覆盖信用。全局决策/请求上限仍触发完整规则兜底，尾部每秒记入学习目标；完成保证以实际预算允许执行且模型假设成立为条件，有限预算下证书未完成必须保留失败。

与另一个 adaptive cover 分支对接时，预留实际测量 ledger 钩子：接受真实回执后，以实际 action 序号、频道、精确提交位置和结果调用记账。该分支的 `AdaptiveCoverLedger.observe/proposal/remove` 与 `replay_adaptive_artifact` 负责实际/计划隔离；planned 点只用于将来可行性，不能授予信用。自然服务位置对未知频道的测量仍应是候选，即使一次不能立刻删站，也允许累计方向覆盖价值。取消整站须逐一证明该站所有仍未知频道义务可删，或频道已经发现/清除。第一版微动作保留原22站完成证书，adaptive cover作为后续独立因素。

## 3. 补足公开几何与历史，避免仅靠区域大小

同样的 outer radius/area/count 可以对应长条、楔形和不同方向/位置；负测次数相同也可能发生在完全不同的方向。attention只能关联已经给出的信息，不能恢复这些丢失量。建议新特征版本分两层，所有方法使用相同输入；不得让某个网络单独得到更多信息。

**最小几何版 G1：** 保留现10/16项，再提供目标 `C` 的中心相对当前位置和候选点坐标、8个固定方向的支持值 `max_v u_k·(v-center)`、候选至 `C` 最小距离和顶点最大距离、候选相对首个/最近真实正观测的距离与夹角正余弦、顶点数及“无正观测/退化区域”mask。8方向支持值只是压缩形状，不能替代安全检查中的全部顶点。无需PCA主轴符号约定，也不能把楔形朝向当源发射方向。归一化使用公开固定米/秒尺度，不用验证库拟合。

**历史版 H1：** 每频道最多保留最近8条真实 measure/clear 事件 token：相对位置、距离、相对当前决策的时间/动作间隔、`direction/near/no_signal/clear_success/clear_miss` 类型、实际正方位的 sin/cos 与误差界；没有方位的事件显式置mask。保留全部历史供几何/证书与原始审计使用，token截断只影响网络。给候选增加最近负测相对方向/距离、已尝试网格数、剩余网格数/公开路线代价估计；给全局加剩余决策、请求与虚拟时间预算，消除128步截断的隐藏状态。先用固定摘要MLP，再单独试小历史attention，不把网络和信息扩展混成一次消融。

不提供真实源位置、类型、发射方向、接收半径、总源数、种子/案例编号、未执行反馈或事后LB。`CandidateRegion` 顶点/中心是由公开历史算出的估计，可输入；标为“几何估计”，不得当成真实位置。负测可影响学到的动作价值，但只有经验证的几何证明才能让它改变安全mask或完成证书。

## 4. 候选有限化和计算成本

第一版每决策至多保留22×20覆盖测量、20个当前位置测量；每个已知未清源至多5个原探测点、2个安全清除点、4个网格点。最多16个已知源时上限636（实际去重后更少）；不能为了候选上限删除没有真实账目的覆盖义务。grid四点取原队列首点、当前位置最近点和两个确定的分散队列点，未选全队列保留。所有来源按固定规则生成、可去重，候选顺序不是场景标签；保留策略置换测试。

第二版可加 `choose_positive_hull_probe` 的至多2个真实正站凸组合点，以及 `choose_directional_probe_pair` 的2个端点，总上限700。前者只保证接收，名义收缩评分不是后验/清除证书；后者只保证同一未清源的两次探测至少一次接收，不能把首点单独标为必收。若允许网络暂停/放弃第二点，必须把待完成pair与anchor存在公共状态中，且未实际完成不能领取pair信用。这些点族单独消融，不和G1/H1同时开启。

按频道几何版本缓存中心/支持值/候选与网格，只在真实新观测后失效；当前位置相关距离每决策刷新。不要每步运行完整方向覆盖证书或几千网格的全路线优化。特征时间、候选数、网络时间、fallback时间/动作占比均报告；CPU总成本应包括提议、证书、采样、训练与推理。

## 5. 长期回报、候选价值与最小消融

保留 `attach_returns` 的 `gamma=1` 和固定1000秒尺度：reward只取实际完整计费增量的负数；失败惩罚与行政截止处理保持。不添加“区域变小奖励”“少测量奖励”或LB奖励制造局部偏好。宏拆微后128次决策意味着更短的实际控制范围，不能把两者128直接当等控制权：报告学习所执行的实际动作数与fallback成本占比；预注册128/512微决策两个资源档，与同一环境的宏模型比较并单独列计算成本。

顺序消融建议：A=冻结宏；B=原点族的微动作+确定性teacher；C=B+学习（先用原摘要）；D=C+G1；E=D+H1；F在固定输入上比较MLP/attention；新增点族与adaptive cover均后置。B的teacher需从实际R8轨迹拆分并验证每个执行动作在候选内，不支持的R8试清要显式标出/另外开动作臂，不把不一致轨迹强行贴标签。保留每个差异的规则和账单日志，不能将B的规则收益算成网络收益。

候选价值最小路径先不引入仿真预测：共享候选编码器增加 `Q(h,a)`，只以训练中**实际选择并执行**的动作全回报训练，用同状态 `V(h)` 作PPO基线；未选候选没有标签，不把日志当全反事实反馈。对照固定动作/输入/预算下的纯actor+V与actor+Q，先看新训练后真实开发回报和价值校准，再允许有限的价值引导选择。若以后做多步belief rollout，必须从公开历史构建显式类型/半平面/半径假设，模拟反馈仅为假设且不能更新实际ledger；当前只有凸位置C的模型不足以给Q4负测做可信完整预测。此项应在单独实验中检验模型失配，不能直接调用当前真实场景的隐状态预测候选结果。

验收优先看同一预注册新开发场景上的配对全清率、证书矛盾/非法动作、失败清除、平均/p95/最大实际与失败惩罚用时、配对差值CI、CPU开销和共同T/L两种聚合比值。再看具体源内探测/网格用时、额外测量是否减少后续全程成本、fallback占比与状态价值误差。单步区域收缩、BC或PPO loss变好不够。小pilot只决定是否扩展，独立确认合格才可推荐；无提升保留代码/原始结果及原因，不能称其为全局最优或证明微动作无价值。
