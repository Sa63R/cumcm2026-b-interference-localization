# Q4 微动作第一阶段：冻结开发协议

本阶段只验证控制器可靠性并运行4个预指定的新合成开发案例，不训练模型，不读取验证数据库，不调用官方演练或正式模拟器。基线为主树提交 `3caef9b`；原 v1 控制器、R8、network/train 与通用评估器不变。

## 实现边界

入口 `q4_rl.micro_controller:run_q4_micro(client, policy=None, *, problem=4, **kwargs)`；新 schema `q4-micro-g1-v1`，全局13维、候选50维。可调用策略只收到纯数值列表，不能访问 client、场景或评估器。参数沿用 v1 的决策/请求/时间预算与记录开关。学习轨迹字段仍为实际 `cost_s`、`fallback_cost_s`、动作索引、动作类型和公开特征；本阶段不接入任何模型。

- 三类动作：一次测量、可证明范围内的一次清除、一次光学网格搜索。微动作直接使用 `_Search._perform` 单请求原语，绕过 R8 的 clear-before-measure 插入。`micro_steps` 保存决策与真实动作序号、接受请求数、计费时间及清除证书。
- 清除充分条件：真实 near 点的5m盘；或真实正方位约束外包多边形全部顶点距清除点不超过 `19.9-1e-5` 米。备选点为外包圆中心和朝当前位置的保守安全边缘点。距离使用全部顶点复查，不由网络概率决定。证书清除真实未命中是模型/数值矛盾并标记失败；光学网格未命中允许，但完整计费并计入失败清除。
- 发现仍使用已证明的固定22站逐频道实际测量账本；16个已发现源只结束发现工作，清除仍依赖真实 success。未完成证书时不得早停。
- 网格28米间距，完整覆盖队列保留。首次真实执行后队列固定，记录已尝试点；后续正测缩小C、其他任务插入、候选只展示4点，都不能丢失网格义务。no_signal 与光学未命中都不删凸位置域。兜底对未开始网格使用冻结R8，对已开始网格按完整旧队列续跑，全部尾部成本回传。
- G1新增8方向支持值、可行域中心相对位置、候选至区域上下界距离、顶点/退化/正观测标志、首末真实正方位相对几何、网格进度及剩余决策/请求/虚拟时间。支持值是网络摘要，不能替代证书全顶点检查。绝不输入真实源参数、总源数、案例或种子、事后下界。
- 初始候选族最多636：22×20覆盖测量、20个当前位置测量，以及每个已知未清源5个原中心/方位偏移探测点、2个安全清除点、4个网格代表。没有自由连续动作、adaptive cover、正站hull/pair扩展或attention集成。禁重复测量和ready后禁测属于明确的搜索空间限制。

确定性 micro heuristic：先完成当前固定站扫描，再就近安全清除；发现已获证或区域半径不超过40米时，按目标中心距离选择源，优先原中心/偏移探测，累计6次局部探测后优先网格；其他情况下就近继续固定站。它不是已证明最优规则，也不等价于R8拆轨迹teacher：没有R8的19.9至40米中心试清，且安全边缘清除/服务插入均可能改变结果。任何收益先归于动作与规则扩展，不算网络训练收益。

## 预指定比较

固定 `seed=8105000,8105001`，`family=random`，每个seed分别使用 `mixed` 和 `all_directional` 模式，共4个case（两个seed簇）。这是开发功能检查，不是独立确认或最终评估。任何案例失败都保留，不补选有利案例。

四臂：冻结 `r8`、`v1_heuristic128`、`micro_heuristic128`、`micro_heuristic512`。所有臂最大20000请求、6次默认主动探测参数、360000秒虚拟时限、相同本地物理环境与既有共同下界。微动作和宏动作的128决策不是相同实际控制时域，必须并列报告真实动作与fallback成本占比。源内微动作只有heuristic使用6次探测门限，未来actor仍可在全局预算内自由选择合法探测。

运行前通用 `experiments/q4_rl_evaluate.py` 将全部src、评估代码、原协议、精确spec与本文hash写入manifest/source.zip，再启动评估；各臂验证源码没有变化。只用1个worker、每个数值库1线程、禁止GPU，计入全任务预算；不启动任何并行本地训练。

每臂报告全清/审计通过率、失败清除数、平均/p95/最大实际及失败惩罚时间、完整配对差值与seed簇bootstrap CI、CPU/墙钟、特征/推理/fallback开销、共同T/L的均值之比与比值均值。只在实际策略退出后评估器读取合成真值用于物理审核和同一下界。保留所有原始history、summary、微动作和网格账本，并复核每个微动作仅一次实际请求、安全证书、完整账单与源码冻结。

脚本测试覆盖单请求不插清、全部顶点与边界裕量、证书矛盾失败、网格覆盖/未命中/正测收缩/兜底续跑、负测不剪域/假账、G1同面积同半径不同形状、真实方位与预算特征、拒绝请求、全清发现门槛和完整尾部回报。通过后只运行本协议四例；严重耗时退化同样保留。四例的区间只作描述，不能升级推荐版本。

复现命令（在独立代码树、CPU环境执行）：

```powershell
$env:PYTHONPATH = "src"
python -B -m pytest tests/test_q4_rl_micro_controller.py tests/test_q4_rl_controller.py -q
python -B experiments/q4_rl_evaluate.py --output results/q4_rl/micro-stage1-fourcase --specs research/q4_rl/micro_stage1_specs.json --start 8105000 --count 2 --families random --source-modes mixed all_directional --workers 1 --bootstrap-samples 2000
```

输出目录必须新建；已有原始结果不得覆盖。本阶段不修改通用评估协议，不自动promotion。
