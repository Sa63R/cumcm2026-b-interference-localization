# Q4：从完整回报训练走向全局长期决策

2026-09-11。本文是后续实验设计，不是训练结果或最优性声明。只读检查当前 Q4 代码并查阅五篇一手论文；没有读取审核数据库、执行训练或修改已冻结评估协议。

建议优先检验两条路线：**A，补全观测关系与历史表示，并用同场景完整回报基线降低训练噪声；B，在合法观测构造的 belief 上执行有未来观测分支的有限深度规划，用已验证价值函数估计尾部代价。** 两者分别针对信息压缩和显式未来推演，可以与独立的自适应覆盖动作设计组合，但组合收益必须重新评估。

`attach_returns()` 已使用不折扣的完整剩余计费成本，且将兜底尾部成本纳入最后一个学习决策。PPO 的优势估计是完整 Monte Carlo return 减去旧 critic，而非只奖励本步移动变短。因此，**不能把现有 PPO 称为只优化一步的贪心算法**。PPO 是更新策略的近似优化方法，并不会自动赋予状态表示完整信息或全局搜索能力；原论文讨论的是采样与代理目标更新。[PPO 原论文](https://arxiv.org/abs/1707.06347)

以下局限来自本地代码，是否主导当前性能仍须实验区分：

1. `CandidateActorCritic` 先逐候选编码，再做 mean/max pooling，将同一个上下文拼回各候选。它已经有集合级信息和置换等变性，不能说候选完全互不影响；但有限维池化没有显式表示“这个频道在那几个位置测过”“两次正观测夹角”“两个目的地共用一路移动”等关系。
2. 16 维候选特征只含半径、面积、观测次数、负测次数和待扫比例等摘要。不同正负观测几何可能产生相同摘要，却需要不同下一步行动。若输入张量相同，任何更大 MLP 或 attention 都无法恢复已经被删掉的信息。这是首先需要补的表示缺口。
3. `service` 仍调用整段 `_resolve()`。网络能决定何时处理哪个源，但不能在其内部每次测向后决定继续扫描、换定位点还是转去另一个源；候选中的 `distance/5+5` 也只是粗特征，不是整个 service 的真实成本。实际 reward 仍按真实费用，不能把这个特征当成本承诺。
4. 达到 `max_decisions` 后使用固定兜底。若学习前缀极短，训练对象实际是“短前缀加固定尾部”，而不是全部流程。尾部正确计费避免了漏算，但不能证明网络已经学会尾部决策。需要同时报告学习决策覆盖的动作/费用比例、兜底比例和真实决策种类。
5. 大量“站点×频道”动作加上 BC 启发式暖启动，可能令探索集中于近点扫描和尽早服务。仅看到训练 loss 降低、动作与启发式一致或低步数烟测通过，不能说明已经学会信息获取的长期价值。

两种特别需要学习的长期权衡是：现在多花一次测量的钱，是否能省去后续大段绕行；现在先去一个看似远的地点，是否同时推进几个频道的缺席证明与定位。负测次数、面积缩小和 attention 权重都不是这两个问题的答案。

## 2. 路线 A：关系/历史表示与同场景完整回报基线

**假设 A：** 当前可观察几何关系被摘要压缩，同时场景难度造成的整局成本差异增加了优势噪声；改善这两点能在原动作空间内降低完成成本。先固定动作空间，避免把新增位置的收益归于网络。

### A1. 最小可实现的表示改造

使用三类 token：最多 20 个频道、当前候选涉及的地点、近期合法观测事件。频道 token 保存正观测候选区域的中心、尺度、长宽方向、near/已清除标志，以及覆盖台账的关系；事件 token 保存真实动作类型、相对坐标、反馈类型、方向的 sin/cos、实付费用。用“是否同频道/同地点”“相对距离/方向”关系连接候选与 token，不把频道数值大小当几何含义。

第一版可采用宽度 64、两个小 attention block、16 个 inducing token，或候选对频道/地点 token 的 cross-attention，避免每步对约 440 个候选做多层完整二次 self-attention。Set Transformer 的直接启发是显式建模集合元素关系及控制集合注意力复杂度；它不是 Q4 性能保证。[Set Transformer，ICML 2019](https://proceedings.mlr.press/v97/lee19d.html)

历史先用固定上限事件窗口或小 GRU；保留完整几何与覆盖台账供安全控制，不能因网络窗口截断删除安全证据。时间位置编码仅表示同一局内合法事件顺序；真实时间戳、场次编号、场景 seed 与案例名称不入网。对 recurrent 版本必须按轨迹片段训练，重置局间隐藏状态；不能继续把彼此独立的旧 transition 随机打散后宣称训练了记忆。相关研究表明 recurrent RL 的架构、输入与训练细节值得单独认真检验，而不是直接假定更复杂模型一定优越。[Recurrent Model-Free RL，ICML 2022](https://proceedings.mlr.press/v162/ni22a.html)

### A2. 完整回报的配对基线

只在新的合成训练场景中，为采样策略和冻结参考策略分别启动相互独立的环境副本，二者共享相同场景与固定误差场。每个策略只能看到自己的合法观测。参考策略先用冻结 R8，后续若切换为冻结 greedy 学习策略，应另记训练版本。

最清晰的首次消融是独立的整轨迹 REINFORCE：令 `C(τ)` 为全清总计费成本或预登记失败惩罚，`B(s)` 为同场景参考策略的完整成本，则成本最小化梯度估计为：

\[
\widehat{\nabla J}
=\bigl(C(\tau)-\operatorname{stopgrad}B(s)\bigr)
\sum_t\nabla\log\pi_\theta(a_t\mid h_t).
\]

`B(s)` 是训练时从另一次合法执行得到的标量，不是在线输入；它不得依赖本条采样轨迹所选动作，不得从隐藏真值构造最优路线。场景名仅用于外层配对，网络和 critic 均不接受。若参考轨迹失败，照样保留预登记惩罚，不筛掉。需要将额外参考执行的 CPU/采样成本计入总预算。

attention routing 论文使用整条路线成本与冻结 greedy rollout 基线，提供了该方向的直接依据；其路由任务和 Q4 的未知源发现不同，不能照搬其成绩或假定相同收益。[Attention, Learn to Solve Routing Problems!，ICLR 2019，§4](https://arxiv.org/html/1803.08475v3#S4)

保留现有 PPO+critic 为对照。不要把整局 `B(s)` 直接、不加推导地减到每一步 reward-to-go 后称为“更准的剩余成本 critic”；也不要在 PPO clipping 内混用动作相关后见基线。先用上述明确的整轨迹估计检验方差和实际成绩，再考虑 observation-only critic 的残差基线。训练回报固定缩放、不按真实源数或事后 LB 归一化，诊断 LB 继续只作事后报告。

### A3. 最小消融与继续条件

| 配置 | 表示 | 优化 | 能回答的问题 |
|---|---|---|---|
| A0 | 当前摘要 MLP | 当前完整回报 PPO | 冻结学习对照 |
| A1 | 同一摘要加候选 attention | 同 PPO | 仅候选交互的贡献，不能补已丢历史 |
| A2 | attention 加合法几何/历史 token | 同 PPO | 新观测信息的贡献 |
| A3 | 与 A2 相同 | 整轨迹配对 REINFORCE | 参考 rollout 相对 critic 的贡献 |

各配置使用相同动作集、兜底、开发请求和总 CPU 并发上限；同时报告训练场景数、实际执行轨迹数与训练 CPU 秒。先在预登记相同资源预算下比较，若要比较样本效率另列等场景数分析，不能藏掉配对参考轨迹的成本。至少记录 critic 对完整剩余成本的校准、优势方差、动作熵、真实总成本与兜底比例。

A1 不额外加入原张量不存在的频道关联标签；A2 才开放这些来自合法台账的关系。表示实验结束后，与控制器团队配合将 service 中的测向、继续定位、暂停服务和清除暴露为可选动作，须再做“新动作加启发式/新动作加冻结网络/新动作加重新训练”的独立比较。仅有当前宏动作版本不能称为已实现全部定位与清除的联合决策。

每约 30 分钟检查开发配对结果。若 A1 无收益但 A2 有收益，说明主要瓶颈是信息而非 attention 名称；若 A3 只减训练方差、相同预算下时间不降，就不将它晋级。出现未全清或证书异常先修正并保留记录；两个预登记资源档位都无开发成本收益且计算代价明确增加，可暂停该配置并换路线，但不能据此宣布 attention/记忆在 Q4 无效。独立确认仍使用冻结评估协议与新保留场景，不以反复查看独立集来调 token 数或学习率。

## 3. 路线 B：观测条件下的有限深度 belief 规划

**假设 B：** 学习策略能够给出有价值的候选与剩余成本估计，但不足以稳定判断某次扫描是否值得；显式比较“行动—可能观测—再行动”有望补上多步信息价值。

### B1. 必须满足的模型边界

从公开物理规则和合法历史构造联合假设：频道是否有源、位置、接收半径、全向/定向类型、发射朝向。假设源数必须与 10–16 上限和已发现频道一致。不能把各空频道独立存在概率相乘后生成超过 16 个源的“Q4 场景”。概率先验只来自预登记合成假设；审核数据库不用于拟合。

真实 `no_signal` 联合约束半径和发射半平面，不能按全向源逻辑删除整个接收圆。方位、near 和清除反馈也必须在采样假设中同时一致。同坐标同频道误差固定：重复同一点不能再次生成独立测角噪声或重复相乘似然来虚增置信度。无粒子存活、权重退化或几何预算耗尽时报告模型不支持，并回退可靠策略；不能宣称目标不存在。

POMCPOW 原论文说明，连续观测中的简单树扩展可能导致信念退化；其加权方案需要可查询观测相对似然。Q4 的研究误差模型可提供一种近似似然，但官方量化和误差分布未完全确认，不能据此宣称实现了有保证的官方后验。[POMCPOW 原论文，§4.1–4.4](https://arxiv.org/pdf/1709.06196)

### B2. 首次实现范围

先做 CPU 可控的 shallow belief rollout：每次评估最多 4 个根动作、32 个一致假设、深度 2；第二档只扩到深度 3 或 64 假设，二者不同时改。根动作保留一个当前可靠策略动作，再从网络分数及空间多样性选取测量/定位/服务候选，避免只比较四个几乎相同的近点。这个截断本身会遗漏好动作，须明确列为近似。

每个动作先通过同一物理模型产生可能反馈，再由更新后的**观测历史/belief**选择下一动作。可用：

\[
\widehat Q(h,a)=\mathbb E_{\text{合法假设与反馈}}
\left[\sum_{k=0}^{d-1}c_{t+k}+\widehat V(h_{t+d})\right],
\]

其中 `c` 包括真正会发生的移动、切频、测量、光学和成功移除费用；终端 `V` 估计从叶子历史开始的全部剩余费用，不能与已经展开的费用重复相加。首次可将叶子设为冻结可靠策略的完整模拟执行，待确认价值网络校准后再比较学习 `V` 的计算收益。保留对不同先验假设、正负极端误差和全定向情形的敏感性分析。

**不能对每个粒子直接读取其源位置、计算最优后续路线，再平均这些最优值当作可实现 Q。** 这样相当于假设未来会额外获得真实状态，可能低估发现/定位成本并误判信息价值。相同观测历史的分支必须共享同一可观察决策规则；模拟世界真值只能留在生成反馈的内层环境。该约束与论文讨论的 QMDP 类退化问题相关，但此处是本项目的实现要求，不冒用论文的收敛结论。

网络 `V`、粒子概率、rollout 预测只用于选择合法动作；实际清除与终止仍必须通过完整几何、实际清除记录和逐频道覆盖证明。单纯信息熵降低、区域面积变小或某站点 attention 权重大，均不能替代计费成本或完成证明。自适应覆盖团队提供的新位置和合法覆盖替代证书可进入根动作候选；规划层不自行赋予未执行扫描信用。

### B3. 最小消融与继续条件

| 配置 | 候选 | 前瞻 | 尾部 | 解释 |
|---|---|---|---|---|
| B0 | 相同根候选 | 无 | 当前策略 | 控制候选扩展本身 |
| B1 | 相同根候选 | 深度 1、真实反馈分支 | 冻结可靠 rollout | 一步观测价值 |
| B2 | 相同根候选 | 深度 2 | 同一可靠 rollout | 多步协同的增量 |
| B3 | 与 B2 相同 | 深度 2 | 学习 V | 价值尾项节省计算及其偏差 |

先用新合成训练/开发历史进行模型一致性检查：重复点反馈一致、真实观测可被粒子假设解释、同历史不能偷看粒子身份、费用可独立重算。只要这些失败，就不做性能晋级。对根动作排序还应报告预测节省与实际完整续跑节省的符号一致率，并披露高置信错误排序。

继续条件是固定 CPU 预算下 B2 相比 B1 在开发配对完整成本上产生可重复增益，且计算没有大量触发真实期限/兜底；B3 必须保住这部分收益才值得替换完整 rollout。若扩展一次预登记粒子/深度档位后，收益仍仅来自候选变化，或尾部估计持续乐观且最坏退化增大，应停止扩大该规划配置，保留代码和失败原因，转向表示/动作或模型校准。不能用模拟 Q 下降作为继续消耗算力的唯一理由。

## 4. 如何核查“动作必要性”与长期能力

对一次动作最有用的解释是：它预计改变哪一项剩余任务成本、备选动作完整后续成本是多少、这个差异依赖哪些尚未确定的反馈。不要把网络置信度转写为某个固定站“必须访问”或“绝对无用”的证明。

未来实现可在开发模拟中记录以下对照：同一合法历史下，基线下一动作、候选下一动作、随后相同 continuation policy 的完整结果；对替代动作必须由支持新反馈的完整模拟器执行，不能从历史轨迹补造答案。外层开发诊断可利用新合成场景生成反馈，但在线规划只能从历史构造自己的假设。

特别检查三类场景：一次额外测量能省较长清除绕行；先做远一点的多频道观测能更早停止覆盖；两个单独收益弱的测量共同形成定位或方向缺席证书。场景构造应由规则预先定义，不从已经看到的获胜案例挑选。它们是解释性开发集，不能代替随机独立确认和压力评估。

最终仍以统一评估的全清率、失败清除次数、尾部、计算开销及完整 `T/L` 为准。沿用 `q4-common-source-edge-v1`，不因某一方法采用 belief 或 attention 就换一个更有利的分母。缩短训练预算、模型样本不足、值函数失准、候选不完备、有限规划深度或先验失配，都可能留下改进空间；任何一条路线停止都不意味着已达到全局最优。
