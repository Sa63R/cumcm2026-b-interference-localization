# Q4 覆盖义务、路线成本与联合决策的可优化边界

本分析基于 `1080e4e` 的代码和已保存的第二轮四例开发记录，未运行场景、模拟器或数据库，未训练模型。逐动作账单只读复算通过。它指导下一轮动作与特征设计，不调整 `q4-common-source-edge-v1` 统一下界，不认定当前方法或 22 点几何达到问题 4 的理论最优。

**结论：22 个固定坐标不是题目要求；保证全清需要的是足够排除所有仍可能存在源的实际观测，以及所有已知源的成功清除记录。** 发现 16 个不同频道的源后可以取消全部未知频道发现任务；发现不足 16 个时，不能因为“已经清完目前看到的源”停止。在后一种情况下，自适应轨迹可以替代固定站，但必须对每个仍未知频道形成完备、可重放的发现/排除证据，或保留一个仍可完成的兜底计划。省去个别站点—频道义务与省去整站访问是两件不同的事。

## 1. 公开规则与证书的前提

规则依据：题目附件 2《通信接口及编程指南》1.1、1.3、2.1–2.4、4.2–4.4、7.3、8.2；仓库常量见 `src/simulator_client/rules.py`，实际研究计费实现见 `src/simulation/engine.py`。原附件只读核对，未连接官方软件。

- 所有源位于半径 1800 m 的目标圆域，机器人可以走到圆外；20 个频道，每频道最多一个源，源数 10–16，真实数量不通过接口返回。
- 接收半径未知，范围 1000–1500 m。定向源覆盖一个包含边界的 180° 半圆，朝向未知；不能假设未知频道一定全向，或把合成数据类型比例当公开约束。
- `/measure(p,c)` 到达提交位置后测一个频道，计费为移动距离/5、检测 5 秒及必要的切频 1 秒。没有沿途连续扫描，也没有免费同时测多个频道。站点坐标只是策略的选择。
- `no_signal` 可能源于无源、超距或定向背面；一次无信号不能推出以测点为中心的 1000 m 圆盘无源。
- `/clear(p,c)` 与源朝向无关：20 m 内成功，光学 3 秒和清除 2 秒；失败也付光学 3 秒及移动成本。它不改变测向机当前频道。
- 同一点同频道的测向误差固定。重复测量不能通过平均消除这一误差；只路过某点、测过别的频道、拟定将来测量，都不能记作该频道在此点有实际证据。

设未知频道 c 已实际得到无信号的位置集合为 P_c，且该频道没有在此前清除。对任意可能源位置 x，取距离 x 不超过 1000 m 的点集 S_c(x)。仅依靠负测量排除任意未知朝向的一个充分且理想几何下必要条件是：

`对全部 x∈目标圆域，x∈conv(S_c(x))。`

若 x 在这个凸包中，则每个以 x 为边界的闭半平面至少含一个实际测点，该点对最小接收半径的源也应可见，与全部无信号矛盾。若 x 不在凸包中，严格分离方向给出一个可能避开这些测点的半圆朝向；取合法半径 1000 m，较远测点也收不到。此反例是几何相容性，不是得知真实源位置。有限测点集在几乎所有位置都需至少三个近距点才能包住 x；两个点只可能覆盖其线段这一零面积集合。

`src/planning/q4_directional_cover.py` 的 22 点证书用四叉树叶盒保证整个区域，而不是抽样格点通过就算覆盖。`src/q4_rl/adaptive_cover.py` 对提交的浮点坐标按其精确有理值重放支持点、距离余量、凸包包含和完整叶分区。证书预算不足或未找到证书表示“暂未认证”，不能据此宣布几何不可能，也不能跳过义务。

上述凸包条件适用于负测量单独承担发现保证的情形。合法失败清除还可排除该频道清除点 20 m 内的位置，原则上能与负测量联合；当前自适应发现 ledger 尚未利用失败光学盘，不能把未来功能当成已有证据。已知源的正测向区域也可用于其定位；不能把一个频道的区域约束移用到另一个未知频道。

## 2. N=16 与 N<16 的探索义务不同

这里 N 是事后评估数量，仅用于本分析分层；线上策略只能使用已知不同频道数 K 和实际成功清除数 C。

| 当前合法证据 | 可省略的任务 | 仍必须完成的任务 |
|---|---|---|
| K=16，但 C<16 | 所有剩余未知频道扫描与发现覆盖，可以立即省去其未访问站点 | 继续定位/清除尚未成功的已知频道；不能把“发现完成”当“全清完成” |
| C=16 | 剩余扫描、定位与清除任务均可结束 | 合法退出并保留 16 个不同频道的实际成功证据 |
| K<16，已知源全部清除 | 对已清频道的未来动作 | 对每个仍未知频道排除合法隐藏源；否则无法保证没有第 K+1 个源 |
| K<16，未知频道均有完备实际排除证书 | 剩余纯发现任务 | 仍未清的已知源及其安全兜底 |
| 只有 actual+planned 的完整覆盖证书 | 被替换的固定义务，可按修订后的兜底计划执行 | planned 部分仍欠账；终止前必须实际测量或通过新的完整证据取消 |

当真实 N<16 时，即便实际 N 个源都清了，只要某个未知频道仍存在与全历史相容的额外定向源，增加一个源后仍不超过 16，策略就无法区分这两个场景。要保证全部合法场景都全清，就不能在这里停止。最低数量 10 也不能提供这种停止证据：清完 10 个不排除第 11 个。

N=16 的潜在收益是尽快获得第 16 个不同频道的可靠正证据，并在全清前停止无关发现工作。它不要求清源先后顺序固定，但为追逐未知最后一个源大幅绕路未必合算；策略要比较长期总费。已有四例仅含 N=10、14，各两个源类型场景，没有 N=16，不能用本批数据证明或否定数量上限早停的收益。

## 3. 固定点是不是必须逐个走，整站如何合法取消

22 点由原点、半径 970 m 的 7 个内环点，以及半径 `1800/cos(π/14)+5 m` 的 14 个外环点组成。它是一组已经认证的充分解，不是题目规定的必访坐标，也没有证明它在可变点集里点数最少或总费用最小。

对未知频道 c，令 A_c 为真实负测点，F_c 为尚待执行的固定支持点。当前实现维护 `A_c∪F_c` 的完整覆盖证书。删去固定点 p 的义务需要认证 `A_c∪(F_c\{p})`；若用一个新点 q 论证替代，`A_c∪(F_c\{p})∪{q}` 只能先证未来可行，q 真正取得无信号后才可转为实际支持。测得正信号则改为已知源服务任务，不再承担该频道全域无源证明。

一个固定站 p 可从未来纯发现路线中取消，必须满足：**每个仍未知频道在 p 上的义务均已完成或通过各自的完整残余证书合法删除。** 所有频道可以在别的不同实际点累积支持，不必共同依赖同一替代点。每次删点是事务性的，多个单独可删的点不能基于同一旧证书同时删除而不重证。已知源如仍需要该站作定位测点，必须另有合法定位/清除方案，不能借“发现义务取消”删除清源兜底。

这意味着：

1. 单个频道省去在 p 的检测，通常最多省检测/切频；只要另一个频道仍需 p，移动依旧发生。
2. 若多个频道在自然到达的服务位置完成必要测量，并联合替代 p 的全部义务，才可能省掉该站的进入/离开绕路。
3. 在去 p 的直线上提前 1–20 m 测一次、随后因其他频道仍到 p，通常不能节省路线；还可能增加一次动作或改变服务插入顺序。
4. fixed 点没有独立物理地位，但一个能够证明完备的实际自适应观测集有物理必要性。不能以“模型大概率已全清”替代这项保证。

已有 [COVER_ROUTE_BOUND.md](../q4_joint/COVER_ROUTE_BOUND.md) 证明：**若强制访问给定全部 22 点、从原点出发、自由终点且只计移动**，原内外环开路线达到 MST，长度约 17612.4194 m，移动约 3522.4839 秒。继续只给这组点换排列不能在该子问题上降低最优值。它不限制可变测点、数量上限早停、部分频道义务取消、源服务点/定位点与覆盖路线联合设计。3522.4839 秒不能直接加到 source-edge 移动下界上：覆盖和清源可能共享同一段移动，直接相加会重复计费。

## 4. 当前统一下界包括什么、遗漏什么

代码 `experiments/q4_comparison_bounds.py:common_bound` 固定版本为 `q4-common-source-edge-v1`。保持原统计口径：

`L = source-edge 开路径距离 / 5 + 5N + [N<16]·50(20−N)。`

第一段源边距离取起点至第一个清除盘的下界 `max(|s|−20,0)`，以及相邻两源清除盘间的下界 `max(|s_i−s_j|−40,0)`，子集 DP 精确解的是这个有限图。它事后读取真实源位置；策略输入、训练回报和动作筛选不能读取该信息。相邻边可能要求同一个清除盘内不相容的进入/离开位置，故图最优值不必在连续空间可达。

**空频道探索并非完全没计入。** 当 N<16，统一下界已为每个空频道加 50 秒。它由对全部合法隐场景完成的条件以及面积放松得到：若有 m 次负测量、f 次失败光学，必须满足 `m·1000²+3f·20²≥3·1800²`，整数动作成本 `5m+3f` 至少为 50 秒。这个证明不保证 10 个测点就能构成可达、可共享、方向完备的覆盖轨迹。

因此 L 仍未充分表达以下费用：

- 实际负测点为包围整个圆域而发生的探索移动，及其与清源路线不可完全共享的部分。
- 有限几何、边界朝向和鲁棒余量可能迫使空频道使用超过面积放松所需的检测次数。
- 非空频道第一次发现之前的检测、发现后的带误差定位与主动探测。
- 全部切频费用、失败光学的实际费用，以及这些动作产生的路线偏离。
- 策略为了获得信息而做出的绕行，以及 source-edge 图的连续位置不相容松弛。

上述项同时含“物理上可能不得不付的成本”和“算法可优化浪费”。不能把全部 `T−L` 都当作可学习节省，也不能因 `T/L` 约 3.5 就断言还能提速 3.5 倍。本文没有构造更强的统一 LB，没有修改历史分母，没有证明不可优化或理论最优。

### 5.1 精确解释 heuristic 的 T−L，而不许诺全部可省

四例 heuristic 的空频道各恰测 22 次：N14 两例各 132 次，N10 两例各 220 次，平均 176 次、880 秒；统一下界对应的空频道动作仅平均 400 秒。事后分类使用完整成功/完成记录中的已发现频道集合，分类信息没有进入策略。

| 与统一 L 的差额来源 | 平均秒数 | 解释 |
|---|---:|---|
| 实际移动 − source-edge 移动下界 | 4149.832505 | 探索几何、清源服务插入、定位绕行、边松弛共同贡献；不能分配为纯浪费 |
| 空频道检测 − 50 秒/空频道 | 480.000000 | 当前22次与面积整数放松10次之差；不能宣称10点覆盖可实现 |
| 非空频道全部检测 | 535.000000 | 同时含发现前和发现后；并非全部冗余 |
| 切頻 | 262.500000 | 需要跨频道获得真实证据，不能用长程按频道遍历换来更大移动 |
| 失败光学 | 51.000000 | 17 次平均失败；失败移动已在第一项，不重复计 |

这将主要目标定位到“发现/定位/清除/排空共同选择位置和路线”，而不是单独减少切频或只优化已知源的短程服务顺序。该分解不读取源坐标；source-edge 标量仅取自已存终局评估结果。

### 5.2 自适应试验为什么未减少必要遍历

从真实 `/measure` 坐标集合核对：所有 16 份记录都测了全部 22 个精确固定坐标，`coverage_points_visited` 字段不被用作这一断言的依据。adaptive_actions 每例删除 10、11、13、15 条义务，但每个固定站仍有其他频道要测；自然清源/定位位置的机会替代计数四例均为 0。它没有实现本任务最期待的“顺路负测量累计后取消整站”。

adaptive_actions 的空频道测量数为 133、132、222、221，均未少于基线；总测量相对 heuristic 分别增加 1、5、2、1 次。平均回退 112.192976 秒，恰分解为移动增加 100.942976 秒、检测增加 11.25 秒，切频/光学/清除均不变。最大的 all_directional N14 例增加 403.771902 秒移动及 25 秒检测，其余三个例移动完全相同。新增候选让扫描分组/服务插入改变是待消融的解释，不是凭这一条轨迹就断言唯一因果。

累计负观测已进入证书支持集，并非只看最后一个点。但新增移动点必须立即允许替代一条近邻固定义务；真实负测后也只主动尝试删最近一个、250 m 内的固定义务。这会漏掉需要多个自然服务点联合积累后才生效、或者影响较远站点的覆盖。继承的当前实际位置扫描未被“立即替代”条件剪掉，理论上允许累计；默认启发式却缺少评估这种长期必要性的信息和价值函数。

另一项事后现象：mixed N10 在最后一次实际成功清除后，R8 仍运行 776.974477 秒（全局 T/L=3.54493），heuristic 仍运行 749.764705 秒（全局 T/L=3.78375），用于未知频道排空。此时策略不知道“这已经是最后一个真实源”，不能倒放终局答案提前停止；应优化这一尾部与此前源服务路线的融合。最后一次发现时刻也仅是事后诊断，不能作为线上标识。

## 6. 下一轮应暴露的联合状态和可证伪消融

优先优化对象是整个任务的剩余成本。现有 R8 `resolve` 宏应作为固定对照保留；要证明更深联合能力，后续还需把服务内部测点、继续定位、暂停服务和安全清除拆开，而不是仅扩大网络后宣称所有动作已可学。

| 改进/消融 | 只用公开观测的状态与动作 | 必须验证的收益及反证 |
|---|---|---|
| 当前自然服务位置的机会测量，关闭小位移候选 | 为每个未知频道保留当前点动作；记实际负测点集、来源、支持方向缺口及覆盖进度；允许暂时不删点 | 对照禁用该动作、允许但无训练、训练选择三臂；若多测却不能减少最终移动/检测，否定当前打分而非归咎证书无价值 |
| 逐频道累积证据与跨频道整站取消 | 站点的剩余未知频道义务数量、多少频道已有可删证书、使该站完全无需访问还缺哪些观测；将有限共享备选位置作为集合候选 | 同一真实轨迹前缀逐个重放删站；报告每站义务向量、实际整站取消数、替代检测数、绕路差和证明成本；不能只奖励删了多少对 |
| 全局覆盖路线与已知源服务联合 | 当前点、各公开定位区域、可安全清除点集、待覆盖支持方向、近邻路线插入成本/下界代理；同时选择下一测点/频道/服务 | 固定22点+同网络、可自适应点+同网络、规则启发式+同动作、训练+同动作；分离几何扩展和网络收益 |
| 服务微动作、暂停与重访 | 正测向带/可行区域形状及方向，实际负测约束，候选探点，已失败光学盘；清除必须保留原物理安全门与有限兜底 | 同一动作集比较宏固定顺序、单步贪心、长期策略；记录清除失败、服务间反复绕路和尾部耗时，完整收费不得遗漏 |
| N=16 发现上限专项 | 只用 K、C、剩余未知频道与历史；奖励使用整局实际费用 | 新合成 N=16 分层开发，随后独立确认；比较发现16前后费用与取消站数；不得把真实N输入策略或按终局N切换算法 |
| 切频/同站分组辅助 | 当前测向机频道、当前位置所有合法频道、共享的移动费用 | 分组开关配对；若少切频但移动增幅更大，按总T判失败，不单独挑切频指标宣传 |

可学习的进度不能仅是“已扫描了几个站”。建议将每频道的**实际已认证叶盒面积**、未认证盒的方向支持缺口/边界位置、已有自然服务测点支持度，与**实际+planned** 的残余可行性明确分开。近似覆盖面积、边界角缺口和信息增益代理可以用于打分，但必须标为近似，不能进入停止证明。跨频道站点向量/注意力应区分“某个频道获益”和“整站所有发现义务可取消”；网络训练目标用全局实际计费回报，防止重复扫点刷局部进度。

候选沉默/正回执的分支价值只能根据与当前公开历史相容的模型估计，不能先查看本局未来真实响应。多步想定必须共享第一动作并按观测分支，而不是对每个隐藏粒子独立知道答案规划后求均值。证书预算应按受影响叶/站点批处理，而不是每步每个候选重证全场；超预算回退，全部证明 wall 计入报告。

下一轮开始前应冻结动作与特征版本、训练/开发/确认切分和上述消融；本批四例已经用于解释失败，不能再算独立确认。按总T及原统一T/L、全清与失败清除、尾部、计算费用和不确定性选择，才可判断长期联合决策是否真正省掉了移动或扫描义务。

## 7. 只读复算与证据入口

- 原始账单/配置/源归档：`results/q4_rl/adaptive-cover-smoke-v2/`。完整失败路线比较与归档恢复记录：`ADAPTIVE_COVER_EXPERIMENT.md`，同目录 `mechanism-audit.json`。
- 本文所有费用按 `/measure` 和 `/clear` 的 accepted history 复算：每步移动 `round(distance/5·10^6)/10^6`，measure 加 `5+int(c!=previous_measure_channel)`，clear 加 `3+2·int(success)`；enter/exit 不加费。校验每步和等于相邻回执 `virtual_time_s` 差，且五项合计等于记录 T。
- 场景分类只使用现存记录名、终局 source_total/complete channel 集合及存档 L；没有读取 ground_truth 的源坐标/半径/朝向，没有访问 SQLite 或重建隐藏反馈。
- 所有16条记录纳入复核，没有剔除混合 N14 的长光学兜底，没有用最后发现/最后清除时刻构造伪在线早停。

最低复算片段（仓库根目录，标准库，仅读保存文件，不导入策略或仿真）：

```python
import gzip, json, math, statistics
from pathlib import Path

records = []
for path in sorted(Path("results/q4_rl/adaptive-cover-smoke-v2/records").glob("*.json.gz")):
    with gzip.open(path, "rt", encoding="utf-8") as stream:
        d = json.load(stream)
    totals = dict(movement_s=0., switching_s=0., detection_s=0., optical_s=0., removal_s=0.)
    position, channel, last = (0., 0.), 1, 0.
    for action in d["history"]:
        if action["action"] not in ("/measure", "/clear"):
            continue
        point = action["position"]["x"], action["position"]["y"]
        costs = {"movement_s": round(math.dist(position, point) / 5 * 1e6) / 1e6}
        position = point
        if action["action"] == "/measure":
            costs.update(switching_s=int(channel != action["channel"]), detection_s=5)
            channel = action["channel"]
        else:
            costs.update(optical_s=3, removal_s=2 * int(action["response"]["clear_result"] == "success"))
        current = action["response"]["virtual_time_s"]
        assert abs(sum(costs.values()) - (current-last)) < 2e-9
        last = current
        for key, value in costs.items():
            totals[key] += value
    assert all(abs(value-d["row"][key]) < 2e-8 for key, value in totals.items())
    assert abs(sum(totals.values())-d["row"]["virtual_time_s"]) < 2e-8
    records.append(d)
for arm in ("r8", "heuristic", "adaptive_ledger", "adaptive_actions"):
    rows = [d["row"] for d in records if d["row"]["strategy"] == arm]
    print(arm, {key: statistics.mean(row[key] for row in rows) for key in totals},
          "T/L", sum(row["virtual_time_s"] for row in rows) / sum(row["common_lower_bound_s"] for row in rows))
```
