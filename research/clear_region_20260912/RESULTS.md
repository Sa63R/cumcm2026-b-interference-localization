# 第三问 State 搜索优化与独立验证

2026-09-12。本轮找到可复现的小幅改进：利用同一频道历史“无信号”的位置，证明新位置必然无信号后，省略这次物理检测。冻结参数后的 128 个新随机场景中，平均总虚拟时间减少 **12.46875 秒（0.4000%）**，97 胜、0 负、31 平，全部清除成功。另有 28 个压力场景全部成功。

这是本地合成模拟器的结果。本轮没有调用官方演练或正式测试，不能将这里的时间当作官方成绩。

独立随机集共有 **1684 个目标**，双方均全部清除、零失败清除。每个目标平均耗时按“所有场景总时间 / 所有目标数”计算：**236.936 → 235.989 秒/目标**，平均省 **0.948 秒/目标**。若先在每局计算 T/N 再等权平均，则是 241.762 → 240.817 秒/目标；两种口径不要混用。

独立集每局平均物理检测次数从 **116.430** 降到 **114.352**。移动、光学定位、清除三项费用在全部 188 个场景中逐局完全相同；收益全部来自检测与切频。独立集基线的移动时间为 2362.586 秒/局，占总时间约 75.8%，仍是主要成本。

## 新增规则为什么成立

只对已发现且未清除的第三问全向源使用该规则。令源位置为 x，当前保守候选多边形为 C，同一频道历史无信号位置为 n，新查询位置为 q，真实固定接收半径为 R。

历史负观测给出 R < |x−n|。若对 C 中每一点均有 |x−q| > |x−n|，则新查询必然无信号。平方距离差为仿射函数：

`|x−q|² − |x−n|² = 2(q−n) · ((q+n)/2 − x)`。

因此只需检查完整凸多边形的每个顶点；最小差严格为正就可得到结论。实现使用相对于垂直平分线的 1e-5 米正裕量，仿射值用 `Fraction` 精确计算已存二进制浮点坐标，范数取可核验的上界，返回下界向下舍入。

这部分运算的精确性针对已保存的坐标。既有候选区域构造及原 1500 米证书仍使用浮点几何；这里没有把整套求解器升级为形式化区间算术。

未知频道仍实际检测。推断带有 `physical_measurement=false`、历史见证点、前缀动作数量和证书下界；推断不计入真实动作、真实观测或未知频道的覆盖证据。历史推断若作为后续见证，必须有可追溯且已重证的前缀来源。

冻结版本继承的顶层 `inference_scope` 文字只描述旧 1500 米规则，未完整描述本轮扩展；解释新证书应以逐条 `method=history_negative_bisector` 及本节说明为准。该文字不参与策略决策。

## 被排除的清除落点改动

同时实现了一个局部几何候选：在所有候选源位置的 19.9 米圆盘交集中，选择距当前机器人最近的可保证清除点。独立几何测试通过，但完整局表现不够好。

| 开发候选 | 平均总时间 | 相对基线平均节省 | 最大单局退化 |
|---|---:|---:|---:|
| 仅清除落点投影 nearest | 3098.359 s | −8.008 s | 299.326 s |
| 仅历史负观测 history，最终选择 | 3076.289 s | 14.063 s | 0 s |
| 两者叠加 both | 3084.109 s | 6.242 s | 281.326 s |

例如 seed 220009，落点投影累计在当次清除进场段局部省 1.765 秒，但后续移动总费用增加 282.326 秒，并多测 3 次，最终整局慢 299.326 秒。局部点位变化会影响后续观测和规划；单步更短不能推出整局更快。该候选保留作负结果，未进入独立随机集或压力集。

## 验证和复现

开发前定义三种候选；开发完成后按全清、零失败清除、P95 不超过基线 1.05 倍的候选中均值最小者选择。选定 history 后，在新随机集首局前记录完整参数与源码哈希；后续不调参。协议和选择记录分别为 `protocol.json`、`selection.json`，后者的状态字段记录的是选择时刻。

新增几何、历史证书及策略整合测试共 **32 项通过**。整合测试包含关闭两个新模块后与冻结基线逐动作及费用相同，以及逐前缀清除几何验证。已验证演练配置的 dry-run，发送模拟器请求数为零。

完整实验输出保留每局双方的场景哈希、参数、源码快照、动作、观测与费用；失败不会被删除。失败罚时预设为 360000 秒，主效果声明要求全部成功。本轮所有运行均成功。

独立审计脚本 `experiments/audit_clear_region.py` 重新建立观测前缀区域，独立展开平方距离差并用有理数重证历史推断；清除依据来自当时证据，未知频道完成证书只用真实无信号位置。还逐动作核验移动、切频、检测、定位、清除费用与接受退出状态。审计不以最终源估计、落点优化日志或事后真值代替在线几何证书。**全部 440 条轨迹审计通过，零失败**；history 在开发、独立、压力集分别少测 75、266、43 次。审计汇总见各输出目录中的 `audit.json`。

结果目录：

- `results/clear_region_dev_220000_32/`：32 场景 × 4 方法，128 条轨迹。
- `results/clear_region_holdout_230000_128/`：128 场景 × 2 方法，256 条轨迹。
- `results/clear_region_stress_240000_28/`：28 场景 × 2 方法，56 条轨迹。

在此仓库根目录复现独立随机集，输出目录须尚不存在：

```bash
.venv/bin/python experiments/evaluate_clear_region.py \
  --output results/clear_region_holdout_reproduced \
  --stage holdout --seed 230000 --count 128 --workers 2 \
  --candidate-mode history \
  --freeze-manifest results/clear_region_dev_220000_32/manifest.json
```

核心运行只依赖 Python 标准库，Python 版本要求至少 3.10，本次使用 3.12.14。批量实验存在并发和固定顺序影响，不能用其中的 wall time 声称程序计算提速；单独串行检查见 `RUNTIME.md`。

## 使用位置

本次实现位于独立目录 `state-optimization`。原 `code` 目录没有修改。原 state 入口及其默认行为保留；新方案必须显式加载配置，实验入口的函数默认值不是本次选中的配置。

- `experiments/state_search_history_silence_20260912.json`：评测的完整有效参数，明确 `clear_mode=disabled`、`history_silence=true`。
- `experiments/state_search_history_silence_practice_20260912.json`：兼容仓库既有演练 runner 的配置；移除由 runner 提供的 `problem=3` 和 `max_actions=10000` 两项，其余完全相同。
- `src/planning/history_silence.py`：历史负观测证书。
- `src/strategies/clear_region_state_search.py`：扫描整合和可单独关闭的试验候选。

仅检查演练配置可加载，不连接模拟器：

```bash
.venv/bin/python experiments/run_q3_practice.py \
  --spec experiments/state_search_history_silence_practice_20260912.json --dry-run
```

若继续寻求明显更大的收益，应关注发现尚未结束时的源处理次序及移动路线。仓库既有诊断表明，同一有限任务模型的 A* 大多已搜索闭合；增加该搜索预算不能补足未来发现和位置变化的建模损失。本轮没有证据支持承诺更大提速，也没有使用旧封存测试集继续调参。
