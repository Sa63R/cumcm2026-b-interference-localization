# R24：扩大顺路服务半径是否有足够机会

**结论：当前限定前缀样本不支持优先新增扩大门槛实验，更不支持同时放宽半径、片长和次数。** 38个已打开R12开发案例中，检查1121个去重宏动作/覆盖前缀，只发现1个满足全部指定条件、仅被40米半径门槛排除的case-channel机会。该结果不是所有可能策略的无效证明；它是一次固定范围的旧历史诊断，没有执行反事实服务。

## 过去是否已试过

当前可靠R12继承 `src/strategies/q4_r2_scheduling.py`：

- `cap16` 不进行顺路服务；`onroute` 每局最多4片、每频道最多一次。
- 原门槛为 canonical MEC 半径≤40米、经其中心到下一固定覆盖站的绕行≤100米、靠近中心/5+6≤60秒；每片真实费用上限60秒。
- R2开发配置分别评估cap16、onroute、range，并组合range+onroute。可追溯 `research/q4_round2/development-specs.json`、`RESULTS.md:30`。
- R5动态路线、R8/R9/R12局部改进仍沿用这套40/100/60/4门槛。所检索的源码历史与已归档说明没有发现已完成的扩大半径/片长/次数试验。`git log --all -- src/strategies/q4_r2_scheduling.py` 仅列原模块引入节点，并未显示后续门槛扩展。

因此，扩大半径在当前可追溯研究中不是已经被否定的同配置复试；但“未做过”本身不构成值得投入的证据。

## 固定检查规则

`R24_EARLY_SERVICE_DIAGNOSTIC.py` 只读取621001–621024随机开发、621031–621044压力开发的 `summary`，以真实direction按原 `CandidateRegion` 重放canonical区域。near直接排除为ready，真实clear、原顺路attempted、blocked均排除；覆盖完整结束才解除blocked。R12仅在resolver中暂存的辅助区域没有替代canonical门槛。

每例取前10个完整覆盖结束前缀，加全部保存的chain宏动作起点、对应源resolver终点、真实early边界并去重；不将服务片内部或无法排序的零动作边界当外层决策。真实覆盖块核查了全部当时未知频道的实际测量，下一站取原固定链中尚未完整扫描的首站。已知16源或已完成覆盖时不再统计发现途中的机会。

对未ready、未清、未blocked、未attempted频道，固定要求

\[
40<r\le120,\qquad
\|p-c\|+\|c-q\|-\|p-q\|\le100,\qquad
\|p-c\|/5+6\le60.
\]

其中 (p) 是真实当前位置，(c) 是真实正观测canonical区域的MEC中心，(q) 是下一原覆盖站。同一例同一频道只记录第一次全部几何条件成立的前缀；分别记录原4片是否耗尽，以及仅放宽半径后该频道在同一冻结局部比较中是否会胜出。没有生成新源、补造反馈、仿真执行或拟合120/100/60阈值。

## 结果

| 统计项 | 数量 |
|---|---:|
| 已读旧案例 | 38 |
| 去重检查前缀 | 1121 |
| 已无覆盖义务/已知16源而跳过的前缀 | 180 |
| 处在(40,120]半径窗的频道快照 | 364 |
| 同时满足绕行与首次靠近条件的快照 | 1 |
| 首次case-channel机会 | 1，来自1局 |
| 仅被半径门槛排除 | 1 |
| 同时被4片上限排除 | 0 |
| 原真实early服务片 | 25，全部清除成功、0中断 |
| 原来用满4片的案例 | 1 |

唯一记录是621005、prefix288、频道2：当前已知10源、已清9源、原early次数0；canonical半径62.204米，距中心191.395米，经中心到最后一个原覆盖站的绕行49.405米，首次靠近准入代理44.279秒。若只在这个冻结前缀把半径门槛改为120，它会通过原局部排序；**这不等于该次服务一定清除，也不意味着知道真实总源数是10。**

44.279秒只是原准入公式，R12可能先依据辅助区域选择另一真实动作；最终能否执行仍由原60秒真实费用门控决定。到达canonical中心也不保证定向源正接收。不能凭MEC半径62米宣称它能在剩余约16秒完成定位，或把未来绕路距离当已经节省的时间。

364个半径窗快照大多没有同时满足短绕行与短靠近条件，故当前主要缺口并非已经耗尽4片。没有实际early日志的机会不能用模拟回包补成成功事件。本次每例只主动抽取前10个覆盖结束点，后面的无chain决策覆盖间隙并非穷尽；因此1/38只描述这个预定检查样本，不宣称所有旧轨迹时刻或新场景都只有这一处机会。

## 是否另开实验

目前建议暂不优先开展。若根任务仍决定做最小可证伪实验，最清楚的单变量候选是 **radius_m:40→120，其余detour100、每片60秒、每源一次、每局4次全部不变**；本次没有证据支持同时增加片长或次数。候选仍使用真实R12 resolver、实际费用中断、原完整覆盖和最终清除证书，必须新冻结后实测，不能把本诊断当效果验证。

需要注意60×4只限制提前服务动作本身的直接费用，不能限制相对原策略的整局退化：服务后位置、观测、后续调度以及是否更早发现16源均可能改变。现有25片的成功率也不能外推到新增较宽区域。主指标仍应是完整成功前提下冻结源数构成的 `mean(T/N)`，而不是“新增服务片成功”或当前局部绕行变短。

JSON保存全部输入及几何源码SHA、每局统计和唯一前缀几何见证。未修改策略、未建分支、未运行新案例。
