# axis 实际主动探测点的选择性共享：失败消融

## 结论与停止

新训练 `106001..106016` 上，axis 基线均值 3109.128 s，追加选择性主动点共享后为 3115.076 s，**平均慢 5.948 s**。配对“节省”95% bootstrap 区间为 [-14.736,3.747] s，5 胜 11 负，最大退化 43.186 s；两者全部清除、零失败清除。P95 用时由 3386.201 s 增至 3406.697 s。

该 pilot 不支持进入 64 局确认，因此停止，不调阈值或换一批参数。保留独立 spec 与完整失败证据，不改变原 axis 默认策略。这里失败的是把该局部收益代理用于已经优化过的 axis 策略，不能据此推断共享测量一般无效。

数据：`results/state_search/active_sharing_pilot/`，含运行源码 SHA256、逐局虚拟时间、动作历史和 `paired_summary.json`。全部为本机 Windows 合成训练数据，未读取扩展/最终测试，未调用官方模拟器。

## 唯一改动与原规则的交互

`SharingStateSearch` 完整继承 axis_quantile 的探测点选择。在一条实际 `active_localization` 测量反馈已经写入真实区域后，考察当前位置对其他已发现、未清除频道的价值，最多追加 4 条通过阈值的测量。不会为了共享而改变当前测点、移动机器人、扫描未知频道或中断当前源的原子定位/清除过程。

清除后的原 StateSearch 共享规则完整保留：区域半径至少 60 m、保证接收、名义缩小至一半且至少减少 30 m。额外主动点共享会先缩小其他源，因此原 after-clear 规则之后可能少触发；这属于真实交互，不能把两种共享的预测收益直接相加。任务排序仍在当前源处理完后，使用实际更新后的几何状态重算，不启用未发现源插入评分或区域期望矩阵。

关闭 `sharing_config.enabled` 时，两局独立回归的整段动作历史与原 axis 完全一致。原 source-count 上界退出、预算退出与安全清除逻辑均保留。

## 接收条件、收益代理和完整费用

复用 `q3-geometric/src/strategies/geometric_joint.py` 的选择性共享原则，两个纯函数独立保存在 `planning/shared_observation.py`，使本分支可独立运行。

对当前点 q 和其他源的保守外多边形 C，只有所有顶点 v 都满足 `|q-v|≤1000−10^-6 m` 才评分。距离是凸函数，其在凸多边形上的最大值可由顶点取得，因此该检查是整个 C 内最坏情况的充分接收保证。实际未知接收半径至少 1000 m，所以在模型假设成立时不会把“可能接收”冒充“保证接收”。此外跳过 near 源、已清除源、已认证可清源和当前频道在同点的重复观测。

用多边形面积的 9 点确定求积，以及方向误差 `(-error_deg,0,+error_deg)`、权重 `(1/4,1/2,1/4)` 构造评分反馈；每份反馈只写到独立区域副本。旧中心 c、假设更新后中心 c' 的绕路余量为：

```
excess(q,c,c') = |q-c| + |c-c'| - |q-c'| >= 0
```

对这个量作有限平均，再除以移动速度 5 m/s，作为“提前获取定位信息可避免多少绕路”的局部代理。它不等于全程期望节省：原 axis 会主动选择更好的测点，未必先去旧中心；未来覆盖和其他共享也会更新中心。面积/三节点误差求积也不是实际反馈概率分布的精确积分。

对候选频道 c，本次选择要求：

```
局部绕路节省代理/5 − [5 s检测 + 1(c≠当前频道) s切入 + 1(c≠主频道) s切回] ≥ 5 s
```

每次选取净值最高者，观测后再更新当前频道计算下一条的费用。由于原主频道测量刚完成，选入的是其他频道，每条被选测量的保守总费用为 7 s。实际共享命令收取 6 s；预留的 1 s 恢复费在以后确实回到主频道测量时才由模拟器收取。如果之后直接清除、不必恢复，这项预留偏保守。多条共享各预留一次恢复费，也偏保守；不存在遗漏切回成本后人为制造正收益。策略没有为“恢复频道”额外做一次无用检测。

评分永不替代实际反馈或清除证书。实际清除仍要求原可行域全部包含于 19.9 m 范围，或使用原 near/兜底规则。接收安全条件可以证明；代理净收益不能作为实际收益下界。

## 为什么这轮实际变慢

| 每局均值 | axis | axis + active sharing |
|---|---:|---:|
| 覆盖测量次数 | 96.250 | 96.313 |
| 主动定位测量次数 | 18.000 | 17.625 |
| 原清除后共享次数 | 2.625 | 1.188 |
| 新主动点共享次数 | 0 | 3.125 |
| 移动时间/s | 2351.941 | 2348.076 |
| 检测 + 切频时间/s | 691.250 | 701.063 |

282 个主动点停止机会中，250 个其他频道通过接收/未认证等筛选参与评分，最终选了 50 次共享，全部实际收到 direction/near 正反馈。新共享每局实际消耗 18.750 s，同时减少部分以后测量；全程检测/切频净增加 9.813 s。移动只减少 3.865 s，所以合计慢 5.948 s。

被选动作的局部净收益代理平均为 23.130 s，明显没有变成相应全程收益。不能将这些局部数值相加视作总收益预测：彼此会重复估计后续定位价值，也可能替代原 after-clear 共享。此诊断与实际测量次数分解支持停止，而不是继续认为接收成功或几何范围变小就必然更快。

墙钟均值由 0.481 s 增至 0.803 s，其中新增评分约 0.338 s/局；虚拟时间退化是主要停止原因，额外计算也是代价。
