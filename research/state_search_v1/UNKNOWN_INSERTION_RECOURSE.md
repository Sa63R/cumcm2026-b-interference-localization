# 未发现频道概率质量与发现后路径插入：有停止条件的阴性实验

## 结论与范围

此候选保留 `axis_quantile` 的覆盖布局、合法反馈更新、主动定位和安全清除，只替换覆盖/清除任务的排序评分。在新训练种子 `102001..102016` 上，平均用时从 3069.721 s 降到 3063.271 s，仅节省 6.450 s（0.21%）；配对 bootstrap 95% 区间为 **[-20.551, 36.480] s**，3 胜、5 负、8 局完全相同，最大退化 78.777 s。两种插入评分均全清、零失败清除。

该结果不足以支持结构性改善，因此按预设“小 pilot 无实质收益就停止”的条件收束，不打开 64 局确认集，不替换已有 axis 候选。这里否定的是本次有限求积、加性插入近似的实际收益，不能否定所有未知源信念规划方法。

数据：`results/state_search/recourse_pilot/`，其中 `manifest.json` 保存运行时全部源码指纹；`paired_summary.json`、`paired_cases.json`、`surrogate_decisions.json` 保存配对和决策证据。平台为本机 Windows，不能与 Linux 均值直接配对。未使用官方模拟器、扩展验证或最终测试集。

## 先验和精确压缩的部分

题目给出数量范围和半径范围，并没有给出生成分布。本次明确假定：

- 总数 N 在 10..16 上均匀；20 个频道中均匀选择 N 个有源频道。
- 各源位置在半径 1800 m 圆盘内按面积均匀；用 4 个等面积径向带 × 24 个角扇区的面积质心，共 96 点作位置求积。
- 每个源的接收半径 R 只抽取一次，服从 [1000,1500] 上均匀分布；R 与位置、N 独立。

这些是研究先验，不是题目保证。96 个质心是有限近似，不能提供连续概率积分精度证书。

设频道 c 的实际负反馈点集为 H_c，求积位置为 x_j。所有负反馈共同约束同一个 R：

```
u_cj = max(1000, min(1500, min_{p in H_c} ||x_j-p||))
L_c = (1/96) sum_j (u_cj-1000)/500
```

空 H_c 对应 u=1500。重复测同一点不会反复降低似然；这里没有错误地将每次负反馈的独立半径概率相乘。各频道只使用它自己实际发生的测量记录。

已发现和已清除频道都计入已存在标签数 D。对仍未知频道的 L 向量，用基本对称多项式 e_k 压缩所有有源标签子集：

```
P(N | H) ∝ e_(N-D)(L) / C(20,N),  max(10,D) <= N <= 16
P(c存在 | H) ∝ L_c sum_N e_(N-D-1)(L_其他频道) / C(20,N)
```

已知频道的位置/半径观测似然在不同 N 间是同一个因子，因此相消。`1/C(20,N)` 不能丢掉，否则会改变数量后验。`e_k` 用多项式系数动态规划计算，避免显式枚举所有频道存在子集。同一负反馈几何的未知频道可以合并为一个空间概率质量组：后续目标采用加性期望，期望的线性性允许合并，**并不要求频道存在事件相互独立**。

测试将 D=14、6 个未知频道的公式与所有 64 个标签子集显式枚举对比；D=0、没有负反馈时恢复均匀 N 先验及各频道 0.65 的存在概率。

## 插入评分是近似，不能当下界

对一条冻结覆盖/已知源路线，在 x_j 和当前 R 上界下，按路线顺序积分每个覆盖点成为“首次检测点”的 R 区间。源只能插到首次检测之后的路线后缀。若插在点 a、b 之间，新增移动近似为：

```
(|a-x| + |x-b| - |a-b|) / 5
```

插在末尾用 `|a-x|/5`。完整版还扣除此处清除后节省的后续扫频费用 `6 × 后续覆盖点数`；消融版不扣。对插入位置取有限最小值，再对源位置、半径事件和频道存在概率求期望。

这精确计算的是所声明有限位置先验下的**加性插入评分**。它没有精确模拟多个未知源插入时的相互作用，也没有模拟一次测向之后仍需定位的动作与中心漂移；将新源位置当作插入点，相当于在这一局部代价估计中给予额外信息。新增源的共同固定服务项因候选间期望数量相同而省略，但位置相关的定位工作不能按此理由消掉，仍是明确未建模项。整个评分不是可采纳下界，也不是全 Q3 期望最优值。

每步候选保留原有限任务最优/预算内路线，再枚举至多 3 个不同首任务，固定首任务后调用同一 mask A* 生成后缀。总计最多 4 条候选路径，选择“冻结已知任务代价 + 插入修正”最小者，仅执行首任务后根据真实反馈重算。原 mask A* 的界和 exact 字段仍只适用于该冻结任务模型（对其他首任务是条件模型），不包含插入修正。

概率质量求积耗尽时回退原策略，未来剩余覆盖未计完有限质量时也回退。**零概率质量从不删除覆盖点、不认证不存在源、不触发完成。** 实际清除沿用原安全几何证书。

## 与旧方法的区别

| 方法 | 未发现源如何进入评分 | 主要近似 |
|---|---|---|
| axis 基线，`scan_source_s=0` | 不进入未来路径；覆盖点只支付背景扫频固定费用 | 已知源任务冻结在当前包围圆中心 |
| 原有 rollout | 从合法观测构造有限随机世界，执行若干候选宏动作及旧 efficient 后续策略 | 少量粒子、有限 rollout 预算、尾策略近似；不是完整 POMCP |
| 本实验 | 频道存在多项式 + 连续半径积分 + 96 位置质量 + 发现后后缀插入 | 多源插入相互作用、定位信息代价和实际反馈重规划未展开 |
| 阶段 3 环布局搜索 | 根据已知中心选择初始环相位/半径 | 没有未知质量，也没有固定布局下的发现后插入 |

本实验没有改布局，也没有把多世界 rollout 更名；压缩的是未知频道存在子集及共享负反馈几何。相关方法基础见 [Held–Karp, 1962](https://doi.org/10.1137/0110015) 的子集动态规划、[Smallwood–Sondik, 1973](https://pubsonline.informs.org/doi/10.1287/opre.21.5.1071) 的部分观测决策背景。上面的组合公式与插入积分是本次实现中明确推导的有限模型，不声称出自这些文献的现成定理。

## 实验解释与复现

280 次有未知质量的重规划中，只有 12 次改变首任务：5 次从覆盖变清除、2 次反向、4 次换清除源、1 次换覆盖点。改变时冻结已知任务代价平均增加 20.048 s，插入评分预测平均改善 27.307 s；这些局部代理改善不是完整反事实局收益。实际每局移动平均减少 10.638 s，但测量和切频合计增加 4.188 s。

完整版与“不扣后续扫频”消融在 16 局的整个动作历史均相同。因此这次实验不能把微小收益归功于扫频费用修正。它也表明单独加入未知位置的加性绕行代价，并未解决信息到达后路径重新安排的主要误差。

原 axis 墙钟均值 0.416 s，候选 0.463 s；候选记录的整段 recourse 规划均值 0.061 s/局。pilot 后仅补全规划日志的时间/累计展开数统计，并标明所选冻结路径的单独耗时；动作与评分公式未变，运行源码以 manifest 为准。

```
python -m pytest tests/test_unknown_mass.py -q
python experiments/run_state_search_development.py --configs experiments/state_search_recourse_configs.json --seed 102001 --count 16 --traces --output <新目录>
python experiments/summarize_unknown_recourse.py <新目录>
```

公开接口为 `strategies.recourse_state_search:run_recourse_state_search`。26 个单元/安全回归测试已通过；几何困难构造和随机场景经仅暴露合法观测的客户端运行。保留模块是为了复现与未来有针对性的改进，当前不作为推荐替代候选。
