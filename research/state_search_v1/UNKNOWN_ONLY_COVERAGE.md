# 将发现义务与已知频道信息分开：unknown-only 失败消融

## 结果和停止

新训练 `108001..108016` 上，原 axis 均值 **3253.935 s**，覆盖站只扫描仍未知频道后为 **3344.297 s**，平均慢 **90.362 s（2.777%）**。配对“节省”95% bootstrap 区间为 **[-157.820,-27.417] s**，5 胜 11 负，最大退化 350.056 s。P95 用时由 3693.824 s 增至 3811.036 s。两者均全清、零失败清除。

这是明显的负结果，按预设条件归档，不进入 64 局确认，不追加 optional 信息筛选或阈值扫描，也不改变 axis 默认策略。保留真实逐频道测量账本，供未来需要更细控制粒度的独立方案使用。

完整证据在 `results/state_search/unknown_only_pilot/`，含源代码 SHA256、动作轨迹、逐局费用与 `paired_summary.json`。本轮只用本机 Windows 合成训练场景，未读取扩展/最终测试，未调用官方模拟器。

## 唯一策略改动

`DiscoveryStateSearch` 继承原 axis_quantile 的测点、原子定位/清除、after-clear 共享和任务排序。覆盖站只扫描当前尚未发现且未在该站实际测量过的频道；不将 active-sharing、区域期望矩阵或未知源插入评分混进来。

每个固定站保存一个 20 位 `station_measured_masks`。只有真实 coverage 测量返回后才置位；到达站点、经过该点、其他频道在该点测量，都不能替代这一位。当前必需发现任务为：

```
pending[station] = still_unknown_channels & ~actually_measured_channels[station]
```

某频道真实返回 direction/near 后，它在其他站的**发现义务**可以取消，但已发现源的**清除义务**保留。已知未清频道在覆盖站再测量是可选信息动作，本次消融统一不做，用来检查这些动作是否实际上可省。

已经没有任何未知频道义务的站点从剩余路线删除，不强迫回访。公开已发现上界 16 可以在站内扫描尚未结束时停止发现，但仍必须实际清除这 16 个源。16 个原点 near 源构造中，恰好 16 次测量后继续完成 16 次成功清除，用时 175 s，没有在“全部发现”时提前退出。

此候选固定使用七点覆盖，不允许 `replace_coverage=True`。关闭 `unknown_only` 则退回原整站扫描，两局独立回归验证与 axis 全动作历史一致。

## 发现完整性的证明范围

若已发现数不足 16，一个最终仍未知的频道 c 必须在全部 7 个覆盖站都有真实 no_signal 记录，才能解除全部发现义务。原七点布局的 1000 m 接收圆覆盖整个半径 1800 m 场地；假如 c 仍有源，至少一站应能接收，与这些真实负反馈矛盾。已发现数为 16 时，公开数量上界直接排除其他未发现源。

这些结论只完成发现证明，不完成清除证明。真正退出仍依赖全部已发现源的实际成功清除，或第 16 次实际成功清除触发公开上界退出。动作预算耗尽不可能因账本部分为空而认证全清。

测试逐条重建了每站每频道的真实测量，检查未发现频道最终七站均为负反馈、没有重复coverage测量、没有用已知频道冒充未知发现任务；同时验证实际全清和零失败清除。

## 为什么省了检测却整体更慢

| 每局均值 | axis | unknown-only |
|---|---:|---:|
| 覆盖测量次数 | 100.313 | 81.375 |
| 主动定位测量次数 | 16.938 | 22.438 |
| 清除后共享测量次数 | 2.563 | 3.500 |
| 检测 + 切频时间/s | 709.063 | 630.375 |
| 移动时间/s | 2478.310 | 2647.360 |

检测和切频共节省 78.688 s，却增加 169.050 s 移动；差额正好对应平均退化 90.362 s。取消覆盖站重复观测后，原位置本来能提供的交叉约束消失，之后需要更多专门定位动作，且调度代表点也会不同。

原 axis 每局 19.063 次已知频道覆盖观测中，8.750 次为 direction，**10.313 次为 no_signal**。对固定半径 R 的同一全向源，先前正反馈点 p 和后来负反馈点 n 满足 `|x-p|≤R<|x-n|`，因此获得关于 x 的距离比较半平面；负反馈本身可以提供定位约束，不能因没有测向值就一律当成无信息。

本次消融同时删除正、负两种反馈，因此不能进一步声称退化中的某个具体秒数是由负反馈单独造成。它足以否定“已发现频道在覆盖站的测量只是冗余”这一实现假设，也说明仅允许保证接收的 optional 规则会排除部分可能有价值的负反馈。

墙钟均值由 0.647 s 增至 0.782 s，主要伴随更多定位计算。此结果不证明整站原子扫描全局最优，也不否定可中断控制；它说明必须保留有价值的信息获取，不能只以测量条数最少优化总用时。
