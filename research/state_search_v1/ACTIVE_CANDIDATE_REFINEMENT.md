# 第四阶段：保留旧候选的几何测点细化

此阶段保留首版 .5 半径代理、五个经验源假设、覆盖环、路线规划和实际安全清除规则；只扩展主动测量的有限候选位置，继续使用第三阶段的非负项下界剪枝。未加深有限源反馈树，未增加噪声节点，未修改旧候选配置。开发仅使用 `100257..100336`；验证和封存测试未读取。

## 两个预先确定的候选族

**长轴分位候选 `axis_quantile`**：以当前可行多边形最远顶点对定义长轴，投影范围长度为 W。在 1/4、3/8、5/8、3/4 分位位置放置轴上点及对称横向点，横向距离为 `clip(W/8,20,200)` m；再增加几何中心的两个同尺度横向点。新增至多 14 个点，连同原九点共至多 23 个。宽条带的外四分位点可能不满足保证接收条件，3/8、5/8 内分位用于覆盖这一情况。

**旧最佳点局部细化 `local_refine`**：先精确评价原九点，在其最佳点周围构造 3×3 局部格点。轴向步长为 `clip(W/12,20,125)` m，横向步长为 `clip(W/30,10,50)` m，除去中心新增至多八点，共至多 17 点。这是两层有限搜索，不是连续域全局优化；旧最佳点和其他旧候选都保留。

这些比例、上下限和两个候选族在 pilot 前确定，没有根据后续训练结果做网格选参。所有新增点都经过同样的接收证书筛选：到可行区域每个顶点的距离不超过 1000 m，并且此前没有在该坐标测过此频道。对凸外包区域，距离的最大值可由顶点控制，故源真值无需参与筛选。

候选使用同一有限代理评分，新增点只扩大动作集合，因此在**同一观测状态**上，完整代理最小值不可能增大。剪枝仅删除下界已严格超过当前完整评分的点，保留此有限集合最优性。它不是实际清除时间的单调性定理：换了动作就会换反馈、几何区域和后续路径，仍须以完整局的真实虚拟时间核验。

## 冻结实验结果

`100257..100272` 的 16 局 pilot 中，剪枝首版均值 3110.61 s，长轴分位 3084.26 s，局部细化 3085.92 s；均全清、零失败清除。随后冻结两种候选和参数，在 **64 个全新训练种子 `100273..100336`** 上确认：

| 方法 | 平均虚拟时间 / s | 比首版节省 / s，配对 95% CI | 胜 / 负 | P95 / s | 最大单局回退 / s |
|---|---:|---:|---:|---:|---:|
| 剪枝首版 | 3249.36 | 0 | — | 3705.81 | 0 |
| 长轴分位 | **3208.55** | **40.81 [30.13,52.16]** | 58 / 6 | **3613.07** | 43.95 |
| 局部细化 | 3215.62 | 33.73 [24.56,43.73] | 55 / 9 | 3636.65 | **26.00** |

所有方法 **64/64 全清、失败清除 0**。这些置信区间来自同场景差值的 5000 次 bootstrap，仍属于训练证据；需要统一 Linux 平台和独立验证检验泛化，不能把训练结果称为最终测试。长轴分位平均约快 1.26%，有六局退化，并非逐局改进或已逼近全局最优。

时间分解表明收益有实际来源：长轴分位平均移动成本 2458.04→2430.42 s，检测成本 614.92→601.72 s，约节省 27.62+13.20 s；平均测量数 122.98→120.34。局部细化移动更少，但测量数略升，抵消一部分收益。这也说明不能只比较单次代理分值，或只比较移动一项。

平均程序时间为剪枝首版 0.280 s、长轴分位 0.541 s、局部细化 0.738 s。它们是同机开发实测，期间存在其他检查负载，不用作跨平台硬件速度保证。首版旧动作算法本身仍可选择更快的剪枝实现。

## 计算量与可审计机制

64 局中，长轴分位完成 1149 次主动决策，平均合法候选 21.86 个；相对相同状态旧候选最佳点有 773 次改变。在扩展集合评价时剪掉 22396 个候选，共做 33004 次假想几何更新（包含先算原候选的开销）。局部细化平均合法候选 16.54 个，但其候选离旧最优更近、下界不易区分，几何更新 45897 次，实际反而更贵。因此候选数不是计算量的充分指标。

这些假想观测只作用在 `region.copy()`。实际历史独立重建的几何区域才授权清除；扩大候选不把假设源位置或假设角度写进真实状态。全套检查通过，新增 16 个参数化困难局/观测接口测试验证有限评分单调性、候选规模和独立清除证书；原剪枝版历史逐项一致性测试仍通过。

实验结束后生成[有限动作代价图及全部 64 局配对分布](../../results/state_search/refinement_summary/refinement_mechanism.png)，同时保存 PDF。图选 pilot 中首个代理改善超过 1 s 的归档状态，实际为 seed100257、频道7；原最佳代理值 261.2912 s，扩展后 251.8620 s。图中的细网格仅用于事后显示代价形状，没有用于在线决策或调参。配对分布保留全部负收益局；不能将局部热图当成源真值或真实全局价值函数。

## 交付与复现

优先进入下一轮独立核验的候选为 `experiments/state_search_candidate_axis_quantile_v1.json`，入口 `strategies.refined_state_search:run_refined_state_search`，`mode="axis_quantile"`。局部细化作为第二候选和消融保留在 `state_search_candidate_local_refine_v1.json`。原首版及精确剪枝版 spec 均不改。

```powershell
python experiments/run_state_search_development.py --configs experiments/state_search_refinement_configs.json --seed 100273 --count 64 --traces --output results/state_search/refinement_reproduction
python experiments/summarize_probe_refinement.py
python experiments/plot_probe_refinement.py
```

重跑实验应使用尚不存在的输出目录；汇总/作图脚本默认读取已归档的原结果。`refinement_pilot`、`refinement_training` 目录保留运行开始时源码哈希、配置、逐局成本分解和完整压缩轨迹；`refinement_summary` 保留配对置信区间与局部搜索计数。

方法沿用 [Held–Karp 子集状态思想](https://doi.org/10.1137/0110015) 与上一阶段已证明方向的非负项界剪枝，新增部分是结合当前几何尺度的有限动作设计。没有将有限动作最优或更细离散误写为完整部分可观测问题的最优性保证，也未更改第四问或运行官方模拟器。
