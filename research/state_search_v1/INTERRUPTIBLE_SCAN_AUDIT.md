# 扫频原子性：既有轨迹审计与待确认控制设计

本阶段只读已有训练的合法反馈历史，没有实现新策略或运行新场景。输入为 `region_travel_confirmation/` 的 64 条 axis 基线轨迹（104017..104080），不读取 `evaluation_after_exit` 的位置/半径真值。

## 时间账不是节省账

64 局有 433 个连续点内扫描组，其中 301 组发现新源。平均每组 14.642 次测量、87.596 s 点内检测/切频；每局全部点内扫描 592.641 s。首次发现一个新源后，该组平均还测 10.176 个频道，耗时 61.056 s，合计每局 287.156 s。

**这 287 s 不能直接解释成可节省时间。** 首次发现频道已经在本站测完；301/301 次它均不在余下 pending 中。因此仅中断去清这个源、再回本站测其余频道，不会删掉本站任何待测频道。提早完成一个源也不等于提早完成全部源。

真正可能的利益是：暂缓的频道在其他位置被发现，使其本站“发现义务”取消；或者其他实际测量点已对该频道形成全域覆盖证书，从而免返。单纯返回原站的折返必须计入费用。

在首次发现时，本站仍待测且**已经由过去反馈确认存在**的频道，其全部扫描费用上限平均只有 10.106 s/组（按每条最多 6 s）。若事后只用成功清除的频道标签认定哪些 pending 最终属于存在源，全部这些频道的费用上限平均为 33.708 s/组。后者是乐观的事后核算上限，不代表中断后必能在别处发现它们，更不能拿这些标签做在线选择。

## 可证明的返回代价范围

对首次新发现时的合法保守区域 C，当前站 q、成功清除点 z 满足源 x∈C 且 |z−x|≤20，因此：

```
|z−q|/5 ≤ [max_{v∈vertices(C)} |v−q| + 20]/5
```

这是“已经成功清除后返回”的单程上界，平均 229.287 s；它不是完整定位耗时上界，也不是实际会发生的返回时间。

为了提供确实可执行的完整上界，另外仅计算现有 `clearance_grid` 对 C 的 28 m 方格覆盖路线：从 q 出发按固定顺序光学尝试、成功即返回 q。完整格点闭合路线移动时间加 `3×格点数+2` 是成功清除并返回的上界；若提前成功，由三角不等式，直接返回不比走完剩余路线再返回更长。平均 74.203 格、最大 110 格，完整构造上界平均 917.307 s。near 反馈则在 q 直接清除，构造费用为 5 s。

这个上界非常松，只证明有限终止，**不建议以光学枚举作为新的实际中断策略**。计算没有向模拟器发送任何光学尝试。它也说明不能把点内剩余约 61 s 与“立即知道并清除源”作不公平比较。

## 有限可实现的控制器账本

建议新增独立控制器，不修改当前 axis：

1. 对 7 个固定站保存 `measured_mask[station]`，每个 20 位；只有该站该频道实际测量成功返回后才置位。访问过位置不等于测过全部频道。
2. 保留全局已发现、已清除、near、各源真实几何及当前频道。必需的发现任务为 `unknown_mask & ~measured_mask[station]`。频道一经真实发现，其其他站的发现义务即可取消；它仍必须真实清除。
3. 已知未清源在站点的重复测量单独视作“可选信息动作”。它不是证明发现完整性的必需扫描，也不能因从发现账本删除就宣称没有定位价值。已清/已认证源按原规则跳过。
4. 仍未知的每个频道都在 7 个保证覆盖点测过且全为 no_signal，才可证明这些频道不存在。也可用公开的已发现数量 16 上界结束发现。两种情况下都还要完成所有已发现源的实际清除。
5. 原 full-scan 控制顺序应作为关闭中断的兼容模式，验证逐动作一致；退出和日志仍采用现有客户端，不从求积概率零值获得覆盖证书。

若后续扩展到实际源旁的新测量位置，必须按每频道真实 no_signal 点集重新认证整个 1800 m 圆盘覆盖，不能将某频道测量挪成所有频道的共同覆盖站。

## 可搜索的有限动作集与最优性范围

第一版可仅允许每个站的“下一频道”和“完成该站剩余批次”，加上每个已发现源的原子 resolve。下一频道从冻结的频道次序选取，原批扫描始终保留，最多约 14 个扫描宏动作 + 16 个清除动作；实际反馈到来后再生成下一组动作。不要立即枚举 140 个扫描位的所有组合，2^140 不是一个可行的首版。

压缩应针对确实等价的状态：站点 pending 模式相同、合法负反馈历史相同、先验相同的未知频道，在固定反馈模型中可按个数合并，但当前频道必须单独保留以精确计切换费。已知源几何不同，不能只因频道标签不同而合并。选择性的跨频道信息价值也不能作为与顺序无关的固定服务费，因为那样对所有完整路线只加同一个常数。

对**固定响应、固定目的地和固定剩余任务**，可以对这些有限动作作子集/动态规划，给出该静态服务问题的最优值或预算内差距。真实正反馈会产生新源、取消其他站发现任务并改变源的可行域；这部分属于未来不确定信息，静态最优值不能当原题下界，也不能证明中断收益。

因此建议下一步先验证账本与 full-scan 兼容模式，再明确选择一种机制做 16 局独立试验：是允许暂留 pending 后免返，还是仅用逐频道新反馈更早重排已知源。两者都应与“每次首次发现就立即往返”区分开。算法启发式和新种子区间待父任务确认，当前不根据本审计擅自启动新策略训练。

复现本审计：

```
python experiments/audit_interruptible_scans.py results/state_search/region_travel_confirmation --output <新目录>
```
