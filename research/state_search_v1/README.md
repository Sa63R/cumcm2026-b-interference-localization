## 首候选接口

`strategies.state_search:run_state_search(client, *, problem=3, max_actions=10000, config=None, max_active_probes=6)` 返回 `SearchResult`。

首候选完整配置在 `experiments/state_search_candidate_v1.json`。该配置根据已曝光开发种子 `2000..2031` 选择，随后进入 `6000..6047` 验证集；验证集不是最终独立测试集。接口默认参数仅是最初的任务调度原型，实际推荐比较必须传入首候选配置，不能省略配置后声称是首候选。

48 局首轮验证：候选均值 **3152.514778 s**，同一 Windows 平台 efficient 均值 **3417.457144 s**；配对平均减少 **264.942366 s / 7.7526%**，95% bootstrap 区间 **[214.864242,317.511484] s**，P95 时间比 **0.929773**。48/48 完整清除、零失败清除，46 胜 2 负，最坏配对退化 **49.286612 s**。这仅满足相对 efficient 的本轮验证目标；仍需同平台旧 rollout 较强基线及封存最终测试。

运行环境也是配对条件：远端 Linux 与本地 Windows 的初步 efficient 均值出现差别，可能由浮点三角函数与位置固定误差哈希造成。共有评测的 `case_sha256` 必须一致，最终比较应让所有策略在同一平台、同一引擎版本运行；不能直接把跨平台同种子均值拼成配对结果。

## 与原方法相比，实际改了什么

1. **有限任务状态搜索**。把剩余覆盖站、已发现但未清除的源各自作为一项任务；源位置只用观测可行域的最小包围圆圆心估计。以已完成任务的位掩码和末任务索引表示状态，合并拥有相同后续代价结构的历史，使用 A*、MST 剩余路程下界、状态支配及可行路线作为上界剪枝。每执行一项真实任务后重建状态，因此会吸收真实的新发现与定位结果。
2. **离散主动测量位置搜索**。原方法先去可行域中心，可能与第一次测量近共线，额外测量仍缺乏交叉角。新候选包含中心、向中心移动半程/全程后横移 ±50 m 和 ±150 m，共至多 9 个点。只保留对当前整个外包区域均保证接收的点。枚举 5 个固定区域内假设，对每个候选计算名义方位观测后的区域、移动代价、到假设源的剩余路程及未达到清除精度的代价，选择有限评分最小者。
3. **共享交叉测量**。清除一个源后，利用当前已经到达的位置检查其他已发现源。只有保证接收、从未在该点测过、名义区域明显收缩时才测量，避免专门绕路到另一个源的粗糙中心。
4. **信息充分时省测**。已有近源反馈或 19.9 m 安全清除证书的源不再在覆盖站重复测量；通过合法观测已经发现 16 个源时不再保留发现任务。只有确实清除 16 源，或者完成发现覆盖且已发现源全部清除，才判完成。
5. **未选中的覆盖替站实验**。实现了全圆盘 Voronoi 有限见证覆盖检查，可用当前位置替换冗余未来站。该点必须先对每个仍未知频道实际测量，才记入公共发现站并删除未来站。1150 m 环的开发数据未触发替换；更大环偶有替换，但总体变慢，因此首候选关闭该功能。

## 可以证明的有限任务模型

冻结 n 个点任务，状态为 `(M,j)`，M 是完成任务位掩码，j 是末任务。转移到未完成任务 i 的成本定义为：

`d(j,i)/5 + service(i) + 1[i是覆盖站] * q * 当前未完成源任务数`。

首个原型使用 q=6，试图表达先清除可以节省后续扫描；但它忽略覆盖过程中的未知源发现和共享信息，开发中有反效果。因此首候选选择 q=0，并通过真实动作控制器处理测量。基准模型的 service 固定而非真实定位耗时预测；代价不能当作原问题的可实现总耗时。

两个历史到达相同 `(M,j)` 后，模型中的未完成任务、各任务位置、未完成源数完全一致，故更大累积代价的历史可被支配删除。这个严格支配仅对冻结模型成立；不能把两个不同真实观测历史仅凭同一任务掩码合并。

对未完成点集 U，剩余移动至少是 `min d(j,U) + MST(U)`：任意完整路径去掉入口边后仍连接 U，长度不小于 U 的最小生成树。再加 U 的固定服务费并放松非负的源/覆盖顺序惩罚，得到可采纳下界。队列为空时得到浮点实例最优；预算用完时保留可行路线成本 U 和队列最小下界 L，记录模型间隙 U-L。重复状态最多 O(n·2^n)，转移最多 O(n²·2^n)；实现为稀疏、按需展开，最多 22 项，每轮及每局都有确定的展开上限。相比 n! 排列枚举，这是状态共享的实际加速，而非将启发式结果改名为穷举最优。

**这些模型上下界不约束真实第三问最优值。** 真实源坐标、实际清除落点、尚未发现源、后续方位结果均不等于冻结任务模型。主动测量评分也只是固定有限假设和名义零误差观测下的经验目标，不是连续区域的期望真值或最坏情况证书。任何假设观测都只进入区域副本，不写入在线状态。

## 覆盖证书为什么包含内部空洞

对于已测站集合 P，定义 `rho(P)=max_{x∈B(0,1800)} min_{p∈P}|x-p|`。在一个裁剪到场地圆盘的最近站 Voronoi 单元内，最近站固定为 p，平方距离是凸函数；其最大值只能在直边端点，或圆弧端点/圆弧上的反向径向极值。因此枚举所有三站外心、所有两站垂直平分线与场地圆周交点、每个站的场地反向径向点，取这些候选上的最近站距离最大值。枚举的是必要见证的超集，额外点仍在场地内，不会造成虚假的过小上限。

三站外心覆盖内部 Voronoi 顶点，所以检查不局限于圆周。测试专门包含半径 1800 m 的六站环：圆周每一点到站小于 1000 m，但中心空洞达 1800 m，算法正确拒绝覆盖。代码使用浮点几何和正安全余量，绝不以稀疏网格抽样充当覆盖证明。

上述是精确实数几何上的证明，浮点实现加安全余量不是经过区间算术验证的形式化证书。独立审查另测试 39 组近重复、共线和扰动覆盖构造，未发现对 156000 个圆内/圆周样点的低估；此抽样仅检验数值实现，不能替代理论分类证明。审查还发现“已知16源后替站仍会测4个空频道”的24秒性能浪费，已添加对应早退和回归测试，首候选因关闭替站不受该修复影响。

公共发现站的含义是：对任何最终仍未发现的频道，该站都有真实 no_signal 反馈。不是机器狗经过一个位置就算测过所有频道。每次替站都会记录实际测量频道，测试在退出后独立按各个缺失频道的真实负观测重建覆盖。

## 资料依据

- Held 与 Karp (1962), *A Dynamic Programming Approach to Sequencing Problems*, DOI [10.1137/0110015](https://doi.org/10.1137/0110015)。采用集合加末端状态的动态规划思想。出版页摘要可检索，完整出版页访问受限；没有声称复现其全部实现。
- Hart、Nilsson 与 Raphael (1968), *A Formal Basis for the Heuristic Determination of Minimum Cost Paths*，以及 1972 勘误。[作者出版列表及原文链接](https://ai.stanford.edu/~nilsson/publications.html)。采用可采纳剩余代价下界、代价更低状态保留的搜索思想；本实现允许重新打开改进状态，不依赖未经证明的一致性。
- Aurenhammer (1991), *Voronoi Diagrams — A Survey of a Fundamental Geometric Data Structure*, ACM Computing Surveys 23(3), 345–405。[全文](https://www.wias-berlin.de/people/si/course/files/Aurenhammer91-Voronoi.pdf)。核实最近站单元的半平面表示、三点等距顶点、最大空圆思想；圆盘边界的径向候选与本题逐频道覆盖使用是本实现的具体推导。

这些来源支持算法构件，不能据此声称组合后的完整在线策略具有原论文的最优性保证。代码接口、实际观测审计、配对实验和独立最终测试共同决定是否值得采用。
