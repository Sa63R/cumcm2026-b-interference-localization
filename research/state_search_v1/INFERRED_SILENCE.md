# 已知频道的确定无信号推断与物理删测

## 结论与范围

在 axis_quantile 的独立子策略中，只删除测前即可证明必然无信号的已知频道覆盖测量。16 局 pilot 后冻结代码，另 64 局确认平均节省 **13.250 s（0.423%）**，配对 bootstrap 95% 区间 **[9.750,16.969] s**，37 胜、0 负、27 平。两组都全清且零失败清除；64 局的移动完全相同，删除对应的物理读数后其余实际动作记录也逐条相同。

这是有明确逻辑依据的小改进，不是进一步逼近整体最优的证明。所有结果来自 Windows 合成训练环境；官方环境的噪声序列、切频及后续控制分叉仍须独立验证。旧 axis 默认、Q4、清除证书和未知频道的真实发现测量均未改变。

## 数学条件

令 C 为由某个**已发现且未清除**的 Q3 源的合法观测构造的保守外包区域，真实位置 x 属于 C。公开规则给出同一个源的固定接收半径 R≤1500 m。在待测位置 q，如果

```
d(q,C) = min_{y∈C} ||q-y|| > 1500,
```

则对全部可行真实位置都有 ||q-x||>R，反馈必为无信号。该结论不需要猜测源位置、真实半径或总源数，也不需要平均收益先验。

计算先用外包最小圆 C⊆B(c,r)：三角不等式给出 d(q,C)≥||q-c||−r。若此便宜下界未通过，再计算 q 到完整凸多边形的距离：在多边形内取零，否则取所有闭边线段投影距离的最小值，显式处理单点、线段、零长度边和空区域。不能用到顶点的最小距离代替到边的距离，否则会高估距离、误删测量。

实现要求距离严格大于 1500+1e-5 m，并要求已有正方位观测、非空区域。1e-5 是任务尺度下 binary64 的工程余量，**不是区间算术或形式化精确数值证书**。这里证明的是已知源的一次必然反馈；它不授权将未知频道的未测位置算成覆盖，也不能推广到含定向源的 Q4。

## 推断、几何约束与真实记录分离

无信号事实存为 `inferred_no_signal_constraints`，记录频道、位置、推断时已有实际动作数、距离下界、证书方法和 `physical_measurement=false`。它不调用模拟器、不构造假响应，不增加实际测量次数，不插入 `action_history` 或实际观测位置集合，也不改变设备当前频道。

区域内部显式调用 `observe_no_signal(q)` 保留该逻辑约束。对于来自 p 的正反馈，同一个固定 R 给出 ||x-p||≤R<||x-q||，故可继续使用原有正负距离比较半平面；以后到来的正反馈也与此推断位置配对。推断事实的来源由单独日志标记，不应在读报告时将区域中的全部负位置都称作实测。

每个覆盖站仍实际测量所有尚未发现的频道。因此原七点覆盖完成证明不借用这些推断；发现 16 个源只结束发现，退出仍需真正清除全部目标。axis 局部探点、成功清除后的共享测量和路线求解器均保持原代码。

## 先审计，再运行独立场景

对原有 104017..104080 的 64 局 axis 完整历史，仅从实际观测顺序重建区域，谓词在读取待判定测量结果之前计算。1167 次已知源覆盖反馈中，667 次无信号、500 次方位；102 次通过严格几何条件，其中最小包围圆证书 93 次，多边形边证书 9 次，涉及 30 局。随后检查这 102 次实测果然全部无信号。

冻结余下动作顺序重算检测和切频费用，潜在平均省 9.546875 s/局，其中检测费 7.968750 s/局。这只是轨迹审计，不是提前使用这些事后位置执行策略。用推断替换相应物理读数后，每次更新的区域顶点及负位置历史与原记录完全相同。

另做完全丢弃该约束的对照：138 次更新出现不同顶点表示，含 53 次后续正反馈，但最大 MEC 半径差为 0，最大面积差只有 5.82e-11 m²，未达到预设几何差异阈值。因此不能据此声称“省略约束必然损失显著信息”；保留推断约束的理由是明确来源并保持原几何更新语义及表示一致性。

## 与区域均值点调度的组合

本次只重写 `_scan`；`RegionStateSearch` 只重写 `_next_task`，两者都继承原 axis 局部测点选择，因此在结构上可以通过薄包装组合，并保留两个独立候选以作消融。组合并不意味着收益相加：排序变化会改变到达覆盖站时的区域，进而改变可推断次数。至少需要检查禁用推断与原均值点策略一致、推断日志仍只来自合法历史、未知频道实际覆盖与清除证书成立，再单独比较组合后的真实时间。当前这份 64 局结果只支持 axis 上的推断删测。
