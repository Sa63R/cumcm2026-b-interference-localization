# 问题3每源200秒目标：本轮诊断与停止记录

本轮未找到可保留的虚拟用时改善，推荐版本仍为`experiment/q3-runtime-equivalent`。
它的策略与`760af823`一致，运行效率优化已完成，不能用CPU提速冒充搜索虚拟用时改善。
本文是实验交接，不是论文正文。未操作正式测试、演练窗口或采集程序，未训练、未用GPU。

## 当前成绩与目标距离

已保存的40局演练平均243.41秒/源，原物理观测下界平均131.79秒/源，mean(T/LB)=1.851；
3/40局低于200秒/源。同一批合计T/合计N为238.11秒/源，不能与逐局T/N平均互换。
32个普通合成案例对应243.01秒/源、物理真值下界136.29秒/源、mean(T/LB)=1.798。
演练和合成下界的可用信息不同，不能据两比值直接评价跨批优劣。

40局中10源局平均287.63秒/源，16源局207.67秒/源。因此对方若只是某局/某个源数低于200，
尚不足以断定其同分布多局平均优于本版；反之，同源数、同口径独立多局低于200是值得追赶的成绩。
当前演练均值到200需约17.8%的比例改善。存在物理下界已高于200秒/源的合法压力案例，
所以不能承诺所有场景都低于200。

移动占演练总虚拟费用75.69%。有限固定目标点规划98.665%的调用已在其代理模型内精确，
主要空间在发现、定位和清除路径的联合决策，而非单纯增加该模型的枚举预算。
主动定位阶段的移动也包含走向源附近的必需路程，不能把整个阶段都当成可消除绕路。
完整源数分组、成本分解及141个输入哈希见[基准诊断](BASELINE_DIAGNOSIS.md)。

## 实际做了哪些新检查

1. **先排除已经失败的机制。** 无约束释放当前源会引入后续长距离回访，旧几何抢占已显示这一失效机制。
   本轮初写原型未运行就归档；不能将它计作新的失败性能试验。最近清除圆盘交集、负点凸包等也不原样重做。
2. **清除后补扫并调整多个剩余覆盖站。** 旧32局合法前缀中筛查5058个删站/邻站联动候选和4896个整体变换候选。
   前者没有完整覆盖可行方案，后者725个覆盖可行，但扣除必要新增扫描费后均无正代理收益。
   这里只否决这些固定候选，未证明一般连续多站优化无效。
3. **沿途替换一个覆盖站上的已知源读数。** q位于原行进线段，用q处实际观测替代站b上的同频道观测，
   其他未知频道仍在b实测。双端保证接收版本，在旧16局112个扫描边界的62个合法q点评分后0选择。
4. **显式混合接收模型。** q仍保证接收，但b允许direction/near/no_signal；每个位置节点保留与全部旧正负历史
   相容的同一个R区间，而不是每次重新抽半径。新增模型共评估81个q点，最大代理毛收益6.589413秒，
   仍未超过事先固定的7秒门槛（2秒切频预留＋5秒净收益裕量），0选择。没有空支持或数值失败。

第3、4项是在同一批旧16局真实观测前缀上评分，**不是新策略跑完16局**，也不能声称0次选择证明真实收益为零。
它只说明本次有限动作和价值模型没有给出值得扩大测试的动作。没有降低阈值来追求触发；预留的
976000..976015开发集及976100..后续独立确认集均未打开。

## 实施与验证

新增实现分为`planning/enroute_scan.py`和`strategies/enroute_scan.py`，默认的双端保证版本与
独立mixed配置分开保存；它们均为未采用实验模块，不应替代当前最佳入口。
新动作只基于已观测区域，假想分支只修改副本。q不取得公共发现覆盖信用，替换的必须是已知频道。
控制器保留其余频道原顺序，避免16源截断因无关排序而改变；预算中断不伪造完成的扫描站。

实现前审查发现最初1秒切频预留只覆盖站内，遗漏最终调谐频道变化在下一次测量的额外1秒，
因此在任何新性能案例前修正为2秒。纯离散2880组频道序列验证该局部2秒上界。
最终针对性测试92项通过（8.81秒），含27项几何模型测试、10项控制器测试和已有静默/覆盖回归。
其中关闭新增机制的旧案例回归与原策略完整同轨迹；未把这些回归记作新的性能验证集。

因为准入阶段没有达到预定代理收益裕量的候选，本轮没有开启新整局性能对照，也没有重新跑全量性能基准。
CPU开销、完整清除率和虚拟费用的改善均不能由这里的前缀评分推出。

## 结论与后续优先级

停止原因是这两组具体新机制未获得进一步实验的依据，加上已有重复方向的阴性记录，
并非额度耗尽、并非发现理论不可优化，更不是证明200秒的多局平均目标不可能。
当前最佳算法和核心分支保留；本轮无效新试验分支在完整可恢复归档推送后清理。

若继续投入，优先级应转向能够改变完整发现与清除路线的方案，并与现有更强学习版本做同案例比较。
例如完整的多站非刚性覆盖优化或有真实反馈条件的联合服务代价模型仍有未覆盖范围，但它们都没有
现成可靠收益证明；不能把“尚未做过”当作能兑现17.8%改善的依据。
单纯加A*预算、重复调局部测点阈值或拿单局200秒当胜利，都缺少本轮证据支持。
