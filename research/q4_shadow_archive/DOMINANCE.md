# 严格远距删测：可以证明什么，不能证明什么

本文针对冻结的 `Q4RangePruningSearch`，不使用新开发集或最终集结果。此前64例日志只用于发现结构机会，不能继续称为独立验证。这里没有新仿真。

## 1. 几何删除条件成立

真实正方位观测构成的凸外包区域记为 (C)，真源 (s\in C)。若

\[
\operatorname{dist}(p,C)>1500+10^{-5},
\]

则 (\lVert p-s\rVert>1500\ge R)，该测量必定无信号，和源类型、发射半平面无关。反向命题不成立，普通Q4无信号不能据此裁剪 (C)。推断事件不是实际观测，不增加空频道覆盖证据。

## 2. 空间轨迹不变所需条件

以下结论只讨论与原 `compact_22/joint/state_pruned` 比较的独立删测配置，并假定：

1. 两者从相同的新会话状态开始，面对相同固定源、半径、朝向和按位置/频道固定的测量误差场。仅“重复同点反馈固定”本身不足以约束两个不同执行历史中新点误差怎样耦合；本地坐标哈希误差场满足这一条件。
2. 两者都不因动作、虚拟时限、实际时限、外部异常或用户中断提前停止。CPU耗时和停止概率不包含在支配结论内。
3. 保持原22站集合、顺序、完整站内扫描、正观测区域更新、中心及最大180m偏移的主动点、光学路线和确定性chain DP/A*不变。当前上层并非一步贪心，但也不分支模拟未来观测。

至少 (20-16=4) 个真实空频道一直没有正观测，不能被ready或range规则删去，故每个保留的覆盖站仍有真实测量，删测不删掉到该站的移动。站内各频道独立，跳过必然静默的测量不改变扫描结束时各频道的正观测区域、near状态、ready集合、源数状态或狗的位置。

原定位候选距当前区域的MEC中心最多180m，且实数几何下MEC中心属于凸区域。区域只会缩小，因此一个曾距旧区域超过1500m的被删站点，也距后来区域超过1500m，不可能变成后来这些主动候选。`observed_positions`中少这些点不会改变此独立配置的候选去重结果。

DP使用位置、源/覆盖任务和固定费用；当前调谐频道、虚拟时间只用于测量顺序、计费或预算检查，不进入其任务代价。按任务归纳，两者在上述条件下具有相同站点与源处理空间序列、正观测、主动测量及光学尝试。浮点实现仍采用现有几何余量，本文不是区间算术形式证明。

## 3. 当前实现不能直接套“删掉序列元素，换频不增”

`_scan`会把**实际当前频道**移到扫描列表首位。删掉一个末尾频道会改变下个站的列表顺序，所以新测量频道序列不一定是旧序列的子序列，换频次数也不一定不增。

一个最小直观的调度层反例：空频道为1–4，5/6为已知频道，两者初始调谐6。表中的集合是原算法当前需要扫的频道，ready频道会永久移出集合。

| 步 | 原扫描集合 | 新策略删去 | 原实际次序 | 新实际次序 | 新−原换频数 |
|---|---|---|---|---|---:|
|1|1–6|无|6,1,2,3,4,5|相同|0|
|2|1–6|6|5,1,2,3,4,6|5,1,2,3,4|−1|
|3|1–6|无|6,1,2,3,4,5|4,1,2,3,5,6|0|
|4|1–5|无|5,1,2,3,4|1,2,3,4,5|+1|
|5|1–4|无|4,1,2,3|1,2,3,4|+1|

累计换频22→23；测量减少1次，所以这个小例总费用仍省4秒，**它反驳的是换频不增论据，不是已构造本题负局**。

更大调度抽象中，空频道取1–5，其余15个为已知源。初始调谐20，依次扫1–20三次，只在第二次删20；随后原集合逐站缩为1–19、1–18、…、1–5。18个扫描块共少1次测量，换频222→236，总测量/换频费用反而增加9秒。下面可复算：

```python
def sweep(channels, tuned):
    order = ([tuned] if tuned in channels else []) + [c for c in sorted(channels) if c != tuned]
    switches = sum(a != b for a, b in zip([tuned] + order, order))
    return order[-1], switches, len(order)

old = new = 20
old_switch = new_switch = old_count = new_count = 0
blocks = [(20, set()), (20, {20}), (20, set())] + [(n, set()) for n in range(19, 4, -1)]
for n, deleted in blocks:
    old, c, m = sweep(set(range(1, n+1)), old)
    old_switch += c; old_count += m
    new, c, m = sweep(set(range(1, n+1))-deleted, new)
    new_switch += c; new_count += m
print(len(blocks), old_count-new_count, old_switch, new_switch,
      5*(new_count-old_count)+new_switch-old_switch)
# 18 1 222 236 9
```

这是符合频道数、永久ready删减、空频道保留的**扫描调度抽象**。尚未构造在固定22站几何、方位误差和删测距离规则下实现全部这些ready/远距变化的物理场景，不能冒称本题真实轨迹反例。它说明仅凭频道删除和计数条件，无法推出无条件逐局不增。

## 4. 当前实现已有一个足够强的条件性费用界

令实际共同扫描块数为 (K\le22)，总删测数为 (D)。第 (k) 站原集合为 (B_k)，删去 (d_k) 个频道后为 (A_k)。两集合非空。按“当前频道优先”规则，单站换频费恰为

\[
|B_k|-1+u_k,\quad |A_k|-1+u'_k,
\]

其中 (u_k,u'_k\in\{0,1\}) 表示各自起始调谐频道不在该扫描集合。因此单站换频增量是 (-d_k+u'_k-u_k)。覆盖完成后的共同主动测量尾序列至多在首个测量上相差1次换频；clear不调谐。

在第2节空间轨迹耦合条件下，移动和光学费用相同，得到

\[
T_{\mathrm{range}}-T_{\mathrm{base}}
=-6D+\sum_{k=1}^{K}(u'_k-u_k)+\delta_{\mathrm{tail}}
\le -6D+K+1\le -6D+23.
\]

这是实际微秒计费下也成立的整数动作费用差：移动段相同，首次到站的移动只是转移到该站另一次真实测量上，移动舍入不变。故 **(D\ge4) 时至少省1秒；(D=0) 时执行完全相同**。(D=1,2,3) 不能仅凭此界判定。该界不是“每次必省5秒”，也不覆盖预算触发后执行长度不同的情况。

## 5. 可选shadow顺序能恢复更强的子序列证明

一个后续独立配置可维护仅用于决定原扫描次序的 `shadow_tuned`：真实measure后更新它，被删measure也按原算法本应调谐的频道更新它；clear不改。实际客户端频道仍只由真实指令改变，shadow不是实际状态或伪造观测。

这样在相同空间/反馈耦合条件下，实际测量频道序列恰为原算法序列删除 (D) 个元素。换频指标 (1[a\ne b]) 满足三角不等式，删除元素不增加总换频数，因此

\[
T_{\mathrm{shadow}}\le T_{\mathrm{base}}-5D.
\]

该更强命题仅适用于保留原源处理时机/定位规则的shadow独立配置。和early-service等依赖费用预测或预算的机制组合后可能产生不同动作，必须另做实验，不能继承此保证。

## 6. 审计边界

现有物理账本和真实逐频道覆盖审计照常执行；`audit_range_prefix`仅从真实正观测前缀重建区域并核每次远距删测，不接收隐藏真值或增加absence信用。shadow若实现，只需另审其原次序重建及非真实状态标记；实际费用必须继续以HTTP/local wire的真实频道为准。
