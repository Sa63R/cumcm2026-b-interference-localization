# 第三轮定位假设：用连续反馈包络识别“单测完成”动作

范围：只读保护基准8c624d0、删测增强760af82和已公开诊断；只对旧200114的6个公开前缀做无副作用几何计算。没有运行新场景、策略反事实仿真、SQLite或隐藏真值计算。以下是待检验机制，不是已证明的性能提升。

## 一个建议及其依据

建议研究**有连续反馈覆盖证书的单次测向完成计划**：在原来最多23个主频道测点中，寻找“无论接下来合法测向是多少，测完后都能直接持证清除”的候选，再按测量加清除的完整移动费用选点。暂不增加当前位置，不改变发现调度、共享测量、接收区域或旧删测模块。

当前评分 `planning/radius_probe.py:choose_radius_probe` 用MEC中心和至多4个内缩顶点作为名义源，以零额外误差方向裁剪区域；若预测半径仍大于19.9 m，后续只收固定6秒和线性半径罚项。这个代理不能区别两类不同形状：一个还要走较大横向距离才能分辨深度的长条，与一个几乎已能直接清除的局部区域。它也没有把连续噪声边缘和未采样端部纳入完整定位尾成本。

这是**结构性缺失**，不意味着分数总是低估：旧200114前三个源段的分数与实际完整片段分别为251.482/199.175、190.843/214.551、137.725/176.995秒，有高估也有低估。不能拿它拟合一个统一乘数解决。

已读 `ACTIVE_PROBE_NEXT_HYPOTHESIS.md`：旧32局336个完整定位段有170/120/45/1段使用1/2/3/4次主动测量；主动定位含清除的折线相对固定事后终点的直连仅多71.542秒/局。故潜力应定位为**减少困难区域的补测和转向尾部**，不能声称能省下全部主动定位移动的1264秒/局。

## 连续反馈证书如何做

对公开保守区域C、合法新测点q，将全部报告角度[0,360)分成区间I。区间宽δ、中心β。构造

`C_I = C ∩ wedge(q, β, half_angle=1.005°+δ/2)`，

并保留既有圆上界与正负历史半平面。因为任意落入I的精细测向只使用±1.005°包络，其真实源必在C_I内。这是覆盖**所有连续反馈**的集合论包含，不需要源概率、误差求积节点或后验归一。

对每个非空C_I求MEC(c_I,r_I)。若全部r_I≤19.9 m，则每个方向反馈都有安全清除点

`z_I = projection_of_q_to_disk(c_I, 19.9-r_I)`。

near另行原地清除。q仍必须通过所有C顶点距离≤1000减安全余量、真实测量新鲜性等判据；不能因这套评分接纳可能无信号的点。角度区间只用来保守预测，真实反馈和真实区域仍按原精细观测保存。

这个条件足够但不必要。区间外包或原C的保守性会使可行点被拒绝；固定计算预算未证成时必须回退，不能把有限样本没发现坏反馈当作证书。

完整上界为

`U(q)=distance(current,q)/5 + 5 + actual_switch + max_I[distance(q,z_I)/5+5]`，

其中near尾为5秒。它是**这个单源、一次测向后按区间表清除的实际可执行计划的最坏费用上界**，不包括清完后去别的源/覆盖站，不是整局期望值、全局最优界或官方后验积分。

必须执行被计价的计划：实际收到方向后，可进一步用精细区域独立确认z_I安全，并在z_I清除；若改回原MEC安全小圆的最近点，不能未经验证就沿用上述距离上界，因为不同外包MEC的内部安全小圆不必嵌套。也可选择另一个经过全顶点检查且距q不超过已计价距离的安全点。不能只在评分中假设马上清除，实际仍按原算法补测，却把前述界说成真实完成界。

## 为什么不同于已失败路线

| 旧方向 | 本建议真正改变的内容 |
| --- | --- |
| current-probe | 不加当前位置，改变目标与完整完成动作语义；不能把0.5°包络当另一个名字的24点评分 |
| negative-hull | 不增加负点非凸几何、不靠未知频道区域变化；针对已选主频道的连续反馈不确定性 |
| clear-lens / certified-tail | 在尚无清除证书时选测点；不只是已有证书后的清除落点微调 |
| finite/binned probe tree | 旧树虽也用角箱加宽外包，但分支存在与质量来自6/24个有限源，终端为预测光学格子且现场未必执行；本建议没有有限源后验，并要求所有连续反馈受控、执行所比较的单测完成计划 |
| 全局MC / coupled tree | 不采样完整世界，不重复跑几十条整局尾；只处理当前频道的一个局部完成计划 |

基准已有 `score_detection_point` 的少量假设最坏一阶误差/交角评分，也不等于这里完整连续反馈区域的持证完成费用。

## 最小公平检验与当前判断

先做确定性几何准入，不应立刻宣称有大幅平均收益：独立检查跨0°/360°角箱、楔形边界、near、空区域、重复点、全顶点接收及清除距离，确认所有方向区间覆盖和计划计费。区间细化只能作为有固定容差与预算的证书求解，不能依性能反复扫角宽。关闭模块应逐动作回到删测增强760af82。

最初实验只允许一个机制：保持原23点、原任务顺序与原删测；有单测完成证书时按完整最坏完成费用选一个计划，没有则原样回退，并真实执行所比较计划。必须单列原选择本身也获证的情况，避免把进一步缩半径误当收益。这个选择原则不保证期望或整局支配；即便使最坏局部界改善，也可能让大量普通反馈绕路。

若主代理认为这项抗尾部假设值得一次新小批，则同时报告触发频率、额外/减少真实探测数、完整主频道片段费用、片段之后首条外出边、整局均值/P95/max和CPU。所有候选仍在同一公开前缀内形成；不按旧案例/源位置挑测试，也不把旧前缀上界当新实验结果。未来性能验收必须是另行冻结的新案例集合。

**当前结论：有明确结构性评分缺口，也找到了现有测点集合中的单测完成证书；但首探普遍较长，局部机会集中后半段，且新计划的最坏上界尚未比旧真实成本更低。值得保留为独立的稳健定位假设，不能称其已具备大幅省时证据。若目标只看平均提速，这一小样本依据仍偏弱；若希望减少补测/尾部失控，则比重做原地候选或增加有限后验节点更有实质区别。**
