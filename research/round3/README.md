## 收获与停止依据

主要问题不是把同一个有限路线模型再多展开一些。代表位置、定位结束落点、之后的新发现和重新规划之间的误差，会把较低的代理费用反转成更高的实际用时。正确保留可行上界很有价值，但不能补齐这些模型误差；一步证书能证明安全和局部费用，也不能单独证明全局节省。

此前已检验状态代表、负反馈区域、发现代价、测点细化、覆盖移站、共享测量、中断恢复、尾段和条件蒙特卡洛等主要方向。本轮最后一个具体可隔离的实现缺口也已修复、复核，仍未通过门槛，因此不再重复低价值参数扫描。更可靠的出口/未来发现联合模型、新RL训练、极小尾段与删测组合仍是开放问题，但没有足够新证据要求本轮继续扩展。[方向覆盖与停止依据](diagnoses/RESEARCH_COVERAGE_STOP_CRITERIA.md)

旧LB免费提供位置，允许相邻圆盘边使用互不一致的接触点，还忽略发现信息费用；它不是在线可达最优。1.764不能解释为仍有76.4%的可省空间。本轮没有换分母制造提升，也没有证明当前策略已达极限。
