# 问题3状态搜索的等值运行效率优化

基准为 `research/q3-r2-derived-silence` 的冻结提交 `760af8230a8e5bda6050663b19d871a9701c9829`。本分支只优化实现开销，配置继续使用 `experiments/state_search_candidate_derived_silence_combined_v1.json`。不减候选数、搜索展开预算、二分次数或几何精度，不改变任何物理与客户端规则。本轮不调用官方接口，不使用 GPU，不训练模型。

## 允许的改动及等值依据

1. 在同一次测量决策的两轮候选评分间，复用同一公开区域、同一精确位置与方位的假想区域半径。缓存绑定有序顶点、正负观测和几何参数；不跨真实决策保存。评分的加法顺序、候选排序、剪枝条件和逻辑搜索计数均不变。
2. 完整覆盖半径仍枚举原来的全部 Voronoi 见证点。设已知最远最近距离平方为 M，若某见证点到一个站点的距离平方已经不超过 M，则它到最近站点的距离更不可能超过 M，可结束该点剩余的距离计算。普通有界数值走快路径，非有限或极端数值保留原归约。见证点生成、浮点表达式和认证容差不变。
3. 已有候选区域时不再构造一个随即丢弃的默认 CandidateRegion；保留原区域对象及更新。
4. 第二阶段追加至多 128 组接收圆半平面约束的 LRU 缓存。只缓存原几何函数生成的不可变约束元组；位置、半径、边数保留精确输入及正负零，非普通参数走原函数。裁剪顺序和公式不变，不缓存观测或隐藏真值。追加项先在独立分支验证，再与原基准复跑同一批 54 个案例；这些复跑不是新增独立案例。

## 验证标准

- 对冻结源码做评分/几何严格浮点差分，覆盖退化、异常和缓存失效情况。
- 整局对比要求动作逐项、虚拟时间、清除数、失败清除数、终止证书、策略诊断（仅排除实际计时字段）与观测反馈完全相等。
- 在同一 CPU 主机串行启动独立进程，AB/BA 交错两轮，计时排除 Python 启动、导入、案例生成、下界计算和结果序列化，保留策略及本地模拟客户端开销。记录 CPU 与墙钟时间和主机负载。
- 默认 8 个已使用开发案例、32 个新普通案例、14 个新压力案例，共 54 案例、216 次整局运行。分别汇报各组与总体的平均、P95、最大运行时间；配对日志不一致则不接受提速结论。
- 下界仍为旧的先知物理松弛：清除圆盘间距离图开放路线的精确子集 DP，移动长度除以 5 米/秒，再加每源 5 秒。位置免费已知，不增加空频道认证费用。所有下界仅在策略结束后计算。

## 复现

在本分支根目录，以相同 Python 运行：

```text
python experiments/runtime_equivalence_benchmark.py --baseline ../q3-r2-derived-silence --candidate . --output results/runtime_equivalent/reproduction --repeats 2
```

输出目录必须不存在。无 Git 的远端源码快照使用本地生成的 `SOURCE_SNAPSHOT.json` 严格核验全部文件哈希，基准提交必须匹配且无源文件改动。独立进程使用相同冻结的客户端、物理模拟和评估器。

结果边界：有限案例一致性提供实验证据；上述缓存/提前结束的等值依据说明为什么不改决策。实际提速依赖 CPU、系统负载、Python 版本。真实模拟器还含 HTTP 与服务端耗时，离线结果不能直接作为正式测试表中的程序运行时间。
