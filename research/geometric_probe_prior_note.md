# 下一项可核对的建模误差：面积权重不等于接收条件后的权重

本条只推导建模差异，没有修改或重新评估正在确认的首探策略。

设理想化研究先验为源位置在 1800 m 圆盘内均匀、独立接收半径 `R~Uniform[1000,1500]`。固定一组历史观测，若暂把兼容角度内的似然视为常数，则候选位置 x 对应的接收半径区间为

`L(x)=max(1000, max_正信号点 p |x−p|)`，

`U(x)=min(1500, min_无信号点 n |x−n|)`。

在仍兼容 near/direction、角度、场地等约束的前提下，边际位置权重应乘 `max(0,U(x)−L(x))/500`。这是对未知半径积分的结果，不能只检查区间非空就仍给所有面积单元相同质量。现有 frozen rollout 的 `q3_belief.py` 已使用半径区间长度权重；当前几何首探版本明确只采用等权面积求积，是费用代理而非精确后验。

一个可解析例子：在原点只知道收到 direction（距离>5 m），不条件化具体数值方位。记源到原点距离为 r，则接收后的径向密度正比于

`r w(r)`，其中 `w(r)=1`（5<r≤1000），`w(r)=(1500−r)/500`（1000<r≤1500）。

故条件平均距离为

`[∫_5^1000 r² dr + ∫_1000^1500 r²(1500−r)/500 dr] / [∫_5^1000 r dr + ∫_1000^1500 r(1500−r)/500 dr]`

`= 162499990/189997 = 855.2766096306784 m`。

如果错误地把所有 5<r≤1500 的面积单元等权，则平均为

`[∫_5^1500 r² dr]/[∫_5^1500 r dr] = 903010/903 = 1000.0110741971207 m`。

两者相差约 144.734 m，说明“候选几何面积质心更接近先验均值”并不等于“给定收到信号后的期望位置”。若还条件化具体数值方位，只有在采用与距离无关的角度似然假设时，才可直接沿用此径向结论；不能把它无条件套到当前坐标哈希误差场。

这给出一个有明确依据的后续单变量实验方向：在相同候选、相同假设坐标和费用计算中，对假设成本按可行 R 区间长度重新加权。它仍不能消除粗求积、有限误差场、仅一个邻源及局部后续策略的误差，也没有证明一定节省机器人时间。当前 107001–107080 的策略没有加入这一权重，避免混淆实验身份。

有理数结果用 Python `fractions.Fraction` 直接积分复算，没有数值拟合、实际源坐标或保留测试场景参与。
