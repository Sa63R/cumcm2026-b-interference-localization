# 固定父模型的信用分配诊断（16个训练案例）

本批仅使用预先指定的合成训练 benchmark 种子 3000001–3000016；动作随机种子依次为 9114100–9114115。原父模型权重固定，采用 v3/base/flat 的随机策略。没有优化器步骤、改参、挑选场景或读取开发/确认/最终集、真实验证数据库。不是新策略性能对照。

16/16 正常退出、全清，失败清除 0。共 2124 个完整策略决策，物理轨迹、每步与整局计费、λ=1 累加恒等式全部通过。平均实付 **3120.409828 秒**，平均主下界 **1679.104814 秒**，`sum(T)/sum(LB)` = **1.858377**。主下界固定为 `L/5+5N`，只在退出后从评估器取得源几何并计算原清除圆路线图下界。

## 信用估计结果

同一轨迹、未经 batch 归一化的 λ=.95 与 λ=1 优势有 **555/2124（26.13%）** 异号。父 critic 对本条实际后续费用的预测误差：平均偏差 +16.929 秒，MAE 167.227 秒，RMSE 200.673 秒。正偏差表示预估费用高于该条实际费用。

跨记录的优势经验方差为 5646.711 与 39983.014 秒²，后者约 7.081 倍。它混合了不同历史、动作和回合，**不是同一状态重复采样测得的条件估计方差**。完整成功回合中，`A1×1000 = -V×1000 - 实际剩余费用`；A1 与该 V 预测误差是同一量，不构成两份独立证据。
