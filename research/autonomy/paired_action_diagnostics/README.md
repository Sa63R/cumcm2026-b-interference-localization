# 固定父模型：一次主动测量的真实分叉诊断

**结果：不能把“不保证接收的当前位置测量”直接判为坏动作。** 在预先声明的 16 个训练场景中，将第一次合格动作强制换成同频道、保证接收、即时移动最短的合法 base 探点，9 局更快、7 局更慢，平均总耗时反而增加 **11.781 s**。两组各 16 局全部清除，失败清除均为 0，全部正常接受退出。

这是一次有限的机制诊断，没有更新权重，没有部署新的选点规则。不能由此断言原动作全局最优，也不能推广为保证接收候选普遍更差。

## 预先声明的方法

- 场景固定为训练种子 `3000101..3000116`，没有更换种子、补选场景或按结果挑选前缀；本次 16 局恰好都有合格前缀，缺失数为 0。
- 父模型文件 SHA256：`3d21ba7931143f281d2e7554261b001867c65fec9c2bd7465a79f91e95b7cef4`；原 v3/base/flat MLP，采用确定性 argmax，无训练和优化器操作。
- A 是完整原策略。只有当原策略**首次**选择当前位置的主动 `probe`，该频道公开保守可行域至当前位置的最大顶点距离大于 1000 m，且已有同频道最大顶点距离不超过 1000 m 的合法 base `probe` 时，才锁定分叉。锁定发生在动作执行前。
- B 的替代从这些合法保证接收探点中选即时移动距离最短者；平局依次按 x、y、原候选下标处理。替代的确定不使用真实源位置、接收半径、A 的未来反馈或任何最终费用。
- B 从相同场景种子重新运行，分叉前逐决策核验原动作、候选、float32 网络输入及公开几何状态指纹；在分叉点进一步核验完整已接受动作与响应前缀。仅忽略响应中的 `real_timestamp_ms`，因为独立运行的墙钟必然不同；位置、频道、虚拟时间、测量反馈等物理和策略字段全部保留并要求完全相同。
- B 恰好强制一次替代，然后继续同一冻结确定性策略及原来的安全清除和兜底控制器。32 条完整轨迹都保留。分叉后策略可以随实际新反馈改变后续动作；没有拿 A 的旧动作序列强行套到 B。
- 本地研究引擎的噪声由场景 seed、频道和精确坐标确定，同地点同频道两组反馈一致。未改变引擎或公共 geometry。真实源数据只在分支退出后交给费用审计和下界计算；策略只收到合法 client、候选和公开可行域。
- 本地 CPU 单核亲和性，Torch / 数值库各 1 线程；运行总计 49.191 s。未使用 GPU、官方模拟器、验证数据库、远端服务器、confirmation 或 final 数据。

## 总费用拆分

令分叉前共同费用为 P，即时动作费用为 C，动作完成后的完整剩余费用为 F，则：

`T_B - T_A = (C_B - C_A) + (F_B - F_A)`。

所有移动、切频道、测量、光学搜索、移除以及末尾兜底均按研究引擎实际计费。已被策略选择的 source fallback 作为该宏动作费用收录；只把最后已记录动作之后的费用视为额外尾费，避免重复加账。每条轨迹还独立重放核验了整个物理账本。

|---|---:|---:|

| 失败清除 | 0 | 0 |

B 即时平均多支付 **62.710 s**，后续平均节省 **50.929 s**，合计平均多支付 **11.781 s**。B−A 的中位数为 −5.887 s，范围为 −363.410 至 +424.692 s。均值和胜率回答不同问题：这批场景虽然 B 的胜局较多，几个较大的退步仍让平均总费上升。这些数字是固定 16 例的描述统计，没有宣称对独立新场景显著优越或劣化。

## 能得出什么，不能得出什么

原动作在 15 个分叉处实际返回 `direction`，只有 seed 3000106 返回 `no_signal`。B 的 16 个替代全部返回 `direction`。因此，本诊断直接研究的是**事前不保证接收**的动作选择，不等于把 16 次已知无信号测量删掉。不能用事后看到无信号来挑选要替换的动作。

seed 3000106 中，A 在当前位置花 6 s 得到无信号，B 移动后花 220.166 s 得到方向；B 后续也多花 25.393 s，最终多用 239.560 s。保证收到方向并不保证完整任务更快。另一方面，seed 3000112 中，替代的额外即时移动只需 43.615 s，后续却节省 407.026 s，完整任务节省 363.410 s；原策略显然也存在可改善的具体决策。

这支持保留“便宜原地探测”和“保证接收探测”让策略权衡，关注完整后续费用，而不是一刀切删除不保证接收候选。但不能把该实验用于逐场全知选 A/B，也不能用这批结果声称某个网络已学会信息价值。不同分支的未来费用差同时包含信息、机器人位置、后续选点和清除顺序的影响；本次没有拆出纯信息效应。

13/16 的第一次合格分叉出现在第 21 个零基决策处，另外三次为第 23、45、81 个决策；这是固定规则所得前缀分布，不代表完整任务所有阶段。这里只比较一个固定父策略的后续执行，未评价其他训练成熟程度或更优的后续策略。
