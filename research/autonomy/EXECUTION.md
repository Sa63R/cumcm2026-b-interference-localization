## 修复记录

1. 依赖源下载超时：保留失败日志，在同一个独立虚拟环境内改用依赖镜像安装；Torch 始终使用已有的 CPU wheel。环境最终通过 CPU 构建检查。
2. 第一次实际多进程采样触发 `AF_UNIX path too long`：任务原目录名导致 Python 临时监听套接字路径过长。确认本任务全部活动进程已退出后，只将本任务目录改为短名 `q3a-r1`，源代码、检查点和场景游标保持不变。随后恢复同一任务，已完成的两组评估不重复执行。
3. 首次失败前预留的 128 个训练场景仍计入尝试预算，恢复从后续场景继续；没有清零预算或重新使用该批。首块绝对截止时间也保留，故它的有效优化时间少于干净运行的半小时。后续比较须披露实际更新数/样本数/耗时；不能把这一次受部署中断影响的控制组称作精确同有效训练量对照。
