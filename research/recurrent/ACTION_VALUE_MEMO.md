# 额外测量是否值得：全局回报与记忆的诊断备忘

2026-09-11。供当前轮完成后的诊断使用；本次只读原论文并写备忘，未实现新模型、训练、调用官方接口或打开最终集/真实验证数据库。

**当前训练目标已经计入整局耗时，额外测量的长期价值仍需要学出来。** 多花一次测量的钱，可能换来更短的定位路线，也可能完全不改变后续决策。测量次数、可行域面积缩小、发现新频道都只是诊断量；判断标准是保持清除与终止要求后，整局实际用时是否减少。

## gamma=1、GAE=.95、GRU 分别负责什么

用 H 表示截至当前的可观测历史。若动作 a 的即时费用为 c，后续始终使用策略 π，其预期剩余费用是：

```
Cπ(H,a) = c(H,a) + E[后续全部费用 | H,a,π]
省秒优势 = E[a'~π][Cπ(H,a')] - Cπ(H,a)
```

这是相对当前策略平均动作的优势，不是相对理论最优或强状态基线的优势。网络的 actor logits 也不是带“秒”单位的 Q 值，不能把 softmax 概率大小解释为收益估计。

本分支每步奖励为负增量虚拟耗时/1000，正常失败另有罚项，决策上限后的固定完成策略耗时归入最后一步。完整成功回合的 gamma=1 回报对应负总耗时/1000；它允许“眼前多花、以后少花”的动作获得正优势。全局目标已存在，尚未证明训练能准确分辨哪个动作带来了节约。

对完整终止回合，当前 GAE 为 `δ_t = r_t + V(H_(t+1)) - V(H_t)`、`A_t = Σ_k .95^k δ_(t+k)`，终态 V=0。按公式计算，20/50/100 次决策后的单个残差权重约为 .3585/.0769/.00592；单位是决策步。准确 critic 可把远期效果带入近端残差，所以不能解读为“只看20步”或“远期奖励被全部忽略”。λ=1 可减少此处对 bootstrap 准确度的依赖，方差通常更大；PPO 裁剪、多轮更新和熵项仍在，不能称整个训练无偏。行政截断应排除或正确 bootstrap，不能伪造终态。

GRU 增加利用过去观测的能力，完整回合 BPTT 保留跨步梯度；它不补回从未输入的原始信息，不保证池化后的表示充分，也不自动计算探测的信息价值或消除价值估计误差。当前回合尾部仍是固定完成策略，因此学到的是包含该尾策略的费用；动作集合之外的行为没有被优化。当前整局小批次和旧单步小批次的优化次数也不同，不能把所有差异都归因于记忆。

## 本轮无收益时，只优先检查两个最小机制

1. **优势是否错配到动作：先作离线信用诊断。** 在下一次允许的训练合成场景中预先固定少量完整 rollouts，保存采样时的 V、逐步真实费用与原始动作特征；若现有日志只有汇总，不能反推这些量。固定同一批轨迹，重算 λ=.95 与 λ=1 的未归一化优势，按主动定位/覆盖发现/清除、距离终态步数及进入固定尾策略前后，报告符号分歧、方差、V 与完整剩余回报的误差。单条 Monte Carlo 回报仍有噪声，符号分歧不是动作因果收益的真值。只有该诊断提示长延迟信用不稳定，才值得另立预算做“仅 λ=.95→1”的同预算对照，保持网络、动作、场景划分、初始化和批量口径不变；本轮不改参。

2. **动作本身是否回本：固定前缀，做一次合法动作分叉。** 以后仅在预先固定的合法合成开发案例中，完整重放同一已接受动作前缀；分支A强制一次被质疑的主动测量，分支B强制同一候选集中的一个预先规定的覆盖/定位/清除动作，随后都执行同一个冻结、仅看观测的尾策略到正常结束。比较 `D=T_B-T_A`，同时拆开即时移动/切频/测量成本与后续节约，保留失败和覆盖证书，不能把“跳过必要覆盖”当合法捷径。正D只说明该动作在这些前缀与该尾策略下值得，并非全局最优证明。预先固定前缀抽取与替代动作规则，按 case_sha 配对；隐藏场景只由离线模拟器维持，不提供给选动作的策略，不能用事后最优分支在线作弊。真实验证数据库不支持这种任意反事实分叉。

分叉若表明动作通常无法回本，优先研究候选设计或选择规则；若有明显可兑现的节约而策略选不中，再检查优势估计和历史表示。少量机制案例不能用于宣布性能胜出。后续性能报告须同时给全清/失败、总耗时与旧下界比：`LB_old=L/5+5N+30(20-N)·1[N<16]`，汇总使用 `sum(T)/sum(LB_old)`，其中 L 由原物理路线下界审计得到；最终分区继续封存。
